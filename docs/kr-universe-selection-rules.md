# 국장 후보 100종목 선정 규칙과 현재 상태

후보 목록은 **조사 대상 후보**이며 실제 감시 목록이 아니다. 현재 실제 활성 감시는 0종목이다.

## 선정 규칙 (개별주)
1. 시장: KOSPI·KOSDAQ 보통주만. 우선주·ETN·SPAC·리츠·관리종목·거래정지·상폐 관련은 후보에서 제외하거나 보류로 둔다.
2. 대표성: 업종을 고루 포함(반도체, 조선, 자동차, 금융, 2차전지, 바이오, 인터넷·게임, 통신·전력, 소비재, 지주·종합상사 등).
3. 유동성·규모: 시가총액·거래대금 상위권을 기준으로 삼되, **이번 단계는 시총 순위와 거래대금을 확인하지 못해 순위 근거를 기록하지 않았다.** 선정 이유에는 "대표성·유동성 후보"라고만 적었다.
4. 각 항목은 종목명·6자리 코드·시장·업종·평가 프로필·선정 근거·선정일·출처·검증 상태를 가진다.
5. 100개를 채우기 위해 코드를 추정하거나 만들지 않는다. 부족분은 비워 둔다.

## 검증 절차 (후속 승인 필요)
1. 사용자가 합법적으로 받은 공식 상장종목 목록 파일(예: 한국거래소 제공 내보내기, 공공데이터포털 KRX상장종목정보)을 준비한다. 이번 단계에서는 해당 API를 호출하지 않았다.
2. `node tools/kr-universe-audit.cjs <상장목록.json>`으로 **오프라인 대조**한다. 코드·이름·시장이 모두 맞으면 `matched`, 다르면 `mismatch`(보류), 없으면 `not-found`(보류).
3. 대조 통과는 "코드와 이름이 실존한다"는 뜻일 뿐 감시 활성화가 아니다. 활성화에는 별도의 가격 검증(정규장 종가·수정 52주 고가·분할·교차검증)이 필요하다.
4. 부족한 27개는 같은 규칙과 같은 대조 절차로 채운다.
