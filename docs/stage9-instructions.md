## 3. 목표 A — 한국 공식 상장목록 검증 준비

1. 금융위원회 공공데이터포털 `금융위원회_KRX상장종목정보`의 공식 API/파일 제공 범위, 인증 절차, 라이선스(공공누리 유형), 표시·저장·가공 제한, 업데이트 시점을 **공식 원문 근거와 확인일**로 정리한다.
2. 실제 키 발급·호출은 하지 않는다. 사용자가 적법하게 받은 파일을 로컬에서 검증하는 **오프라인 입력 절차와 예시 형식**을 문서화한다. 인증키·토큰·개인정보를 채팅/로그/ZIP/저장소에 넣지 않는다.
3. 기존 상장목록 검증기의 해시·기준일·행 수·종목코드·시장구분·중복코드·우선주/스팩/리츠/ETN 의심 보류 규칙을 보존한다. 필요 시 합성 픽스처로 오류 검증을 강화한다.
4. 공식 목록이 없으면 실제 검증 수는 **0**으로 유지한다. 임의 데이터로 73개를 '공식 확인' 처리하거나 27개를 지어내지 않는다. 공식 데이터가 적법하게 확보된 이후에만 종목 보충 후보를 제안한다.
5. 국내 개별주와 국내 상장 ETF는 별도 목록 및 별도 적격성 기준으로 관리한다.

## 4. 목표 B — 미국·한국 시세 공급자 이용권 및 정확성 조사

공식 문서·약관·가격 페이지를 가능한 한 직접 확인하고 URL, 확인일, 인용 근거, 미확정 항목을 표로 남긴다. 최소 조사 대상:

- 한국: 금융위원회 주식시세정보, 금융위원회 KRX상장종목정보, KRX 정보데이터시스템/유료 서비스, 한국투자증권 KIS(가능 범위).
- 미국/글로벌: Twelve Data, Alpha Vantage, Massive, Tiingo, Finnhub(공식 문서 확인 가능한 범위).

각 공급자에 대해 아래를 개별적으로 판정한다.

- 한국·미국 주식 및 ETF 지원 범위, 일봉/정규장 종가 제공, 최신 거래일 갱신 시각 및 지연(T+1 포함)
- **52주 최고가와 종가의 동일 조정 기준**(분할·배당·권리락), raw/adjusted 혼용 방지, 과거 52주 충분성
- 시장 휴장일·거래소 시간대·UTC 오프셋, 정규장/시간외 구분, 수정/정정 데이터 처리
- SPY 및 한국 지수·업종 ETF 등 벤치마크 이용 가능 여부
- 개인 단말의 **가격 표시, 내부 계산·가공, 로컬 저장, 캐시 기간, 파생지표 보존, 재배포** 권리 구분
- 무료/유료 범위, 월비용, 요청 제한, 호출 실패·제한 시 대응, 키 보관·브라우저 노출 위험
- 약관이 확인되지 않으면 `미확정`; 권리상 충돌이 확인되면 `부적격`; 모든 필수 요건이 문서로 충족된 경우에만 `후보 적격`으로 구분. `후보 적격`도 실제 연결 승인이 아니다.

가격표만 보고 서비스에 가입하거나 결제하지 않는다. 공식 문서 접근이 안 되면 실패 사유를 기록하고 추정으로 채우지 않는다.

## 5. 목표 C — 읽기 전용 5+5 파일럿 게이트 고도화

- 미국 고정 5종목: MSFT, GOOGL, AVGO, VRT, JPM.
- 한국: **공식 상장목록 검증을 마친 개별주 중 5종목**만 선정. 공식 검증 전에는 한국 파일럿 0종목.
- 실제 공급자 승인 전에는 네트워크 호출·실가격 수집을 하지 않는다.
- 합성 데이터 기반으로 `출처/이용권 → 종목 적격성 → 정규장·거래일 → 조정기준 → 52주 고가 → 독립 교차검증 → 표시·저장 권리`의 단계별 게이트를 시험한다.
- 각 단계에 `통과/보류/실패`, 이유, 출처, 확인 시각, 검증 범위, 실가격 여부를 기록한다. 실패·보류 시 매수/매도 점수나 활성 감시로 연결하지 않는다.
- 네트워크, 실제 localStorage, API 키, 주문 엔드포인트 접근을 시험에서 차단한다. 불필요한 신규 화면과 운영 연결은 만들지 않는다.

## 6. 개발·시험 기준

- 8단계 기준에서 **기존 279개 단위시험과 모바일 25묶음**을 먼저 재현한다. 재현 불가 시 이유와 환경을 보고하고 변경을 강행하지 않는다.
- 신규 기능은 가능하면 기존 코드를 변경하지 않는 독립 모듈/문서/시험으로 추가한다. 변경이 불가피하면 파일별 사유와 회귀 위험을 보고한다.
- 신규 시험은 라이선스 미확정, stale/미래 시세, 분할 조정 불일치, 장외거래 혼합, 52주 데이터 부족, 휴장일, 중복·상장폐지 의심, 오프라인/네트워크 차단, 비밀값 비노출, 데이터 입력 불변성을 포함한다.
- 합성 100종목 부하시험과 **실제 100종목 감시를 명확히 구별**한다. 기존 모바일 시험은 신규 화면을 검증하지 않는다는 점도 명시한다.
- 실제 Android 홈 화면/PWA 시험은 별도 단계로 남긴다.
