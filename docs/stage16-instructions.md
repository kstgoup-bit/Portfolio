## 4. 작업 B — 실제 시세 공급자 최종 비교 및 무호출 검증
- 미국 주식·ETF와 한국 주식·ETF의 가격 공급자 후보를 **공식 문서 기준**으로 조사한다.
- 비교표 필수 항목: 종가/장중/지연 여부, 미국·한국 커버리지, ETF·상장폐지 처리, 가격 조정(분할·배당), 과거 데이터, API 인증, 호출량·요금, 개인 사용 및 표시/재배포 약관, 데이터 시각·거래소·통화·타임존, 장애·지연 처리.
- KRX 상장종목정보는 **종목 식별용**이며 주가 공급자와 구분한다.
- 실제 호출 없이 샘플 응답/계약 기반 어댑터, 정규화, 중복·결측·비정상 가격 탐지, 공급자 교체 인터페이스를 시험한다.
- 실 API 호출이 필요하면 '호출 대상·최대 횟수·비용·보안·예상 검증 항목'을 승인 요청서로 제출하고 **승인 대기**한다.
- 공급자 선정이 불가능하면 이유와 대안을 제시한다. 검증 불가 가격으로 실감시 종목 수를 늘리지 않는다.

## 5. 작업 C — 모바일 통합을 위한 안전한 데이터 설계
- 15단계 거래기록·투자판단 기록을 기존 앱에 연결하기 위한 **백업 스키마 확장 설계**를 먼저 작성한다.
- 기존 데이터와 신규 거래기록의 차이, 마이그레이션·롤백, 버전 호환, 중복 거래 ID 충돌, 누락 거래, 외화 환산, 계좌별 구분, 내보내기/복원, 기기 교체를 포함한다.
- 기존 앱 데이터는 읽기 전용으로 대조하고, 신규 기능은 별도 실험실/시험 사본에만 연결한다. **운영 데이터에 쓰기 및 기존 백업 스키마 변경은 승인 전 금지.**
- 손익은 거래내역 부족 시 '계산 불가'를 유지한다. 해외 양도세는 추정치, 국내 세금·연금 세금은 검증 전 계산하지 않는다.
- 갤럭시 360/390/430px 화면, 뒤로가기, 앱 종료/복귀, 파일 가져오기/내보내기, 오프라인 상태, 데이터 저장 실패·복구 안내를 자동화 시험한다.
- 실제 갤럭시 실기기 시험은 사용자가 수행할 수 있도록 **휴대폰 전용 10~15분 점검표**를 만든다. 자동화 통과를 실기기 통과로 표시하지 않는다.

## 6. 작업 D — 곡소리·환호성 및 백테스트의 정직한 표시
- 감시 화면에 공급자, 기준 시각, 가격 유형(종가/지연/실시간), 통화, 데이터 유효기간, 갱신 오류, 종목별 검증 상태를 표시하도록 설계한다.
- 활성 감시 수는 '실제 조회·가격 검증·현재 유효한 조건'을 모두 만족하는 종목만 센다. 합성·캐시·미검증 수는 별도로 표시한다.
- 곡소리/환호성 신호는 단순 하락률과 투자 판단을 구분한다. 거래 정지·상장폐지·실적 악화·기업행위의 오탐 위험을 명시한다.
- 실데이터 백테스트는 적법한 과거 데이터 확보 및 사용권 승인 전 실행하지 않는다. 합성 백테스트는 연구용으로만 표시한다.

- 공급자 비교표, 보안·비용·사용권 평가서, 시세 어댑터 합성 시험, 데이터 스키마/롤백 설계, 갤럭시 점검표를 제출한다.

- 별도 승인 없이는 실제 호출·유료 계약·운영 앱 적용을 완료 조건으로 삼지 않는다.
