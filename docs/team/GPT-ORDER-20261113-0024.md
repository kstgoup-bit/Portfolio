## 3. 첫 검증 사례: NVDA 20주 매도
이 사례는 **사용자 사실 기반 합성 입력**이며 실제 증권사 체결원장과 다르다. 실제 체결 가격 미확정:
- 초기 보유 NVDA 40.01002주
- 평균 취득가 USD 139.68
- 20주를 **약 USD 161**에 매도한 것으로 가정
- 가상 매도대금 USD 3220, 수수료·세금·환차손익 제외 가상 실현이익 USD 426.40
- 잔여 20.01002주
- 대안 비교: A 전액 현금, B NVDA 전액 재매수, C GOOGL/MSFT/AVGO 각각 전액 매수, D NVDA+타 종목 분산, E 일부 재투자+현금 유지
- 동일 현금·기준시각·수수료·환율 가정에서 비교, 가격은 사용자 입력 변수. 주식 수 증가만이 아니라 전체 자산가치·변동 위험·집중 위험을 비교.

필수 산식:
```
grossSaleUSD = soldQty * sellPriceUSD
grossProfitUSD = soldQty * (sellPriceUSD - averageCostUSD)
repurchaseQty = (grossSaleUSD - sellingFeesUSD - buyingFeesUSD) / buyPriceUSD
netShareChange = repurchaseQty - soldQty
positionWeight = positionMarketValue / portfolioMarketValue
```
소수점 매매 불가일 때 가능한 정수 수량과 잔여 현금 정확히 계산. USD 투자이익과 원화 세무상 양도소득은 분리: 원화환산 근거 없으면 세금 계산은 `산출 보류`.
예시 검산(비용 0): USD 3220 / USD 140 = 23주(+3주), USD 3220 / USD 175 = 18.4주(-1.6주).
입력값의 0/음수/NaN/Infinity, 통화혼합, 비용 초과, 보유량 초과 매도, 비중 분모 0 처리 필수.
