# 위험계 입력 검증 (risk-guard v1) — 개발 보고

작성: 클로 · 2026-11-26 · 브랜치 work/claude-risk-guard-20261126 (main 미병합) · 원인 조사: CLAUDE-INVESTIGATE-RISK-GAUGE-20261126.md
정정: 조사 문서의 "종합 위험지수 카드가 '안전'을 띄운다"는 **틀림**. 점수(score)는 저장되지 않아 그 카드는 지금도 뜨지 않는다. 실제로 잘못된 값이 영향을 준 곳은 위험계 화면 자체와 아침 브리핑(`v5Brief`)의 VIX·금리·HY 읽기였다.

## 바뀐 것
- `has/risk-guard.js`(신규, 순수 함수): FRED CSV는 머리글(요청한 ID와 일치)·"YYYY-MM-DD,숫자" 형식만, Yahoo는 심볼 일치·가격·시각이 숫자일 때만 인정. 값 범위·관측일(7일 초과 과거, 미래 2일 초과 거부) 검사, HY는 %→bps 변환, 10Y·2Y·HY가 같은 값이면(화면의 1.00/1.00/100bps) 쓰레기 응답으로 폐기, 저장값은 v2 형식만 복원(옛 형식·기본값 280/4.5/18/100·VIX 3.0 전부 폐기).
- `portfolio_v5.html` `fetchRiskData`: 형식 검증을 통과한 응답만 채택(오류 페이지는 무시), **가짜 기본값 제거**, 실패 값은 7일 안의 검증된 이전 값만 "이전값(관측일)"로 표시·경고색, 핵심 지표(HY·10Y·VIX)가 없으면 **종합 점수를 계산하지 않고** "❗ 믿을 수 있는 값이 없어요"로 표시. 2Y 대체 출처 ^IRX(3개월물)는 제거(FRED DGS2만). `loadRiskData`도 검증된 저장값만 사용. 브리핑은 검증된 v2 값만 읽음(옛 임시 키 v5_rkCache는 더 읽지 않음).
- 모듈 로드 한 줄(`has/risk-guard.js`) 추가. 모듈이 없으면 조회하지 않고 안내만.
- 이 파일의 변경 기록을 기존 보호 시험 체계에 반영: tests/lib/live-data-edits.json(역변환 3쌍), live-data-pins.json(현재 해시).
