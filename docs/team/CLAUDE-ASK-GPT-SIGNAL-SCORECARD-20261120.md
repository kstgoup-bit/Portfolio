# P1이 하는 일 (요약)
1. 기록 관문: 요약 36시간 이내, 후보 전부 status=reference, drawdownBasis=bar-close-high-365d(옛 기준 거부), missingCount 5% 이하, 기준지수(KR=069500, US=SPY) 기준일 일치. 하나라도 어기면 그날 전체 미기록.
2. 같은 기준일 중복 거부, 저장 상한 60,000자(초과 시 새 기록만 거부).
3. 신규 진입 이벤트만 표본으로 센다: 직전 기록 5개 이상 연속 부재 후 진입. 첫 기록일은 이전 상태 불명이라 제외.
4. 30/90/180일(±5일) 채점: 종목수익률 − 지수수익률 = 초과수익, 최대낙폭 별도. 미래 봉 사용 금지, 자료 없음·미성숙은 숨기지 않고 센다.
5. N<30이면 "표본 부족 — 참고만", 결론 문구 없음. N≥30이어도 "같은 결과가 계속된다는 보장 없음(시장 국면·생존편향)" 고정 문구.
