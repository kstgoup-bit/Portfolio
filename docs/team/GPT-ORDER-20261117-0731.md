## 1단계 범위 — 코드·계약 조사, 설계·합성 시험만
1. 현재 GAS JSONP 일반 시세 경로, `has/price-trust.js`, `has/price-trust-ui.js`, `has/quote-model.js`, 레이더 및 오늘의 투자 판단의 신뢰도 관문을 정적으로 추적해 메타데이터의 실제 소비 지점을 표로 기록한다. `source`는 원천 가격 공급자, `transport`는 사용자 GAS, `asOf`는 해당 가격 관측 기준시각, `receivedAt`는 앱/서버 수신시각으로 **엄격히 분리**한다.
2. 기존 GAS 계약 `{ "AAPL": 100.0, "MSFT": 200.0 }` 형태를 유지하면서 예약 필드(예 `__quoteMeta`)를 **추가**하는 v1 계약을 제안한다. 예시:
   ```json
   {
     "AAPL": 100.0,
     "__quoteMeta": {
       "schema": "has-quote-meta-v1",
       "quotes": {
         "AAPL": {
           "market": "US", "currency": "USD", "source": "실제-공급자-식별자",
           "asOf": "2026-11-16T16:00:00-05:00", "marketDate": "2026-11-16",
           "kind": "regular-close", "adjusted": "none",
           "receivedAt": "2026-11-17T00:00:00Z"
         }
       }
     }
   }
   ```
   **예시 시각·값은 가상**이며 실제 공급자·종가 인증이 아니다. 실제 제공자가 확인해주지 못하는 필드는 null/unknown으로 두고 허위 공급자·종가·시각을 생성하지 않는다. 스키마 예약 키 충돌·크기 제한·JSONP 콜백 보호·부분 메타·기존 클라이언트 호환을 포함한다.
3. 시장(KR/US)·티커·가격 숫자와 메타의 1:1 결합, 오프셋 있는 ISO-8601·시장일·가격 종류·통화·조정 여부 검증, 미래/오래됨/휴장/장중/혼합 출처/기업행위 의심에서 **보수적 보류**를 계약에 명시한다. 앱의 현재 수신시각을 공급자 `asOf`로 승격시키지 말고, GAS 경로 자체를 독립 출처라고 부르지 않는다.
4. 상태를 (A) **메타가 붙은 단일 출처(출처·시각 확인 가능하지만 독립 검증 아님)**, (B) 독립 가격 대조(독립 공급자·같은 시장/날짜/종가종류/조정기준/통화에서 비교), (C) 근거 불충분/불일치/오래됨으로 나눈다. '확인됨'은 A와 B의 의미를 분리해 표시한다. **A만으로 매수·매도 의견 보류를 해제하지 않는다**. B라도 재무·본질가치·최신 뉴스/공시·반론·사용자 최종 판단이라는 기존 보호 관문을 통과하지 못하면 매수·매도 신호를 허용하지 않는다.
5. 기존 `manual` `signalHold=false` 및 독립 검증 문자열 자가 선언이 하위 관문을 우회할 수 있는지 **합성 반례 시험**을 작성하고, 안전한 fail-closed 변경안을 문서로 제시한다(이번 단계 운영 코드 수정 금지).
6. 한 줄 가격 신뢰도 띠는 '미확인'을 **중립·간결**하게 표시하되 숨기지 않고, 확인된 실제 이상(조회 실패, 기준시각 경과, 종목/시장/통화 불일치, 충돌, 조정 여부 변경)은 명확히 강조한다. 정상 표시와 이상 경고의 기준·우선순위·갤럭시 360/390/430 시험 항목을 설계한다. GAS와 지수의 가격 출처 혼용 문제는 별도 `GPT-20261117-0730` 조사와 교차 참조하되, 지수 히스토리/기존 투자기록 자동 수정은 포함하지 않는다.
