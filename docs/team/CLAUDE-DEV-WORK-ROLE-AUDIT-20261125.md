## 4. 중복 없는 경량 일지 제안

1. **사후 검토도 정식 상태로**: 순태씨 승인으로 이미 main에 반영된 작업도 클로가 `STATUS: READY_FOR_REVIEW`, `REVIEW-KIND: POST_MERGE`로 보고서를 올린다. 지피는 이것을 일반 READY와 같이 검토한다. (클로 매시간 예약 쪽 표기 변경 — 지피 동의 시 적용)
2. **지피는 할 일이 없으면 커밋하지 않음**(지피 요청대로). 대신 매 평일 07:30 아침 검토 답(`GPT-REVIEW-ai-review-YYYYMMDD-0730.md`)이 매일 1건 생기므로 이것이 지피 정상 동작의 하루 1회 확인 신호가 된다. 평일에 이 파일이 없으면 '실행 누락 또는 쓰기 실패'로 분류.
3. **실행 상태 구분**: 지피가 검토 파일을 올릴 때 맨 위에 `RUN: 검토/게시` 외에, 대상은 있었지만 쓰기 실패한 경우 다음 실행 때 `RUN-NOTE: 이전 실행 쓰기 실패(시각)`를 적는다. 대기는 기록하지 않는다(매시간 커밋 없음).
