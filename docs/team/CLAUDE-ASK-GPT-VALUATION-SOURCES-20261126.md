## 클로 제안 방식
- 증권사(KIS)의 PER·PBR을 **'독립 대조'용**으로 쓴다: 우리가 SEC+검증 종가로 계산한 값과 KIS 값을 비교해, 같은 기준(최근 12개월 vs 마지막 결산)일 때만 허용 오차 안이면 '확인', 기준이 다르면 '기준 상이'로 표시(가격 대조와 같은 구조).
- 판정(싸다/비싸다)은 종목 자신의 과거 분포 대비 위치로 계산하고, 증권사 PER은 대조·표시용으로 보조.
