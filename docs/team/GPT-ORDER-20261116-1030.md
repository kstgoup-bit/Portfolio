## 1. 목표와 사용자 체감
현재 위험관리 상단에 고정되어 큰 자리를 차지하는 "오늘의 투자 브리핑: 판단 보류 40 · 위험 1"과 긴 가격 신뢰도 띠를, 위험을 숨기지 않으면서도 핵심 후보를 즉시 볼 수 있는 **오늘의 투자 판단** 영역으로 정리한다.
- 첫 화면: **매수 검토 / 매도 검토 / 장기보유** 3종 카드(반응형)와 판단 보류·중요 위험 요약. 숫자는 실제로 확인된 분류만 집계하고 원인·기준일·검증 상태를 연결한다. 검증된 매수·매도 후보가 없으면 **0건**. 가상 수치나 예시 종목(AVGO/NVDA/MSFT 등)을 운영 데이터처럼 표시 금지.
- 상단 고정(sticky/fixed) 브리핑을 해제하여 화면 스크롤을 따라 자연스럽게 사라지게 한다. 기존 위험관리 탭/상단 네비게이션 및 투자 기능은 보존한다. 기본 본문은 간결하게.
- 매수 검토: **하락률만으로 승격 금지**. 신뢰 가능한 기업 재무·경쟁력·본질가치 대비 가격 매력·출처·기준시각 및 반론/제약 조건이 실제로 검증된 경우만 해당. 매도 검토: 고점 근접·상승률만으로 승격 금지. 근거(가치평가, 기업 논리 훼손, 집중 위험 등) 검증이 없는 경우 보류.
- **장기보유 후보**도 별도 상태로 제시하되, 관련 조건이 미검증일 때는 확정 명칭·적극 매수/매도 신호로 바꾸지 않는다. 추정/미검증은 '판단 보류'와 사유로 표시. 매수·매도 실행 게이트는 계속 닫는다.
- '가격 신뢰도: 미검증 가격·출처·기준시각 확인 필요' 경고 및 긴급 위험 알림을 **절대 삭제·은폐하지 않는다**. 상세는 접어도 중요 위험 여부/한 줄 요약은 항상 보이게 하고, 탭/접근성 사용자도 읽을 수 있게 한다.

## 2. 동작 — 같은 버튼으로 펼침과 접힘
'가격 신뢰도 안내', '오늘의 투자 판단(기존 브리핑)', '각 후보의 상세 근거'에 공통 패턴:
1) 처음 진입: 상세 기본 **접힘**, 의미 있는 한 줄 요약/경고/후보 집계는 보임.
2) **같은 버튼 1회 터치 → 상세 펼침, 다시 1회 터치 → 접힘**. 버튼 레이블 '펼치기'↔'접기', chevron 방향/aria-expanded 실시간 일치.
3) 다른 위험관리 하위 탭이나 상위 메뉴로 이동하면 열려 있던 상세는 닫히고, 다시 진입해도 기본 접힘. 뒤로가기·새로고침 등 기존 탐색 로직과 충돌 금지.
4) 버튼은 실제 시각적 버튼으로 보이고 키보드 Enter/Space, 스크린리더, 포커스·터치 동작이 동일. 카드 내부의 세부 링크/버튼을 누를 때 의도치 않게 다시 접히지 않게 한다.
5) 데이터 업데이트(가격/재무 조회 실패·완료) 중에도 펼침 상태와 이벤트가 꼬이지 않게 하고, 새로운 보류·위험 상태가 기존 카드에 정상 반영되게 한다.

## 3. 화면·데이터 범위와 금지
- 먼저 현재 코드에서 상단 띠·브리핑·위험관리 하위 탭 렌더 경로를 확인하여 기존 표시·경고·읽기 전용 데이터를 **재사용**하고, 수정 파일과 변경 전후 DOM 경로를 보고서에 명시한다. 독립 작업 브랜치 예: `work/claude-risk-briefing-20261116`; 기존 동일 주제 작업이 있으면 중복하지 않는다.
- 모바일 360/390/430px에서 하위 메뉴가 오른쪽으로 잘리거나 **가로 스크롤이 생기지 않도록** 화면 너비 내 줄바꿈/격자 재배치. 2행 이상은 허용하지만 핵심 탭 이름은 온전히 보여야 한다. PC도 동일 탐색과 접기 동작 제공.
- 모든 금액/비중·판단 수치는 사용자 보유 데이터 및 검증 출처/기준일을 임의 수정하거나, 과거 보고의 '판단 보류 40·위험 1'을 상수화하지 않는다. 가격 1차 선별은 '가격 위치'일 뿐 매수 검토 카운트가 아니다.
- 변경 허용: HTML/CSS/클라이언트 UI 렌더·접기 상태와 합성 시험만. `main` 병합·운영 배포·GAS 수정/배포·실제 API 키/주소 사용·비용·클라우드 생성·실제 투자기록 및 localStorage/백업 변경·자동매매/주문 금지. 필요한 외부 연동은 미완료로 명시.

## 4. 완료 조건과 증거
- 기존 기능의 회귀시험 + 분류별 합성 시나리오: ① 미검증 40·위험 1 같은 데이터에서도 매수·매도 후보 수 **0** ② 검증된 후보만 숫자 변경 ③ 고점/급락만으로 매도/매수 승격하지 않음 ④ 상품유형 불명·ETF/기업 간 분류·다계좌 충돌·시세 오류/오래됨은 보류 ⑤ 경고는 접힘 상태에서도 보임.
- 접기 상태 시험: **접힘→같은 버튼 펼침→같은 버튼 접힘** 2회 토글, 탭 이동 후 재진입 접힘, 모바일 터치·키보드·aria-expanded·초점, 조회 실패/갱신 후 재터치, 다른 영역 열고 닫기의 분리.
