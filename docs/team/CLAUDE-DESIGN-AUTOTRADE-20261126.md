# 자동매매 최종 목표 — 단계 계획·투자 원칙 초안 (문서만, 주문 코드 없음)

작성: 클로 · 2026-11-26 · 요청: 순태씨 "최종 목표는 클로와 지피가 스스로 매매하는 시스템. 전용 계좌에 돈을 넣어 줄 테니 둘이 상의해 투자 원칙을 세운 뒤 투자해 보라."
**현재 상태: 주문·자동매매 금지(협업 약속·예약 작업 금지 조항)는 그대로다.** 이 문서는 목표로 가는 길과 안전장치의 초안이며, 아래 각 단계의 시작은 순태씨의 명시 승인 + 지피 검토가 필요하다.

## 1. 전제(정직하게)
- 지금 시스템은 재무·시세 검증 연결이 메인에 반영되기 전이고, 밸류에이션 판정은 아직 없다. 매매 판단 근거가 갖춰지지 않았다.
- 실제 돈 투자는 손실이 날 수 있다. 클로·지피는 수익을 보장하지 못한다. 순태씨는 **잃어도 생활에 지장 없는 금액만** 전용 계좌에 넣는다(금액은 순태씨 결정).
- 증권사 API 키·계좌번호·토큰은 저장소·대화·로그에 두지 않는다(스크립트 속성·비밀 저장소만).

## 2. 단계(앞 단계 통과 기준을 충족해야 다음으로)
| 단계 | 내용 | 돈 | 통과 기준(초안) |
|---|---|---|---|
| 0 | 판단 근거 완성: 재무·시세 대조·밸류에이션·합의 | 없음 | 해당 기능 반영·실검증 |
| 1 | **모의매매**(가상 계좌, 주문 기록만): 원칙대로 매매했다면의 기록·성과 | 없음 | 최소 1~3개월, 원칙 위반 0, 기록 완전 |
| 2 | **소액 실전 + 사람 승인**: 클로·지피가 주문안을 내면 순태씨가 승인 후 주문 | 소액 | 승인 절차 오류 0, 손실 한도 준수 |
| 3 | **제한적 자동**: 사전 승인된 범위(종목·금액·횟수)에서만 자동 주문 | 한도 내 | 단계 2 성과·안전 기록, 순태씨 별도 승인 |
| 4 | 확대 | 순태씨 결정 | 별도 |

## 3. 투자 원칙 초안(지피와 상의해 확정, 순태씨 승인)
1. **하드 한도(코드로 강제)**: 1주문 최대 금액, 종목당 최대 비중, 하루 최대 주문 횟수, 월 최대 손실(도달하면 자동 중지).
2. **매매 조건**: 두 AI가 합의(agreed)하고, 재무 strong·시세 독립 대조 일치·밸류에이션 기준 충족일 때만. 의견 불일치·자료 부족·자료 오래됨이면 매매 안 함(기본값은 '안 함').
3. **금지**: 신용·레버리지·공매도·파생·야간 장외·소형주/유동성 낮은 종목(기준 별도). 순태씨 기존 보유 종목은 별도 계좌로 분리해 건드리지 않는다.
4. **긴급 정지**: 순태씨가 한 번에 모든 주문 권한을 끌 수 있는 스위치(앱·증권사 양쪽), 이상 징후(자료 오류·연속 오류·한도 근접) 시 자동 정지.
5. **기록·검토**: 모든 판단 근거·주문안·체결을 변경 불가 기록으로 남기고, 월 1회 성과·원칙 위반 검토를 순태씨에게 보고.
6. **원칙 변경은 순태씨 승인 후에만**, 거래 중 AI가 임의로 원칙을 바꾸지 않는다.

## 4. 기술·운영 과제(미해결)
- 주문 API(KIS 모의/실전 분리) 공식 명세·약관 확인(자동매매 허용 범위), 주문 오류·부분 체결·정정 처리.
- 키 보관: GAS 스크립트 속성 또는 별도 서버 — 보안 설계 필요(유출 시 피해 최소화: 출금 불가·주문 한도).
- 지연·휴장·서머타임·시세 오류 대응, 이중 주문 방지(멱등성).
- 세금·규제·신고 의무 검토(순태씨 확인 필요, 클로는 법률·세무 자문 불가).

## 5. 다음 행동(승인 필요 없는 것만)

3. 순태씨 결정 필요: ① 전용 계좌 금액 규모 ② 허용 시장(미국/한국) ③ 월 최대 손실 한도 ④ 단계 1(모의매매) 시작 승인 시점.
