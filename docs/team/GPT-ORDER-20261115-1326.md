## 1. 사용자 결정과 목표
사용자는 HAS의 투자 철학 **"곡소리에 분할매수, 환호에 분할매도, 위대한 기업은 오래 보유"**를 화면에 반영할 **'위대한 기업' 탭 신설**을 원하며 클로에게 전달할 지시서 작성을 요청했다. 이 ORDER는 그 신규 기능의 독립 개발 1단계에 대한 명시적 전달이다.

세 탭의 목적을 구분한다.
- 곡소리: 가치와 경쟁력이 유지된 기업을 합리적인 가격에 분할매수할 기회 분석(급락만으로 매수 권고 금지).
- 환호성: 고평가·과열·포트폴리오 집중을 고려한 분할매도/비중 조절 검토(급등만으로 매도 권고 금지).
- 위대한 기업: 5~10년 경쟁력·현금창출·자본배분을 평가하며 **보유할 이유와 보유 논리 훼손 신호**를 지속 검증. 과잉 매매를 막되 무조건 보유도 금지.

최종 투자판단과 주문은 사용자만 한다. 점수·AI 의견은 의사결정 보조이며 자동매매·확정 추천은 금지한다.

## 3. 이번 승인 범위 (독립 1단계)
1) 현재 HAS UI 탭 구조, 종목·가격·재무 데이터 계약, 기업가치/재무 필터, 레이더, 모바일 성능, 회귀시험 체계를 조사하여 **연동 설계 문서** 작성.
2) 아래 여섯 관점으로 **순수 평가 엔진**의 데이터 계약과 판단 상태를 정의. 합성 입력만으로 동작하며 외부 API 호출·영구 저장·계좌 기록 변경이 없어야 한다.
   - 지속 경쟁우위(기술·브랜드·전환비용·네트워크·진입장벽)
   - 장기 성장·잉여현금흐름
   - 수익성·ROIC·자본효율
   - 부채·유동성·재무안정
   - 경영진·자본배분의 질
   - 5~10년 지속 가능성 및 경쟁우위 훼손 위험
3) 상태는 **장기보유 우선 검토 / 경쟁력 재점검 / 보유 논리 훼손 우려 / 판단 보류**로 정의하되, 판정마다 찬성 근거·반대 근거·자료 출처·기준일·누락/충돌/불확실성을 남긴다. 정량 점수는 보조치로만 사용하며 산식·가중치·미검증 영역은 노출한다. 정성 근거가 미검증이면 '위대한 기업 확정' 금지. 데이터 신선도·출처 충돌 시 fail-closed(판단 보류).
4) 곡소리/환호성 판단과의 관계를 **데이터 계약 및 합성 시나리오**로 정의. 급락해도 경쟁력 훼손 시 매수 후보 확정 금지, 급등해도 장기 경쟁력 유지 시 일률 매도 금지, 경쟁력 훼손 시 주가가 오르더라도 별도 경고한다.
5) 모바일/PC **시험 전용 UI 프로토타입**을 독립 경로·게이트에만 만든다(실제 `portfolio_v5.html` 메뉴에 연결 금지). 기업명·티커, 평가 상태, 6영역, 보유 근거·위험·변경사항·출처·기준일·관련 가격 신호를 간결하게 표시. 합성 데이터는 '가상 자료'를 명확히 표기한다. 실제 보유 정보는 읽거나 수정하지 않는다.
6) 탭 최초 진입에만 필요한 기능을 지연 로딩하는 설계와 기존 분석 결과 재사용·기준일 검증을 제안한다. 로그인 초기 로딩과 400종목 전체 분석을 건드리지 않는다.
