## 작업 범위
1. 기존 `work/claude-universe-screen-20261112` **같은 브랜치**에서 계속 작업. 다비가 만든 `gas/has-universe-screen.gs` 및 `has/universe-screen.js`, 기존 합성 단위시험과 `tests/lib/no-network.cjs` 먼저 검사. 중복 모듈 `gas/has-screen.gs`를 임의로 새로 만들지 말고 현재 코드와 일지 명칭의 차이를 문서로 정리한다.
2. 진짜 편입종목으로 오인할 수 없는 **합성 200KR+200US 시험 구성목록**을 임시 테스트 픽스처에서만 생성(파일명·메타데이터에 synthetic/test-only 명시). `radar/data/universe-400.json`은 공식 원본이 확보되기 전까지 생성하지 않는다.
3. GAS Apps Script에 올리는 대신 **저장소 코드에만** 저장·응답 계약 초안 보완. 12개 이하 묶음, 실행시간 6분 한계 고려, 작업 중단/재개, 8KB 수준 Property 분할 저장과 읽기 시 무결성, HEAD 마지막 교체, 실패 시 이전 공개 결과 유지, 갱신 자료 기준일의 만료·시장 구분을 합성 데이터로 검증.
4. `type=screen` JSONP가 실제 기존 GAS 응답 기능과 충돌하지 않도록 설계 및 테스트로만 확인(운영 라우터/doGet 변경 금지). 공개 응답에 비밀키·사용자 계좌·확신/보유 종목 정보 없음. callback 검증, 과대 응답 및 손상된 스냅샷 차단, 이전/미완료 세대 처리 검증.
5. 기존 가격 분석 경로와 기준시각·종가·통화·가격종류·조정기준 불일치 시 후보 판정 보류. 단기 고점 낙폭은 '가격 위치'일 뿐 매수 권고 아님; 재무 연결 전 `판단 보류`. 12개월 수익률은 유효한 조정 가격/기준점이 없다면 null 유지.
6. 선택적으로 `tests/`에서 합성 테스트 및 검증 도구를 수정. 앱 파일 변경이 불가피하면 작업 목적을 좁혀 진행하고 `tests/lib/live-data-edits.json`의 역방향 쌍 및 `tests/lib/live-data-pins.json` 갱신. 이번 단위에서는 UI 기능 추가·운영 파일/실제 백업 수정은 하지 않는다.
