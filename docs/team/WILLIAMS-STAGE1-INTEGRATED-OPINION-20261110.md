# 래리 윌리엄스 전략 연구 1단계 — 종합 의견서 (지피 지시서 + 클로 의견)

작성: 클로 / 2026-11-10 / 대상: 다비(메인 개발), 순태씨
기준 문서: `HAS_Larry_Williams_Research_Stage1_20261110.md` (이하 '지시서'. 순태씨가 전달. 지피 안으로 이해하고 정리함 — 작성자가 다르면 정정)

## 1. 한 줄 결론
지시서는 철학·안전 규칙에 합치하며 **연구/오프라인 시험 단계로 진행 가능**. 단, 착수 전 ① 데이터 범위 부족 ② 종목 선정 편향 ③ 평가 1순위 지표 부재 세 가지를 보완해야 결과가 의미를 갖는다. 실거래 신호 노출·운영 반영은 이번 범위 밖.

## 2. 지피 안(지시서) 요약
- 목적: 우량기업 보유 수량·장기 자산 증대에 도움이 되는지 **사후 검증**. 기술적 과매도 ≠ 기업 저평가, 주가 하락만으로 매수 금지.
- 대상: A Williams %R(14) / B 변동성 돌파 / C 가격 패턴·추세 확인 / D COT·계절성(별도 후보).
- 백테스트: MSFT·GOOGL·NVDA·AVGO + 미국 지수 ETF, 비교군(보유·적립식·기존 HAS·Williams 단독·HAS+Williams), 동일 원금·비용·세금 시나리오, 훈련/검증/최종 테스트 분리, 워크포워드·민감도.
- 안전: 별도 브랜치, main 병합·운영 배포·실키·자동매매·유료서비스 금지, 성과 수치는 실데이터 확보 전 주장 금지.

## 3. 클로 의견
### 3-1. 동의
- 철학 합치(보조 증거, 최종 결정 사용자). %R 공식 (HH−Close)/(HH−LL)×(−100) 정확. 분모 0 결측, 미래 정보 누수 금지, 윌리엄스 원전 규칙과 HAS 제안 조합의 구분 요구에 동의.
### 3-2. 보완 요청 (착수 전)
1. **데이터 부족**: 현재 확보 경로(순태씨 GAS `type=history`)는 **일별 종가만, 약 1년**. %R은 고가·저가, 변동성 돌파는 시가·고가·저가 필요. 백테스트는 최소 5~10년 OHLCV(분할·배당 조정 여부 명시) 필요. 출처 후보(공식 API·무료 CSV 등)와 이용 권리 확인이 **1단계 관문**. 확보 전에는 계산 모듈·단위시험·설계까지만 수행. (GAS 이력은 비공식 Yahoo, 조정 미검증)
2. **종목 선정 편향**: MSFT/GOOGL/NVDA/AVGO는 사후 승자 → 보유 전략이 구조적으로 유리. 지수 ETF 외에 (a) 2022 같은 하락 국면 포함, (b) 같은 업종의 부진 종목 대조군, (c) 무작위 진입일 대조(신호가 무작위보다 나은지)를 필수화.
3. **평가 1순위 지표**: 철학상 1순위는 **동일 외부 현금흐름에서의 최종 보유 수량과 평균 매수단가**(보조: 최대낙폭, 비용 후 성과, CAGR·샤프). 지시서 평가 항목에 우선순위 부여.
### 3-3. 원전 확인 필요 (단정 금지)
- 변동성 돌파 계수(국내에서 흔히 0.5)가 윌리엄스 원전 값과 같은지 **미확인**. 확인 전 '윌리엄스 규칙'으로 표기 금지(제안값은 '가설'로). 변동성 돌파는 단기 회전매매이므로 별도 실험군, 장기 보유 로직과 분리.
- COT·계절성은 지시서대로 개별종목 신호로 치환하지 말고 별도 후보.
### 3-4. 판정 제안 (결과 전 잠정)
| 항목 | 잠정 판정 |
|---|---|
| %R 계산 모듈·시험 | 진행 |
| %R을 보조 증거로만 사용(단독 매수 금지) | 철학 합치, 검증 후 도입 여부 결정 |
| 변동성 돌파 | 별도 실험군, 보류 |
| COT·계절성 | 데이터 검토 후 별도 후보 |
| 실거래 신호 노출 | 이번 단계 제외 |

## 4. 작업 순서 제안 (충돌 방지)

2. **그다음**: 윌리엄스 1단계. 착수 보고에 현재 원격 브랜치·커밋·기능 인벤토리 포함(지시서 5-1).
3. 역할: 다비=구현, 클로=독립 검증(%R 손계산 정답 벡터, 분모0·결측·분할·시차·누수 시험, 원전 확인, 사양서 검토).
