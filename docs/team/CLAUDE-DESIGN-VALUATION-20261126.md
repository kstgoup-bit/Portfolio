# 밸류에이션(싸다/비싸다) 판정 설계 — 초안 (코드 없음, 승인 전)

작성: 클로 · 2026-11-26 · 상태: 설계 초안. 앱 코드·카드 라벨은 이 문서 승인 + 지피 검토 + 순태씨 "올려" 전까지 바꾸지 않음.

## 1. 순태씨 요청(2026-11-26)
- 좋은 회사를 비싸게 사면 의미가 없으니 밸류에이션도 확인한다.
- 순태씨가 판단할 수 있게 "애매·중립" 표현 대신 **싸다/비싸다, 살 때다/팔 때다**처럼 분명히 알려 달라. 검토는 클로·지피가 하고, 순태씨에게는 **매수 검토 / 매수 / 강력 매수** 같은 단계로 보여 달라.
- 주문·자동매매는 계속 금지(판정 표시만, 최종 결정·주문은 순태씨).

## 2. 원칙(분명한 말 + 근거·한계 동시 표시)
분명한 단계 표시는 가능하다. 다만 아래를 지킨다.
1. **단계는 근거가 갖춰졌을 때만 올라간다.** 근거(재무·시세·밸류에이션·두 AI 합의)가 하나라도 빠지면 그 단계 이상으로 표시하지 않고, 무엇이 빠졌는지 한 줄로 적는다. 말투가 분명해도 근거가 비면 단계는 낮게 둔다.
2. **단계마다 한 줄 이유 + 한 줄 반대 근거**를 같이 보여 준다(순태씨가 판단할 재료).
3. **미검증 데이터로 '강력 매수'는 불가.** 강력 매수는 가장 높은 근거 조건에서만.
4. 기존 안전 규칙 유지: 주문 없음, 투자 권유 아님 문구, 지피 합의 7일 유효, 의견 불일치면 단계 올리지 않음.

## 3. 제안 단계(라벨 문구는 승인 후 확정)
| 단계 | 의미 | 올라가는 조건(모두) |
|---|---|---|
| 관망 | 지금은 살 이유 부족 | 기본 |
| 매수 검토 | 사도 되는지 들여다볼 가치 | 재무 strong, 시세 독립 대조 일치 |
| 매수 | 가격이 매력적 | 위 + 밸류에이션 "싸다" + 클로·지피 합의(agreed) |
| 강력 매수 | 근거가 가장 두껍다 | 위 + 밸류에이션 "아주 싸다" + 이익 안정(과거 이익 급락 이력 없음) + 합의 + 시세 최신 |
| 비싸다/매도 검토 | 보유·후보가 비싸다 | 밸류에이션 "비싸다" 이상 (보유 종목에는 '비중 축소 검토') |
※ 현재 카드의 '🧠 판단 보류(재무·시세 검증 전)'는 재무·시세 연결이 메인에 반영되고 순태씨가 라벨 변경을 승인할 때까지 유지.

## 4. 밸류에이션 계산(1단계: 가진 자료)
- 지표: PER, PSR, FCF 수익률(영업현금흐름−투자지출 ÷ 시가총액). 시총 = 검증된 종가 × 발행주식 수.
- 판정 기준: **그 종목 자신의 과거 분포 대비 위치**(예: 분위). 업종 평균은 신뢰 자료 확보 전 미사용.
- 구간(초안, 미검증 제안값): 하위 20% '싸다' · 하위 10% '아주 싸다' · 상위 20% '비싸다' · 상위 10% '아주 비싸다' · 그 사이 '보통'.
- 근거 기간 3년 미만이면 '판정 불가'로 두고 단계를 올리지 않는다.

## 5. 먼저 해결할 데이터 공백(정직하게)
- 현재 수집 자료(data/fundamentals)에는 **발행주식 수가 없다**. → 수집기에 주식 수(공시 표지의 발행주식 수, 희석 가중평균 주식 수) 추가 필요.
- **연간 자료뿐**이라 최근 12개월(TTM) 기준이 아니다. 분기 수집 추가가 필요하며, 그 전엔 "마지막 결산 기준"으로 표시.
- 과거 **주가 이력**은 Yahoo 이력(검증된 종가)으로 가능하나 장기(3~5년) 일봉 분위 계산은 호출량·형식 검증 필요.
- 이익 전망(선행 PER)·동종 비교는 무료로 믿을 만한 출처 미확인 → 조사 후 결정, 확인 전에는 만들지 않는다.

## 6. 위험 요소와 대응
- **경기 민감주(WDC·GLW·ALAB 등)**: 이익 정점에서 PER이 낮아 '싸 보이는' 착시. 이익이 한 번 꺾인 이력이 있으면 '싸다'를 한 단계 낮추고 경고 표시.
- **적자·이익 급변 종목**: PER 의미 없음 → PSR·FCF로만, 둘 다 불가면 '판정 불가'.
- **성장주(NVDA·ARM 등)**: 과거 분포가 현재를 설명 못 할 수 있음 → '평소 대비' 표현과 한계 문구를 붙인다.
- **강한 말투의 부작용**: 단계가 곧 매매 지시로 읽히는 것 → 이유·반대 근거 병기, 최종 결정은 순태씨, 주문 기능 없음 문구 유지.

## 7. 구현 순서(제안, 각 단계 지피 검토 + "올려")
1. 수집기에 주식 수·분기 자료 추가(data/fundamentals 스키마 확장, 기존 판정 영향 없음).
2. `has/valuation-v1.js` 순수 계산 모듈 + 시험(외부 접속 없음).
3. 카드 표시(근거·반대 근거 포함) — 라벨은 아직 판단 보류.
4. 단계 라벨(관망/매수 검토/매수/강력 매수) 도입 — **순태씨 승인 + 지피 검토 별도**.

## 8. 순태씨 결정(2026-11-26 승인: 단계 이름·구간 20%/10%·보유 종목 비중 축소 검토 표시 모두 제안대로)
※ 승인은 설계 방향이며 코드·카드 라벨 변경 승인이 아님.

## 9. 확인 방법 조사
증권사(KIS) PER·PBR 필드를 독립 대조용으로 쓰는 안을 조사 중. 후보·미검증 사항은 docs/team/CLAUDE-ASK-GPT-VALUATION-SOURCES-20261126.md 참고.
