# 실제 GAS 시세 응답 표본과 의미 (클로 → 다비, 2026-11-09)

순태씨가 폰에서 직접 GAS 웹앱을 호출해 복사해 준 **실제 응답 3건**이다(주소·키는 받지 않았다). 호출 형식은 앱 코드의 fetchKR/fetchUS/fetchFX와 같다.

| 요청 | 응답(원문) |
|---|---|
| `?tickers=005930&market=KR&callback=test` | `test({"005930":187000})` |
| `?tickers=QQQ&market=US&callback=test` | `test({"QQQ":671.1})` |
| `?type=exchange&callback=test` | `test({"usdKrw":1346})` |

(JSONP 한 겹을 벗기면 순수 JSON. 가격 숫자가 실제 시장가와 일치하는지는 이번에 대조하지 않았다.)

## 확인된 사실
- 응답은 **종목코드 → 가격 숫자 하나**뿐이다. 환율은 `usdKrw` 숫자 하나.
- **없는 것**: 기준시각, 거래일, 거래소, 통화, 가격 종류(종가/현재가/지연), 가격 조정 기준, 출처 이름, 52주 고점, 기간 수익률, 일별 가격, 거래량, 오류·결측 표시 방식.
- 앱은 `data[ticker]`를 **숫자로 바로 읽는다**(portfolio_v5.html fetchUS/fetchKR). 응답 모양을 객체로 바꾸면 기존 앱의 가격 갱신이 깨진다.

## 계약에 대한 의미
1. 다비의 종가 비교(close-comparison)·증거 연결(advisor-evidence)이 요구하는 거래일·가격 종류·출처 선언을 **GAS 응답만으로는 채울 수 없다.** 어댑터가 상수로 선언하면 엄격한 검사가 형식만 남는다(지난 종가 검토 지적 2와 같은 문제). 실제 GAS 값은 지금처럼 '미검증 단일 출처'로만 쓴다.
2. 곡소리·환호성 판단(기업가치 대비 괴리)에 필요한 52주 고점·기간 수익률·재무는 GAS에 없으므로 **별도 자료 경로가 필요**하다.

## 경로 후보와 제약
- **A. GAS에 새 요청 종류 추가**(예: `?type=history&tickers=...`로 일별 종가 배열과 기준일). **기존 요청의 응답 모양은 절대 바꾸지 않는다**(앱 호환). 순태씨의 GAS 코드 수정이 필요하고, 코드는 비밀 줄을 지운 뒤 확인해야 한다. 가격 출처(구글파이낸스 등)의 제공 범위와 약관 확인이 먼저다.
- **B. KIS 일봉 사용.** 약관·토큰 제한·해외 지연 여부가 미확인이고, 실전 키 사용은 순태씨 승인(B, C) 후다. GAS 중계 방식이면 키는 GAS 속성에만 둔다.
- A와 B를 함께 쓰면 독립 출처 교차검증도 가능해진다(원천 독립성은 별도 확인).

## 요청
- 다비: 위 표본을 어댑터 입력 계약의 현실 제약으로 반영(필드가 없을 때 판단 보류가 되는 경로 문서화, 기존 응답 호환 유지 원칙).
- 클로: 순태씨 승인 후 GAS 새 요청 종류 초안(키 없이)과 호환 시험.
- 순태씨: 경로 A·B 중 방향 결정, GAS 코드 확인 허용 여부.

## 상태
실제 키·실전 호출·클라우드 변경 없음. 순태씨가 직접 호출한 응답 3건만 사용. 승인 A~E 미승인.
