## 3. 수정 요청 — 입력 행이 부분적으로 채워졌을 때 계산 자료에서 조용히 삭제됨 (중요)
**문제 A — 부분 작성한 보유자산의 누락으로 비중·집중도가 왜곡될 수 있음.**
- `has/capital-allocation-lab.js`의 `buildInput()`에서 `holdings: (v.holdings || []).filter(h => !blank(h.symbol))`로 **종목명만 비어 있으면 수량·평균단가·평가가격이 입력돼도 행 전체를 삭제**한다. 예: 기본 합성 입력에 두 번째 보유 줄의 종목명만 빈칸으로 두고 수량 10, 평가가격 100을 입력하면 그 자산 1,000 USD가 분모에서 누락될 수 있는데, 엔진에는 그 불완전 행이 전달되지 않아 유효한 대안처럼 계산할 수 있다.
- 같은 문제가 `candidates: ...filter(c => !blank(c.symbol))`에서도 발생한다. 가격이나 업종이 입력된 후보가 종목명 누락으로 조용히 제외돼 사용자가 기대한 대안 구성과 출력이 달라질 수 있다.
- **수정 기준**: 모든 필드가 빈 선택 행만 건너뛰고, 수량·가격·평균단가·업종·확신 등 어느 하나라도 사용자가 입력했는데 종목명이 비어 있는 경우에는 `HOLD_INSUFFICIENT_DATA` 및 문제 행 번호·누락된 항목을 표시한다. 미완성 행을 임의로 제외한 성공 결과는 금지한다. UI 자체에서 검증해도 되고 엔진 계약에 명시적 검증 실패를 안전하게 전달해도 된다.

**문제 B — '첫 줄=매도 종목' 규칙이 빈 첫 줄에서 암묵적으로 바뀜.**
- `var main = input.holdings[0];`로 **필터링 후 첫 번째** 종목을 매도 대상으로 자동 설정한다. 첫 줄을 비우고 둘째 줄에 종목을 입력하면 원래 '첫 줄이 매도할 종목'이라고 안내한 UI와 달리 둘째 줄의 종목이 매도 대상으로 바뀔 수 있다.
- **수정 기준**: 매도 대상은 원본 첫 줄에 고정하거나 매도 종목을 명시적으로 선택하게 변경한다. 첫 줄이 비어 있는데 다른 줄이 입력·매도 수량이 존재하면 `HOLD_INSUFFICIENT_DATA`로 멈추고 사용자가 보완하도록 안내한다. 어떤 종목을 판다고 자동 추정하면 안 된다.

**필수 회귀시험** (`tests/capital-allocation-lab.test.cjs`에 추가):
1. 보유 2번 줄에서 종목명만 빈칸, 수량/가격 입력 → 성공 대안 0개, 추가 정보 필요 및 행 번호.
2. 후보 줄에서 종목명 빈칸, 가격/업종 입력 → 조용한 제외 없이 추가 정보 필요.
3. 첫 보유 줄을 비우고 둘째 줄에 종목을 채운 상태에서 매도 입력 → 매도 종목 자동 전환 없이 보류.
4. **완전 빈** 선택 행은 기존처럼 허용, 기존 기본 합성 픽스처 결과·이전 7개 대안 회귀 유지. 기존 2011건 포함 전체시험/게이트 ON·OFF·오프라인/비밀값/모바일 폭 재시험 후 수치 보고.
