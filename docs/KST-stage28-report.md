# HAS 28단계 — 기존 GAS 시세에 "이번 접속 갱신 시각" 표시 (KIS 중계 서버 대체)

순태씨, 새 계정·키·서버 없이 지금 쓰는 Apps Script(GAS) 시세를 그대로 쓰고, AI 참모가 "얼마나 최근 값인지"만 표시하도록 했습니다.

## 바뀐 것
- `portfolio_v5.html` 5곳: 국내·미국·환율을 GAS로 받은 시각을 메모리(`quoteMeta`)에만 기록(저장·백업 안 함). 시세 받는 방식·화면은 그대로.
- `has/portfolio-reader.js`: 시각을 읽어 `priceFreshness`(갱신 종목 수·갱신 안 된 종목·시각) 계산. 읽기 전용.
- `has/briefing-model.js`: 위험 항목 문구 — "보유 N종목 전부/일부 이번 접속에서 구글 시트(GAS)로 갱신(HH:MM KST) … 단일 출처·가격 종류 미확인·독립 대조 불가", 환율 갱신 여부 포함. 갱신 기록이 없으면 "저장값(오래됐는지 알 수 없음)".
- 예수금 안내가 두 번 나오던 중복(26단계 때 생김) 제거.

## 바뀌지 않은 것
- 시세는 여전히 **미검증·단일 출처**. 의견은 기존 규칙대로 보수적(독립 대조 없으면 판단 보류). 시각 표시가 신뢰도를 올려주지 않습니다.
- 가격 종류(실시간/지연/종가)는 GAS가 알려주지 않아 알 수 없음. GAS 내부 코드는 확인하지 못함.

- 실제 GAS·실기기에서는 확인하지 못했습니다(가짜 응답 시험).
