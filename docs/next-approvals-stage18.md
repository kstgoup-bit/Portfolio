# 다음 단계에서 순태씨가 독립적으로 승인할 항목 (가~마) — 모두 현재 미승인·미실행

| 항목 | 내용 | 위험 | 비용 | 복구 |
|---|---|---|---|---|
| (가) 영구 원장 저장·백업 확장 | `has_ledger_v1` 저장, 백업 v6에 선택 필드 추가 | 구/신 버전 복원 호환, 기록 손상 | 0원 | 시험 사본에서 먼저, 롤백=키 삭제+원본 백업 복원 |
| (나) 실제 감시 확대 | 5종목 → 더 많은 종목 실조회·감시 | 약관·한도 초과, 오래된 가격 오인 | 무료 한도 내 0원 | 감시 끄기(기본 꺼짐) |
| (다) 합법 실데이터 백테스트 | 사용권 확인된 과거 데이터로 시험 | 사용권 위반, 생존편향 | 공급자별 | 결과 폐기, 합성 표시로 복귀 |
| (라) 키 관리 변경 | 기존 localStorage 키 보관·기본 비밀번호 개선 | 잘못 바꾸면 잠금/키 유실 | 0원(서버 없이) | 변경 전 백업, 단계별 적용 |
| (마) 운영 배포 | HAS 이름·신기능을 실제 주소에 올림 | 설치 앱 캐시 혼선, 데이터 영향 | 0원(호스팅 이미 있다면) | 이전 커밋으로 되돌림(데이터 키 불변) |
선행 결정: 파일럿 호출을 하려면 순태씨가 ① 공급자 가입·약관 확인 ② 승인 파일 작성이 먼저입니다(`docs/pilot-runner-guide-stage18.md`).
