## 수정한 결함
이전 core는 단 하나의 미지원 종목코드가 섞여도 `invalid-symbols`로 전체를 거부했다. 이제 요청을 지원/미지원 항목으로 나눠 유효 종목만 공급자에 보내며, 미지원 항목은 `status: unsupported`, `signalHold: true`로 별도 반환한다.

- 유효종목의 조회와 당일 캐시는 유지된다.
- 미지원 코드·null·getter 객체는 요청하지 않는다. getter도 실행하지 않는다.
- 일부 미지원이면 상단 부분상태와 해당 종목의 “시세 조회 미지원” 안내를 표시한다.
- 미지원 항목이 전부여도 외부 요청 없이 명확한 실패 상태를 반환한다.
- 보유기록·계좌·백업 데이터는 수정하지 않는다.
