## 5. 작업 C — KST '환호성 매도 레이더' 설계와 분리된 합성 시험

실제 투자 판단으로 오인되지 않도록 **설계·순수 함수·합성 시험 중심**으로 개발한다. 매도 기능은 매수 레이더의 100점 배점·기존 신호를 변경하지 않고 독립 모듈로 둔다.

- **고평가 경고**: 단순 수익률보다 현재 밸류에이션과 과거 범위·성장률·현금흐름·전망의 괴리를 우선한다. 근거 부족 시 '평가 불가'.
- **투자 논리 훼손**: 경쟁력, 실적, 현금흐름, 부채, 시장점유율의 구조적 악화 여부를 근거·기준일과 함께 표시한다. 단기 주가 하락만으로 훼손 확정 금지.
- **포트폴리오 집중 위험**: 계좌·종목·업종 집중도와 사전 설정한 한도를 비교하되, 실제 보유 수량·금액은 사용자의 브라우저 밖으로 전송하지 않는다.
- **교체 매매 검토**: 대안 종목의 질·가격·세금·거래비용·현금 필요성을 비교한다. 단순히 더 많이 떨어졌다는 이유로 교체 권고 금지.
- **수익률 +20~30%, +50%, +100%, +200%**는 자동매도 트리거가 아닌 *검토 알림 예시*로만 취급한다. 강제 매도·자동 주문·목표가 단정 금지.
- 연금 장기 코어와 해외 직투 새틀라이트는 별도 설정·위험 한도를 지원하는 설계안을 제시하되 사용자 승인 전 기본 매매 행동을 변경하지 않는다.
- 결과 상태 예: `장기 보유 검토 / 비중 점검 / 일부 매도 검토 / 투자 논리 훼손 재검토 / 평가 불가`. 각 상태의 증거, 결측, 반대 근거, 계산식을 설명 가능하게 한다.
- 보유 종목의 실제 매도 신호가 발생했다고 주장하지 말 것. 실제 데이터 미연결 시 화면은 '설계/합성 데모'로 표시한다.
