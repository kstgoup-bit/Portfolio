## 9. 보안·비용·약관 미확인 사항
- KIS 시세 엔드포인트·tr_id·필드는 비공식 자료 기반, 공식 문서 대조 필요
- 토큰 발급 횟수 제한은 비공식 블로그만 근거
- 호출 한도는 공식 FAQ(2022) 초당 10건, 현재 유효성 미확인
- 실전 키는 주문 권한이 있어 중계 코드는 시세 경로 한정 필요. 별도 소액·시세 전용 계좌 가능 여부 KIS 문의 필요
- 약관상 제3자 제공/중계 허용 범위(개인용 한정) 해석 미확정, IP/주문 제한 기능 유무 미확인
- 클라우드 중계 비용 0원 가정은 미검증. 앱 종료 시 알림은 별도 푸시 인프라 필요
