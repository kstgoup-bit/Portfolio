# 갤럭시 실기기 5~10분 점검표 (순태씨가 직접 확인)

**상태: 전부 미실시.** 개발환경에는 갤럭시 실기기가 없어 헤드리스 브라우저 자동시험(360/390/430px, 가로, 200% 글자, 오프라인, 뒤로가기)만 했고, 실기기 통과를 주장하지 않습니다. 점검 전 **운영 앱의 백업 파일을 먼저 내려받아 두세요.**

| # | 확인 (운영 앱 = 홈 화면 KST) | 방법 | 결과 |
|---|---|---|---|
| 1 | 홈 화면 실행 | 아이콘으로 실행, 전체 화면 표시 | 미실시 |
| 2 | 글자 확대 | 설정 > 디스플레이 > 글자 크기를 가장 크게 → 투자현황이 잘리거나 겹치지 않는지 | 미실시 |
| 3 | 화면 회전 | 가로/세로 전환 시 입력 중 값이 유지되는지 | 미실시 |
| 4 | 뒤로가기 | 탭 이동 후 시스템 뒤로가기가 앱을 갑자기 닫지 않는지 | 미실시 |
| 5 | 오프라인 | 비행기 모드에서 앱 열기·종목 확인 | 미실시 |
| 6 | 앱 재시작 | 최근 앱에서 스와이프 종료 후 재실행, 기록 유지 | 미실시 |
| 7 | 백업·복원 | 백업 저장 → (테스트 브라우저 프로필에서) 복원 미리보기·되돌리기 | 미실시 |
| 8 | 터치 | 버튼이 너무 작아 잘못 눌리지 않는지, 두 번 눌러도 중복 저장 없는지 | 미실시 |
| 9 | 상태 표시 | 종목 검증 상태·시세 기준일이 읽히는지(12px 이상, 어두운 글자) | 미실시 |
| 10 | (선택) 시험 화면 | `mobile-lab/index.html`을 파일 앱에서 열어 조회 흐름·오류 안내 확인 | 미실시 |
