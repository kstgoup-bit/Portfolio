# 시세 공급자 파일럿 계획 (13단계)

확인일 **2026-10-29**, 공식 페이지 열람만 했고 가입·결제·키 발급·시세 API 요청은 **0건**입니다. 12단계 비교표(`provider-selection-stage12.md`)가 기준이며, 이번 단계에서 추가·확정한 것만 적습니다.

## 13단계 추가 확인 (Twelve Data, 미국 1순위)
- 일봉(`time_series`)은 시가·고가·저가·종가·거래량과 `adjust`(all/splits/dividends/none) 옵션, 거래소 시간대(`exchange_timezone`)를 제공합니다.
- `/splits`·`/dividends`는 각 20 크레딧(Grow 이상), `/exchange_schedule`(휴장일)은 100 크레딧이며 **Ultra 이상만** → Grow 기준 **휴장일 목록은 호출자가 직접 공급**해야 합니다(코드는 `holidays` 인자로 받음).
- 일봉 응답이 "수정/비수정"을 필드로 알려주지 않으므로 매퍼는 **요청한 `adjust` 값**을 그대로 믿습니다. 실응답으로 확인하기 전에는 미확정입니다.
- 개인 사용 문구는 요금표의 "personal, internal, non-commercial". **본인 화면 표시 권리는 여전히 불명확**(Basic은 "내부·비표시")입니다.

## 한국
- 금융위 주식시세정보(공공데이터포털 15094808)는 무료·T+1·공공누리 4유형이나, 페이지에 **필드별 스키마가 보이지 않아** 이번 단계에서도 매퍼를 만들지 않았습니다(추측 금지). 수정주가 언급 없음 → 분할 구간에서는 52주 고가를 거부합니다.
- ETF는 별도 API(15094806, `getETFPriceInfo_V2`)로 개별주와 구분해야 합니다.

## 코드로 구현·시험된 안전장치 (합성 fixture 전용)
`kr-radar/provider.js`(기본 OFF, transport 미주입 시 호출 0, 호출 상한, 주문 기능 없음), `kr-radar/pricefeed.js`(기준일·시간대 경계·주말/휴장일·수정/비수정 혼합·분할·거래정지/상장폐지·누락봉·오래된 봉·이중 공급자 차이·환율·ETF/개별주 구분). 데이터가 부족하면 `DATA_UNAVAILABLE`/`HOLD`이며 52주 고가나 점수를 만들지 않습니다. 신호 점수에는 항상 **"백테스트 미검증 가설"** 라벨이 붙습니다.

## 실제 조회 전 최소 승인 (사용자)
1. 한국 신원 검증 실조회 승인(별도) → VERIFIED 산정.
2. 미국 시세 공급자 약관·표시 권리 확인과 유료 플랜 여부 결정(가입은 순태씨가 직접).
3. 수정주가 기준(`adjust`) 확정, 휴장일 목록 출처 결정.
