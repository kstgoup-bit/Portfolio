## 3. B. 읽기 전용 시범 원장
- 위치: 실제 앱 → 🛡️ 위험관리 → 🧪 원장 시범. 주소 `#has-ledger-demo`. 뒤로가기 버튼과 휴대폰 뒤로가기 모두 이전 화면으로 복귀.
- 화면 맨 위와 합계 근처에 `시범 화면 · 합성 데이터 · 실제 보유·수익 아님`. 실제 보유·가계부는 읽지 않는다(코드 정적 검사로 저장소·네트워크·타이머 접근 0 확인).
- 입력은 화면 메모리에만 있으며 새로고침하면 사라진다고 화면에 표시.
- 계산 규칙: 이동평균 원가(원화), 매수 수수료는 원가에 포함, 매도 수수료·세금은 매도대금에서 차감, 해외는 거래별 환율 입력, 배당은 원천징수 차감 후 환율 적용. 반올림은 표시 때만(원 단위).
- **합성 결과 대조표** (엔진 `invest/ledger.js`와 손계산 일치):

| 계좌 | 보유수량 | 평균단가 | 남은 원가 | 실현손익 | 배당(세후) | 수수료 | 세금 |
|---|---|---|---|---|---|---|---|
| SYN-A(일반) | 15 | 11,010원 | 165,150원 | 9,880원 | 2,538원 | 250원 | 20원 |
| SYN-B(해외) | 5 | 32,662.5원 | 163,312.5원(표시 163,313) | 26,612.5원(표시 26,613) | 2,380원 | 2,700원 | 0원 |

- **지원 현황(숨김 없이)**: 매수·매도·배당·분할(엔진 지원, 분할은 수량만 곱하고 원가 불변)은 계산. 입출금은 엔진이 현금흐름만 기록하고 손익에는 영향 없음. **미지원/부분 지원**: 환전 거래, 계좌 이동(TRANSFER), 정정 이력, 세금 계산. 가짜 0이나 성공 표시 없음.
- **정정**: 17·18단계 문서에 "분할·현금 입출금 미구현"이라 쓴 부분은 틀렸다. 코드 확인 결과 엔진은 분할을 지원하고 입출금은 현금흐름만 기록한다.

## 4. C. 가격 신뢰도
**가격 경로 조사 결과**
| 화면 | 경로 | 기준시각 | 상태 |
|---|---|---|---|
| 보유 종목 현재가 | 사용자 지정 GAS 웹앱(JSONP). `freshPrice`는 메모리 전용, 저장값 `currentPrice`는 시각 기록 없음 | 앱이 기록하지 않음 | 미검증 |
| 시장 지수·위험·벤치마크 | Yahoo + 무료 제3자 CORS 중계(allorigins, corsproxy.io, codetabs, corsproxy.org) | 불명 | 미검증(중계 출처) |
- (정정) 17·18단계에서 "보유가격이 Yahoo+중계"라고 쓴 것은 지수/위험 경로에만 해당한다.
- 표시 문구: `미검증 가격 · 출처·기준시각 확인 필요`. 실시간·공식·검증 완료 표현은 근거가 있을 때만(현재 해당 0).
- **가격 메타데이터 틀**: provider, fetchedAt, marketDate, timezone, currency, priceKind(장중/지연/정규 종가/수정 종가), adjusted, verification, status, errorMessage. 모르면 `미확인`. 오래됨(4일 초과)·조회 실패·기업행위 의심·기준일 불일치는 최신처럼 보이지 않고, 가격 기반 신호는 "판단 불가"로 보류.
- 이 표시는 평가금액이나 과거 거래를 바꾸지 않는다(시험으로 확인).
- 새 가격 API 호출·키 추가 없음.

- **측정 방식 주의**: "대비 부족 전" 수치는 그라데이션 배경 위 글씨를 흰 배경으로 잘못 계산한 값이 섞여 있다. "후"는 그라데이션 배경 글씨를 별도(미측정)로 분리했다. 따라서 대비 감소폭은 일부만 실제 개선이다.
- **방법**: 일괄 치환 없이 추가 CSS(`has/readability.css`)로 기간 버튼·탭·편집/삭제 버튼·라벨·인라인 연한 색(#b0bec5 등)만 덮어씀. 가로 넘침 0.
- **남은 예외**: 차트 SVG 눈금 글씨(약 6~11개/화면), 일부 `div` 보조 문구, 대시보드 터치 미달 13개. HTML 안 12px 미만 인라인 선언은 여전히 약 134곳 — "선언 수가 줄었다"로 완료를 주장하지 않으며 이번 범위는 측정된 우선 화면에 한정.
