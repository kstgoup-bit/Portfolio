# 승인 요청서 모음 (20단계) — 이번 지시서로는 어느 것도 승인되지 않았으며, 모두 미실행

| 구분 | 목적 / 대상 | 위험 | 비용 상한 | 시험 방법 | 되돌리기 | 승인 전 → 후 |
|---|---|---|---|---|---|---|
| **A** 원장 영구 저장·이전·백업 확장 | 실제 거래 기록을 `has_ledger_v1`에 저장. 대상: 순태씨가 지정한 계좌·종목 | 원가 근사 오차(해외 환율), 이력 미확인, 백업 호환 | 0원 | 합성 → 사본 데이터 → 미리보기 → 확정 3단계, 구버전 백업 복원 호환 시험 | 직전 전체 백업 + 복원 저널, `has_ledger_v1`만 삭제 | 전: 실제 기록 변경 0 → 후: 지정 종목 기초잔액 생성(기존 키 불변) |
