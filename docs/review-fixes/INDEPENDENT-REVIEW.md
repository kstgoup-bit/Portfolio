# 독립 반례 검토 결과

최종 코드에서 기존 검토의 이스케이프 값·식별자·괄호 키 우회가 가려지거나 전체 결과 보류되는 것을 확인했습니다. 추가로 발견한 8진 슬래시 우회도 \0 뒤 숫자를 거부하는 회귀로 차단했습니다. 복사 실패는 성공 표시 없이 원본이 클립보드에 남을 수 있음을 안내합니다.

종가 검토에서는 미국 서머타임/한국 시각, 정규·단축 마감, 5분 보류, 긴 연휴와 달력 모순을 확인했습니다. 수입 자료의 명시적 합성 달력은 거부됩니다. 긴 연휴의 세션상 최신 종가는 미검증 미리보기로 유지하면서 기존 가치평가 엔진과의 호환이 확인되지 않은 가격은 명시적으로 보류합니다.

독립 회귀 파일: `tests/review-fixes-independent.test.cjs`. 독립 6개와 관련 시험을 함께 실행해 104/104 통과했습니다. 최종 한정 검토에서 추가로 재현되는 위험한 사례를 발견하지 못했습니다. 이는 임의의 모든 JavaScript 구문, 실제 비밀값, 공식 세션 달력, 실시간 자료, 브라우저/실기기를 검증했다는 뜻이 아닙니다.
