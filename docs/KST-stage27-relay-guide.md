# HAS 27단계 — 개인용 KIS 시세 중계 서버 (코드 + 배포·사용 안내)

> 순태씨, 이 문서의 모든 내용은 **코드와 모의(가짜 응답) 시험까지만** 확인된 것입니다. 실제 KIS 서버·실제 키와는 한 번도 접촉하지 않았고, 서버는 배포하지 않았습니다.

## 1. 만든 것
| 파일 | 역할 |
|---|---|
| `relay/relay-core.js` | 요청 처리 핵심. 모든 요청이 `has/relay-policy.js`(인증·허용경로·횟수제한·자동차단)를 통과 |
| `relay/worker.mjs` | Cloudflare Workers 진입점(얇은 껍데기) |
| `relay/wrangler.toml` | 배포 설정 예시(비밀 없음) |
| `has/relay-client.js` | 앱 쪽 호출 모듈(종목 1개씩, 종목코드만 전송, 응답은 항상 "미검증") |
| `tests/relay-worker-stage27.test.cjs` | 16개 시험(전부 모의 fetch) |

허용: 국내 현재가, 미국 현재가. 환율은 검증된 출처가 없어 **501(미지원)**. 주문·잔고·계좌·토큰·웹소켓 경로는 코드에 존재하지 않고 정책에서도 거부됩니다(시험 확인).

## 2. 순태씨가 직접 해야 하는 일 (제가 대신 못 합니다)
1. Cloudflare 계정을 직접 만든다. **카드 등록·결제 화면이 나오면 멈추고 저에게 알려주세요.**
2. Worker를 만들고 이 저장소의 `relay/` 코드를 올린다(대시보드 또는 `wrangler deploy`).
3. 비밀 3개를 **Cloudflare 비밀 저장소(Secrets)에 직접** 입력한다. 채팅·GitHub에는 절대 붙이지 마세요.
   - `KIS_APP_KEY`, `KIS_APP_SECRET`: KIS 발급값
   - `HAS_RELAY_PROOF`: 앱이 보낼 접속 암호. 24자 이상 무작위(비밀번호 관리자로 생성)
4. 일반 변수 `HAS_ALLOWED_ORIGIN`에 앱 주소(`https://kstgoup-bit.github.io`)를 넣는다. (비밀 아님)
5. 하나라도 비어 있으면 서버는 **503으로 닫힌 채** 동작합니다(시험 확인).

## 3. 사용·점검
- 호출: `GET https://<워커주소>/v1/quote/kr/005930` + 헤더 `x-has-auth: <접속 암호>`
- 응답은 `ticker, market, currency, price, source:'kis', kind:'unknown', asOfDate(응답에 날짜가 있을 때만), fetchedAt, verification:'unverified'`.
- KIS 단일 출처이므로 **"독립 대조 불가"**이며, AI 참모는 이 값만으로 신호를 내지 않습니다(기존 규칙 유지).
- 비정상 접근 5회 → 자동 차단(423). 차단 해제는 Worker 재배포(메모리 초기화).
- 키 유출 의심 시: ① KIS에서 appkey 폐기·재발급 ② Cloudflare Secret 교체 ③ `HAS_RELAY_PROOF` 교체 ④ Worker 삭제 가능.

## 4. 솔직한 한계 (미검증 표시)
1. **KIS 경로·tr_id·응답 필드는 비공식 자료 기반 후보**입니다(국내 `FHKST01010100`, 해외 `HHDFS00000300` 등). 실제와 다르면 코드 수정이 필요합니다. 첫 실사용 때 실패할 수 있습니다.
2. **실전 키가 주문 권한을 가질 수 있고 시세 전용으로 제한 가능한지 확인하지 못했습니다.** 이 서버는 주문 코드를 갖지 않지만, 키 자체가 유출되면 키로 주문이 가능할 수 있습니다. 대안: 모의투자 키 사용(`KIS_BASE` 변수로 모의 도메인 지정, 시세 범위·정확도 미검증).
3. 호출 한도·토큰 캐시는 **서버 인스턴스 메모리 기준**(최선 노력)이라 전역 한도가 아닙니다. 전역 한도는 KV/Durable Object가 필요하며 추가 자원·비용 가능성이 있어 넣지 않았습니다.
4. 비용: Cloudflare 무료 한도 내일 가능성이 높으나 **미확인**. KIS 이용 약관·IP 제한·해외시세 신청 필요 여부도 **미확인**.
5. 미국 시세는 NAS→NYS→AMS 순차 조회(최대 3회)라 종목당 호출이 늘 수 있고, 지연/종가 여부는 알 수 없어 `kind:'unknown'`입니다.
6. 앱 화면(portfolio_v5.html)에는 연결하지 않았습니다. 설정 저장 키(`has_relay_cfg`)는 백업 대상 키에 없음을 시험으로 확인했고, 화면 연결은 서버가 실제로 동작함을 확인한 뒤 다음 단계에서 하는 편이 안전합니다.
