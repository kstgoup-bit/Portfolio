# 곡소리·환호성 레이더 실효성 기준과 백테스트 통제 계획 (17단계 작업 E)

## 현재 수치 (정직 표기)
감시 가능 종목 0, 실제 활성 감시 0, 실제 API 호출 0, 실제 가격 검증 0, 실데이터 백테스트 0. 예약 브리핑 자동화(외부)와 HAS 앱 내부 감시는 **별개**이며 앱 내부 실시간 감시는 아직 없다.

## 신호 카드 구조 (매수 추천 아님)
한 종목 카드에 아래를 분리 표시한다.
1. 확인된 사실: 52주 고점 대비 하락률, 지수 대비 상대수익(기준일·공급자 명시).
2. 투자 매력도 근거(사람이 확인): 실적·현금흐름·부채·경쟁력.
3. 악재 성격: 일시적 / 구조적 — 근거 링크 입력칸.
4. 불확실성과 반대 논거: 거래정지·상장폐지·실적 악화·기업행위 오탐 가능성.
5. 추가 확인 항목 체크리스트와 재검토일.
낙폭 신호만으로는 "관찰 후보"까지만 표시.

## 백테스트 통제 계획 (실행은 승인 ③ 이후)
| 편향 | 통제 방법 |
|---|---|
| 데이터 권리 | 합법 확보 경로·저장/표시 허용 문서 확인 전 실행 금지 |
| 수정주가 | 분할·배당 반영 방식 명시, 미반영이면 결과 무효 |
| 생존편향 | 상장폐지 종목 포함 데이터 사용, 불가하면 한계 명시 |
| 미래정보 누수 | 신호일 이후 데이터 접근 차단(시점 고정 입력만), 실적 발표 시차 반영 |
| 거래비용·세금 | 수수료·슬리피지 가정을 파라미터로 고정, 민감도 표시 |
| 기준 비교 | 지수·단순보유 대비, 무작위 진입 대조군 |
| 과최적화 | 학습/검증 기간 분리, 규칙 수 제한, 사전 등록 |
합성 백테스트는 코드 검증용이며 수익률 근거로 제시하지 않는다(화면에 "연구용" 고정 표기).
