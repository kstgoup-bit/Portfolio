# 반영 전후 폰 확인 목록

아래는 별도 반영이 진행될 때의 점검표다. 지금 배포·실자료 확인을 완료했다는 뜻은 아니다.

## 앱 반영 전

1. 평소 기록을 보는 같은 폰·브라우저/PWA에서 인터넷을 켠다. v3 사본 도구의 제목이 보여야 한다. 평소 앱 화면이 대신 뜨면 멈춘다.
2. 일반·국내·해외·연금 4계좌 종목 수가 평소 앱과 맞는지 확인한다. 기존 설정의 v5 백업과 v3 사본을 각각 내려받아 보관한다. v5만으로 일반계좌가 보존되지는 않는다.
3. 받은 v3 파일을 다시 연다. 녹색 해시 확인만 보지 말고 **‘지금 폰 자료와 완전히 같습니다’** 문구까지 확인한다. 다르면 앱 반영을 멈추고 현재 상태의 새 사본을 받아 다시 확인한다. 기존 파일도 지우지 않는다.
4. 파일은 폰의 앱 저장소 밖에 보관한다. 이 사본은 원문 보존 자료이며, 앱의 가져오기 버튼으로 곧바로 복원되는 파일이 아니다.

## 앱 반영 직후

1. 온라인 상태에서 앱을 닫았다 다시 열고, 4계좌 종목 수·보유 수량·예수금·최근 기록이 반영 전 화면과 맞는지 본다. 일반계좌가 비거나 값이 달라지면 멈춘다.
2. 일일기록의 **지수 최신일**과 조회 상태를 확인한다. 코스피200 대용 ETF 날짜가 기존 정체 날짜에서 갱신됐는지 본다. 휴장일·당일 잠정값·제공 지연이 있으므로 무조건 오늘이어야 하는 것은 아니다. 그대로면 상태 문구와 날짜만 기록해 전달한다. 비밀값이나 GAS 주소는 공유하지 않는다.
3. 최근 매매가 있는 계좌의 계산 가능한 수익률/알파에 **‘미검증 참고값’**, **‘보유 변화 미검증’** 안내가 함께 보이는지 확인한다. 데이터가 부족해 ‘보류’인 경우 임의로 값을 채우지 않는다.
4. 새 앱의 v7 백업을 추가로 받는다. 반영 전 v3 사본·v5 백업은 그대로 보관하고, 확인하려고 가져오기/복원을 실행하지 않는다.
5. 다음 정상 거래일 앱을 다시 열어 일반·전체 기록의 새 점과 코스피200 최신일을 확인한다. 과거 누락분이 저절로 복구되는 기능은 아니다.

## 이상하면

자료가 사라지거나 달라짐, 백업 오류, 경고 없는 확정 수익률 표기, 날짜 정체가 계속되면 추가 수정·가져오기·초기화·캐시/앱 데이터 삭제를 멈추고 증상과 시각을 알린다. 기존 사본을 보존한다. 실제 복원은 별도 확인 후 진행한다.

실기기 화면과 실제 자료로 위 절차를 통과했는지는 아직 미검증이다.
