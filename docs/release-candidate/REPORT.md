## 포함한 동작

1. 코스피200 대용 ETF 069500은 기존 설정 GAS의 `type=history`가 우선이다. 주소·응답이 부적합하거나 더 오래된 자료이면 기존 Yahoo 경로로 대체한다. 날짜 관측이며 공식 종가·최신성·조정 상태를 인증하지 않는다.
2. 보유 수량 변화만으로 Dietz·알파를 일괄 비우지 않고 계산 가능한 값에 ‘미검증 참고값’을 붙인다. 외부 입출금 기록만 계산에 반영하며 보유 변화·예수금 지연·입출금 누락 위험을 경고한다. 손상된 입력은 계속 보류한다. 매매 신호 보류도 유지한다.
3. 구형 v4/v5 FG 숫자와 엄격한 숫자 문자열을 허용한다. `null`은 미포함으로 처리해 현재 FG를 덮어쓰지 않는다. 범위 밖·손상 값은 거절한다. 일반계좌가 없는 v5는 불완전 백업이라고 알리며 일반계좌를 추정 생성하지 않는다.
4. 운영 main 내보내기는 v5이고 일반계좌가 빠진다. 과거 ‘구형 v6 전체 백업’ 안내는 철회된 상태다. v3 사본과 기존 v5 파일을 보존하고, 앱 반영 후의 v7은 추가 사본으로 취급한다.
