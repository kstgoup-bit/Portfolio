# 읽기 전용 5+5 파일럿 게이트 (9단계)

합성 입력 전용입니다. 각 종목은 7단계를 순서대로 지나며, 앞 단계가 통과하지 못하면 뒤 단계는 '보류(선행 단계 미통과)'가 됩니다. 어떤 결과도 매수·매도 점수나 활성 감시와 연결되지 않습니다(`scoreLinked:false`, `activeWatch:false`).

| 단계 | 통과 조건 | 실패/보류 예 |
|---|---|---|
| 1 rights | 공급자 판정 '후보 적격'이고 해당 시장 지원 확인 | 부적격=실패, 미확정=보류 |
| 2 eligibility | 미국은 고정 5종목, 국장은 공식 대조 완료한 개별주 + 상태 플래그 확인 | 미검증=보류, 상폐·관리종목=실패 |
| 3 session | 정규장 거래일, 캘린더 범위 안, 시간대 일치, 최신 | 휴장일·주말·미래·시간외 혼합=실패, 오래됨·캘린더 범위 밖=보류 |
| 4 adjustment | 종가와 52주 고가가 같은 조정 기준, 분할 이력 확인 | 기준 혼합·분할 포함 구간의 비조정=실패 |
| 5 high52w | 창 360~370일, 관측 240개 이상, 고가≥종가 | 관측 부족=보류 |
| 6 crossCheck | 독립 출처 1곳 이상, 같은 기준일·조정, 종가 0.5%·고가 1% 이내 | 동일 공급자=보류, 불일치=실패 |
| 7 useRights | 계획한 표시·저장·파생지표 권리가 확인됨, 타인 공유 없음 | 공유·공개 저장소 포함 계획=실패 |

각 기록에 상태, 이유, 출처, 확인일, 검증 범위, `realPrice:false`가 들어갑니다. 실제(비합성) 입력은 이번 단계에서 거부합니다.

**현재 파일럿 종목 수:** 미국 5개 고정(실가격 검증 0), 국장 0개(공식 검증 0이므로 선정 불가). 국장은 사람이 고른 코드가 공식 검증을 마쳤을 때만 `selectKrPilot()`이 받아들입니다.

합성 100종목 부하시험은 순수 함수가 100건을 처리하는지 확인할 뿐 실제 100종목 감시가 아닙니다. 기존 모바일 시험은 신규 화면이 없으므로 신규 기능을 검증하지 않습니다.
