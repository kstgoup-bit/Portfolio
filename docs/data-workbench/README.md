## 사용

독립 작업본의 `has/data-workbench.html`을 여세요. 기존 실험실·투자 기록과 별개인 페이지입니다. ‘합성 예시 불러오기 → 자료 분석’으로 작동을 확인할 수 있습니다. 예시의 회사·재무·시세·거래일은 발명된 시험값이며 실제 데이터가 아닙니다.

JSON 붙여넣기는 UTF-8 1 MB까지입니다. 파일 업로드나 서버 전송 없이 메모리에서만 읽습니다. 보안키·개인정보를 넣지 마세요. 입력을 수정하거나 화면에 돌아오면 이전 결과가 지워지므로 다시 분석해야 합니다. 데이터 이용 권리도 입력자의 선언이며 시스템이 계약을 확인해 주는 기능이 아닙니다.

`HASMarketFixtures.create()`가 입력 형식을 보여 줍니다. `HASMarketData.analyzePack(pack, nowISO)`는 순수 함수입니다. 직접 파일을 여는 브라우저의 로컬 스크립트 정책이 제한적이면 개발 환경의 정상적인 정적 미리보기로 확인하세요. 이번 환경에서는 Chromium 실행이 권한에 막혀 실기기/렌더링 검증을 완료하지 못했습니다.

## 기능 경계

### 시세
- 종목·시장·통화 일치, 실제 가격 숫자 범위, 거래소 날짜/시각과 수신 순서, 미래·오래된 시세, 명시적 가격 유형 및 조정 방식 검사.
- 종가는 최근 완료된 세션과 비교하며 마감 직후 5분은 보류합니다. 수입 자료는 시장·시간대·출처·검토상태와 날짜별 전체 sessionCalendar가 없으면 보류합니다. closedDates만으로 휴장일을 인정하지 않습니다. 긴 연휴·단축장·서머타임을 처리해도 달력의 진위를 인증하지 않으며 결과는 미검증입니다.
- 기존 앱의 quote-model 달력 4일 기준은 이번 작업대 종가 경로에서 사용하지 않습니다. 기존 앱 자체는 변경하지 않았습니다.
- 긴 연휴 후 세션상 최신이어도 달력4일을 넘는 종가는 기존 가치평가 엔진과의 안전한 호환이 확인되지 않아 가치평가를 별도로 보류합니다. 시세 출처 날짜를 수정하거나 검증 완료로 승격하지 않습니다.
- realtime은 입력상 유형입니다. 5분 이내와 권한 선언을 검사해도 실제 연결이나 계약 확인이 아닙니다.
- 1~8개 표본. 최신 거래소 시각을 우선하고 수신 시각으로 과거 시세를 새것으로 바꾸지 않습니다.
- 동일 originId의 중계 경로는 독립 출처로 세지 않습니다. 종가 시간차 60초/그 외 30초 이내, 같은 유형·날짜·조정 방식, 최대 가격차 0.5%인 표본만 ‘수치 일치·미검증’입니다. 이 임계값은 초기 보수적 검사 규칙이지 시장 정확성 증명이 아닙니다.
- 입력자가 verification을 넣어도 검증 완료 시세로 승격하지 않습니다. 실제 수입 시세는 기존 가치평가 엔진에도 미검증으로 전달하므로 가격 대비 가치/매수 판단은 보류합니다.

### OHLCV와 차트
- 2~2000개 KR/US 주식 일봉, 양수 OHLC, 고가/저가 일관성, 거래량(미상은 null), 완료 봉, 공표/수신 순서, 정렬·중복·달력 일치·통화/조정 혼합 검사.
- 합성 표식을 실제 수입 자료로 바꾸는 알려진 경우를 거부합니다. 임의로 위조한 출처까지 인증할 수는 없습니다.
- 관측값 사이 선만 연결하며 데이터를 보간·복원하지 않습니다. SMA20/50, Wilder RSI14, 표본 종가 최대 낙폭, 기간 수익률을 계산합니다.
- 변동성은 일별 로그수익률의 표본 표준편차 × sqrt(252), 최소 20개 수익률이라는 가정입니다. 입력 구간에 평일이 빠지면 휴장인지 누락인지 확인할 수 없어 연환산 수치를 보류합니다. 실제 휴장일도 보수적으로 보류하며, 공식 거래소 달력 어댑터는 아직 없습니다.
- 무조정 가격은 분할/병합/배당락에 왜곡될 수 있습니다. 배당·세금·수수료·환율을 추가로 계산하지 않습니다. 지표는 관측 설명이지 매수 신호나 기업가치가 아닙니다.

### 재무와 SEC
- 새 기업가치 공식을 만들지 않고 기존 `valuation-engine.js`를 재사용합니다. 초기 배수 가치평가이며 DCF가 아닙니다.
- optional `valuationDocument`와 선택 시세의 종목·통화·가격·날짜·합성 여부를 맞춰야 합니다. 충돌 시 분석을 보류합니다. SEC 초안이 가치평가 문서에 자동 섞이지 않습니다.
- optional `secFacts`는 같은 종목/모드일 때만 표시합니다. `SEC-FACTS-ADAPTER.md`의 정확한 accession/tag/unit/period/form/filed 선택 계약을 따릅니다.
- SEC 결과는 언제나 unverified입니다. 연간/분기/시점 항목만 선택하고 YTD 합산, 자동 TTM, EPS 재구성, 특수 태그·기업행사·정성 근거의 자동 추정을 하지 않습니다.

## 테스트와 남은 제한

`node tools/valuation-regression.cjs`는 명시적 비네트워크 회귀 테스트를 실행합니다. 5개 네트워크/러너 테스트는 기존 정책에 따라 제외되어 있으며 전체 npm test 통과로 부르지 않습니다. `node tests/data-workbench-dom.cjs`는 실제 엔진/합성 예시를 포함한 DOM 행동 테스트입니다. jsdom은 package.json의 개발 의존성을 사용합니다. 제작 환경 절대경로를 소스에 넣지 않습니다.

`tests/data-workbench-mobile.cjs`는 360/390/430/1280 폭의 브라우저 검사용입니다. 이번 실행은 Chromium의 socket 생성 권한 오류로 실패했습니다. 브라우저 권한을 우회하거나 재시도하지 않았으며 모바일 렌더링 통과를 주장하지 않습니다. DOM 검사는 렌더링·실기기 검사 대체가 아닙니다.

독립 검토에서 합성 이력 출처의 실제 자료 위장, 누락 평일의 연환산 왜곡을 발견해 회귀 테스트와 함께 수정했습니다. SEC의 합성 URL도 실제 공시 근거와 분리했습니다.
