# 갤럭시 실기기 점검표 — 18단계 (간단판, 10분)

자동 시험은 실기기 통과가 아닙니다. 실기기 시험 현재 **0건**. 17단계 항목(`galaxy-checklist-stage17.md`)을 이어서 하며, 새 버전을 올리지(배포하지) 않았으므로 **지금 순태씨 휴대폰의 홈 화면 이름은 HAS로 바뀌지 않았습니다.**

시작 전: 기존 앱에서 보유 종목 수·금액 3개를 메모.
1. (배포 후에만) 앱을 열었을 때 제목이 HAS인가?
2. 종목 수·금액이 메모와 같은가?
3. 앱 안의 현재가 옆에 **출처·기준일**이 표시되는가? (표시되지 않으면 "미확인 가격"으로 취급)
4. 글씨가 너무 작거나 흐려서 못 읽는 화면이 있는가? 화면 이름과 위치를 메모(예: 잠금화면 하단 안내, 하단 탭).
5. 비행기 모드에서 앱을 열었을 때 화면과 데이터가 보이는가?
6. 백업 내보내기 → 복원 **미리보기**까지만(적용 금지).
7. 뒤로가기를 눌렀을 때 앱이 갑자기 종료되지 않고 이전 화면으로 가는가?
결과: 항목별 ○/×/메모.
