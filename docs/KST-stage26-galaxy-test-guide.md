# HAS 26단계 — 갤럭시 실기기 시험 준비 (제5과제)

**이번 단계에서 시험 환경을 생성·배포하지 않았습니다**(사전 승인 대상). 시험 화면과 절차만 준비했습니다. 갤럭시 실기기 시험 횟수: **0회**.

## 1. 가장 중요한 위험: 저장공간 공유
브라우저 저장공간(localStorage)은 **주소(https + 호스트 + 포트)** 단위로 나뉘며 경로(/Portfolio/…)로는 나뉘지 않습니다. 실제 앱이 `https://kstgoup-bit.github.io/Portfolio/portfolio_v5.html` 이면 **같은 github.io 아래 어느 경로에 시험판을 올리든 실제 앱과 같은 저장공간**입니다. 거기서 시험 자료를 넣으면 실제 투자기록이 덮어써집니다.
→ 그래서 GitHub Pages(같은 계정 github.io)에 시험판을 올리는 방식은 **채택하지 않습니다.** 준비한 시험 화면(`has/galaxy-test.html`)도 `github.io`·https 등 공개 주소에서는 시험 자료 넣기를 **거절**하고, 사용자 기록이 이미 있는 저장공간에서도 거절합니다(시험됨).

## 2. 준비한 파일
| 파일 | 역할 |
|---|---|
| `has/galaxy-test.html` (+ `galaxy-test.js`, `galaxy-test-guard.js`, `galaxy-test-data.js`) | 시험 시작 화면: 주소 점검 → 합성 자료(전부 “합성” 이름) 넣기 → 앱 열기 / 시험 자료 지우기 / 확인 체크리스트·결과 메모 |
| `has/restore-rehearsal.html` (+ `.js`) | 백업 파일 복원 리허설(가짜 저장소) |
| `portfolio_v5.html` | 시험 대상 앱(25단계 AI 참모 + 26단계 수정) |
요구 조건 충족: ① 운영과 분리된 주소에서만 동작(안전장치) ② 실제 기록 변경 없음(기존 기록 있으면 거절, 지우기는 표시 있을 때만) ③ 합성 표시(주황 배너 + 종목명 “합성”) ④ 종료 방법(2번 버튼 후 홈 화면 앱) ⑤ 기존 PWA 설치 상태 유지(매니페스트·서비스워커·이름·아이콘 변경 없음, 정적 시험).

## 3. 시험을 열 수 있는 방법 (모두 사전 승인 또는 사용자 환경 필요)
| 방법 | 설명 | 상태 |
|---|---|---|
| ① 같은 Wi‑Fi의 컴퓨터에서 임시 서버 | 컴퓨터에서 저장소 폴더를 `python3 -m http.server 8080` 등으로 열고 폰 브라우저에서 `http://컴퓨터사설IP:8080/has/galaxy-test.html` — 사설 주소라 실제 앱과 저장공간이 분리됨 | **권장.** 컴퓨터 필요(이전에 PC 보조 도구를 쓰신 이력이 있어 가능할 것으로 보나 확인 필요). 클라우드 자원 생성 아님 |
| ② 휴대폰 로컬 파일로 열기 | 내려받은 파일을 휴대폰에서 직접 열기 | **미확인·불안정 가능**: 안드로이드 크롬은 파일을 `content://` 주소로 열 때 저장공간(localStorage)이 동작하지 않을 수 있어 앱이 정상 작동하지 않을 수 있음. 실기기 확인 전에는 신뢰하지 말 것 |
| ③ 별도 호스팅(Cloudflare Pages 등 **다른 도메인**) | 실제 앱과 다른 주소에 시험판 배포 | **승인 필요**(클라우드 자원 생성). 무료 한도·약관 확인 후 |
| ④ GitHub Pages 같은 계정 | — | **채택 안 함**(저장공간 공유 위험) |

## 4. 시험 절차 (방법 ① 기준)
1. 홈 화면의 실제 앱은 **열지 않아도 됩니다.** (원래 설치 상태 그대로 유지)
2. 폰 브라우저(Chrome)에서 시험 주소 `…/has/galaxy-test.html` 열기 → “0. 이 주소 점검”이 **✅ 시험 가능**인지 확인(⛔이면 중단하고 알려 주세요).
3. “합성 자료로 포폴앱 열기” → 잠금 화면이 나오면 평소 비밀번호 입력 → 종목명이 모두 “합성…”인지 확인
4. 화면의 체크리스트 1~9를 순서대로 확인하고 결과 메모란에 적기(기기 모델·Android/One UI·Chrome 버전 포함)
5. 설정 탭 백업 다운로드 → 시험 주소의 “백업 복원 리허설 화면 열기”에서 그 파일 선택 → 전체 통과 확인
6. 끝나면 시험 주소로 돌아와 “시험 자료 지우기” → 홈 화면의 **원래 앱**을 열어 실제 기록이 그대로인지 확인
7. 결과 메모와 캡처를 클로에게 전달(실제 종목·금액이 보이는 화면은 가리거나 보내지 마세요)
