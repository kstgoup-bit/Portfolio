## 이번에 원문으로 확인한 것
- **공식 상장목록 경로:** 금융위 KRX상장종목정보는 키 필요·무료·공공누리 4유형이고 응답에 상태 필드가 없습니다. KRX Open API 약관은 비상업만 허용하고 키당 10,000건/일이지만 제공 데이터 항목·요금이 원문에 없습니다. KRX Data Marketplace 약관은 자동 수집·복제·배포를 금지합니다. 키 없이 받을 수 있는 공식 상장종목 파일은 찾지 못해 자동 수집은 하지 않았습니다.
- **공급자:** Twelve Data 문서(`adjust` 기본 splits, 심볼당 1 크레딧, 일봉은 거래소 현지 시간, 캘린더 API는 Ultra 이상), Alpha Vantage 약관(개인·비상업 라이선스), Massive 개인·시장 데이터 약관('표시 용도 전용', 키 공유 금지), Tiingo 개발자 부록(토큰·재배포 라이선스), KIS 제휴 안내(개인은 제휴 대상 아님, 시세는 거래소 정보이용계약 필요).
- **새 장애물:** Twelve Data는 요금 페이지와 약관의 문구가 다르고, Massive는 로컬 계산이 '표시 용도 전용'에 맞는지 불명확하며, KRX 계열은 가공·저장 범위가 원문에 없습니다.
