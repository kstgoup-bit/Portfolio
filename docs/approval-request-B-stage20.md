# 승인 B 요청서 (초안) — 미국 시세 최소 호출 시험 · 20단계 작성 · **승인 전에는 아무것도 실행하지 않음**

| 항목 | 내용 |
|---|---|
| 목적 | 미국 종목 5개의 정규장 종가를 1회씩 받아 순태씨가 증권사 앱 값과 직접 대조 → "독립 검증된 가격 수"를 처음으로 0에서 올릴 수 있는지 확인 |
| 대상 서비스 | Tiingo 무료 계정(1순위). 순태씨 본인 명의 가입·약관 동의 필요 — Claude가 대신 가입 불가 |
| 선결 조건(순태씨) | ① Tiingo 약관 본문에서 "본인 화면 표시·본인 PC 저장" 허용 문구 직접 확인(문서에 별도 항목이 없어 미확인 상태) ② 확인 불가면 이 요청서는 실행하지 않음 ③ 키는 채팅에 붙이지 않고 본인 PC 환경변수로만 사용 |
| 호출 범위 | 종목 5개 × 1회 = 최대 **5회** (재시도 없음, 429면 즉시 중단). 일 한도 1,000회의 0.5% |
| 비용 상한 | **0원** (무료 계정만. 유료 전환 요구가 나오면 중단) |
| 실행 위치 | 순태씨 PC의 `tools/us-pilot-runner.cjs`(키는 헤더로만 전송, URL·로그·저장 원문에 키 없음). 브라우저 앱에는 키를 넣지 않음 |
| 위험 | 약관 해석 오류 / 키 노출 / 기준일·수정주가 해석 차이 / 무료 한도 초과 |
| 시험 방법 | 실행기 `--live` + 승인 파일(저장소 밖) + 호출 전 장부 기록. 결과는 `미검증`→`독립 검증(순태씨 대조)`로만 승격, 대조값은 순태씨가 직접 입력 |
| 성공 기준 | 5종목 중 N개의 종가가 증권사 앱 종가와 일치(날짜·통화·수정 여부 동일). **실제 값은 N으로만 보고**, 일치 못 하면 "검증 실패" 그대로 보고 |
| 되돌리기 | 키 폐기, 승인 파일 삭제, 출력 폴더 삭제. 앱·보유·가계부 데이터는 이 시험이 건드리지 않음 |
| 승인 전후 차이 | 승인 전: 실호출 0, 독립 검증 0. 승인 후(성공 시): 최대 5개 가격이 "독립 검증"으로 표시 가능. 감시 종목 확대·백테스트는 승인 C로 별도 |
| 승인 문구 예시 | "승인 B: Tiingo 5종목 1회, 최대 5호출, 0원, 약관은 내가 확인함" |
