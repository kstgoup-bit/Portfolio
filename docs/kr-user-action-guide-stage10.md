## 2. 준비물과 주의
- 공공데이터포털 계정(본인). **서비스키는 채팅·문서·GitHub·ZIP에 쓰지 마세요.** 키는 순태씨 PC에만 두세요.
- 이 API는 키를 요청 주소에 붙이는 방식이라 화면 공유·로그에 키가 남을 수 있습니다. 브라우저 앱이 아니라 PC에서 한 번 내려받는 방식을 권합니다.
- 응답 항목은 기준일자·단축코드·ISIN코드·시장구분·종목명·법인등록번호·법인명입니다. **거래정지·관리종목·상장폐지 구분은 없습니다.** 그 상태는 별도 공식 근거가 필요합니다.
- 이용허락이 '변경금지'라서 원본을 가공해 보관해도 되는지 약관 문구를 직접 확인해 주세요(원문에 가공 범위 설명이 없음).

## 3. 받은 뒤 실행 (PC, 네트워크 불필요)
1. 목록을 CSV로 저장: 헤더 `기준일자,단축코드,ISIN코드,시장구분,종목명`
2. 패키지 변환 — `node tools/kr-listing-pack.cjs 목록.csv 패키지.json "금융위원회" "KRX상장종목정보" "https://www.data.go.kr/data/15094775/openapi.do" 2026-10-29 "공공누리 4유형"`
3. 원본 일치 확인 — `node tools/kr-listing-integrity.cjs 목록.csv 패키지.json` (변조·예시 파일이면 실패)
4. 후보 대조 — `node tools/kr-listing-verify.cjs 패키지.json 2026-10-29`
5. 결과의 matched / mismatch / not-found를 저에게 알려 주세요. 파일 전체나 키는 보내지 않으셔도 됩니다.
