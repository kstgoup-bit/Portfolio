- **C**: 위 시험과 `docs/android-device-checklist-stage13.md`.

## 미완료 · 한계 (숨기지 않음)
1. KRX 실응답(JSON/XML)을 본 적이 없음 → 응답 구조·게이트웨이 코드 매핑은 가정. 우선주는 API 범위 밖. 부족한 27개 후보는 채우지 않음.
2. 출처표시·비상업·변경금지·재배포 제한의 구체 적용 범위는 법률 판단이 필요해 미확정.
3. 미국 시세의 본인 화면 표시 권리, 수정주가 실측, 휴장일 출처(Grow는 제공 안 함) 미확정. 한국 시세 공급자 스키마 미확인, 한국 파일럿 종목은 VERIFIED 0이라 확정 불가.
4. 안드로이드 실기기 시험과 Windows PowerShell 실기 시험 **미실시**. 신호 점수는 "백테스트 미검증 가설".
5. 개인 환경(Windows)의 Node 버전·경로 문제는 사전 점검(`--preflight`)으로만 발견 가능.
