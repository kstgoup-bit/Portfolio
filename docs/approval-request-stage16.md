# 승인 요청서 (16단계) — 각 항목은 별도 승인, 현재 모두 **승인 대기·미실행**

## ① 실제 시세 공급자 소량 호출 (파일럿)
- 호출 대상: 공급자 1곳(승인 후 선정). 종목 MSFT·GOOGL·AVGO·VRT·JPM 5개(읽기 전용), 일봉만.
- 최대 횟수: 종목당 일봉 이력 1요청 × 5종목 + 재시도 상한 1회 = **최대 10회/일, 파일럿 기간 총 200회 이내**(공급자 무료 한도 이내 확인 후).
- 비용: 무료 플랜 한정, **유료 가입 금지**. 한도 초과·약관 불명확 시 즉시 중단.
- 보안: 키는 순태씨 기기에서만 입력(채팅·저장소·번들·로그에 두지 않음), 요청은 허용목록 5개 종목만, 응답 원본은 저장소·보고서에 넣지 않고 합성 계산에 필요한 최소 필드만 사용.
- 검증 항목: 독립 기준값(KRX·거래소 공시 종가 등 사람이 확인) 대비 종가 일치율, 결측·지연, 분할·배당 처리, 표시 권리 문구, 시간대·통화.
- 복구: 호출 기능은 기본 꺼짐. 문제가 생기면 키 폐기·스위치 끄기. 앱의 투자기록은 이 기능과 분리되어 영향 없음.
- 결과 표시: 실제 가격 검증 수를 호출 결과로만 갱신(0 → 확인된 만큼).

## ② 신규 기록(거래·판단)의 앱 내 영구 저장 및 백업 스키마 확장
- 대상: 설계서 `docs/backup-schema-extension-design-stage16.md`.
- 위험: 기존 백업(v6) 복원 호환 파손 가능 → 방지: 별도 키·선택 필드·구버전 무시 규칙·시험용 사본에서만 적용.
- 비용: 0원. 복구: 설계서의 롤백 절차(신규 키 삭제, 원본 백업 복원).
- **승인 전 운영 데이터 쓰기·스키마 변경 금지.**

## ③ 적법한 실데이터 백테스트
- 선행: 과거 가격 자료의 합법적 확보 경로와 사용권(표시·저장·계산 목적) 확인, 상장폐지·분할·배당 반영 여부 확인.
- 비용: 공급자별 상이(무료 한도 이내에서 시작). 위험: 사용권 위반·생존편향. 복구: 결과를 폐기하고 합성 표시로 되돌림.
- 실행 전까지 "실데이터 백테스트 0건".

## ④ 개인용 비공개 서버 또는 인증키 관리 방식
- 선택지: (a) 서버 없이 순태씨 기기에서만 키 입력·메모리 보관(저장 안 함), (b) 개인용 비공개 서버(비용·운영 부담). **현재는 (a)만 권장**, Cloudflare 등 외부 자원 생성은 승인 없이 하지 않는다.
- 위험: 키 유출. 복구: 키 폐기·재발급.
