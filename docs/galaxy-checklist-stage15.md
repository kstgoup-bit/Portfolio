# 갤럭시 실기기 점검표 (15단계) — 현재 미실시

자동화 시험(360/390/430px, Chromium)은 통과했지만 **실제 갤럭시 기기 시험은 0건**입니다. 기기에서 `mobile-lab/invest.html`을 열어(운영 배포 없이 로컬 서버) 확인할 항목:
1. 위험 탭: 금액 단위(억·만원)와 정확한 금액이 잘리지 않는지, 비중 막대·경고 문구가 읽히는지.
2. 입력칸: 숫자 키패드가 뜨는지, 하락률·기준 오류 문구가 키보드에 가려지지 않는지.
3. 파일 선택: 백업 JSON·거래기록 CSV 선택, 내보내기 파일이 내려받기 폴더에 저장되는지.
4. 글자 크기 최대(시스템 설정) 및 다크 모드에서 겹침·가로 스크롤 없음.
5. 비행기 모드에서도 화면이 동작하고 아무것도 전송되지 않는지.
6. 한 손 조작: 버튼 간격, 더블탭 오입력 없음.
