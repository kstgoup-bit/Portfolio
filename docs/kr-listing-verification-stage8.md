# 국장 후보 공식 검증 (8단계)

## 결론
- 공식 상장목록을 **제가 합법적으로 확보하지 못해** 후보 78개(개별주 73 + ETF 5) 전부 `unverified`로 남았습니다. 공식 검증 수는 **0**입니다.
- 100개를 채우려고 임의 종목을 만들지 않았습니다. 개별주 부족은 27개 그대로입니다.

## 확보하지 못한 이유 (확인된 사실)
| 후보 출처 | 확인된 사실 | 이번 단계 판정 |
|---|---|---|
| 공공데이터포털 금융위원회_KRX상장종목정보 | 단축코드·ISIN·시장구분·종목명 제공. 인증키 필요. 공공누리 제4유형(출처표시·상업적 이용금지·변경금지). 개발계정 10,000건/일. 영업일 +1일 오후 1시 이후 갱신. | 키 발급·호출이 금지라 미실시 |
| KRX 정보데이터시스템 | 약관 본문을 열람하지 못함(링크만 노출). 제3자 라이브러리는 스크래핑·로그인 필요를 스스로 밝힘. | 무단 자동수집 위험으로 미사용 |
| 금융위 파일데이터(3036483) | 요청한 번호는 상장종목 목록이 아니라 '인허가 신청사실 공고'였음 | 사용 불가 |

## 도구 (오프라인, 네트워크 없음)
- `kr-radar/listing.js`: 사용자가 합법적으로 내려받은 공식 파일을 `provenance`(제공기관·데이터명·https 출처·기준일·조회일·SHA-256·행 수·이용허락 기록)와 함께 받아 대조합니다.
- 규칙: 코드·종목명·시장구분이 **정확히** 같아야 `matched`(퍼지 매칭 없음). 기준일이 10일을 넘으면 전체 차단. 행 수·해시 불일치, 미래 날짜, http 출처는 전체 차단. 목록 내 중복 코드는 모호로 보고 어떤 후보도 일치시키지 않습니다.
- 우선주·스팩·리츠·ETN 의심 이름은 개별주 후보와 일치시키지 않고 보류합니다(의심일 뿐 제외 확정이 아님).
- 일치해도 `status`는 `hold`입니다. 활성화는 권리가 확인된 실가격 검증 후에만 가능합니다.
- `supplement()`는 사람이 고른 코드가 **공식 목록에 있고 보통주로 보일 때만** 후보를 추가합니다. 도구가 종목을 스스로 고르지 않습니다.

## 순태씨가 하실 일 (별도 승인 시)
1. 공공데이터포털에서 위 데이터의 파일/키를 직접 확보(키는 채팅에 붙이지 마세요).
2. 패키지 JSON(`provenance` + `rows`)으로 정리한 뒤 `node tools/kr-listing-verify.cjs <파일> [오늘날짜]` 실행.
3. 보고서의 matched/mismatch/not-found를 확인하고 부족분은 사람이 고른 코드로 `supplement()`.
