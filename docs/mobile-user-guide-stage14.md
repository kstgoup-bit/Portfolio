# 휴대폰 사용 안내 (순태씨용, 14단계)

**지금은 시험용 화면입니다.** 운영 앱(홈 화면의 KST)은 바뀌지 않았고, 새 화면(`mobile-lab`)은 배포되지 않았습니다. 화면 모습은 `docs/screenshots-stage14/`의 사진 4장으로 확인하세요.

## 화면 읽는 법
- 맨 위 노란 띠: "합성 시험 전용 · 외부 요청 0회". 이 화면의 결과는 **가짜 응답**이며 실제 검증이 아닙니다.
- "데이터 상태": 공식 신원 검증 0종목, 실제 시세 확인 0종목, 실제 감시 0/0 — 실제 수치입니다. 합성 예시는 따로 표시되고 합산되지 않습니다.
- 각 항목은 **기준일 · 출처 · 조회 시각 · 실패 이유**를 함께 보여줍니다. 오래되었거나 없으면 "데이터 없음(DATA_UNAVAILABLE)"과 "HOLD — 신호 없음"으로 나옵니다.
- 종목정보 조회는 **신원 확인용**입니다. 주가 확인도, 매수·매도 신호도 아닙니다.

## 조회 버튼 흐름(모의)
잠금 해제 → 기준일·최대 호출 확인 → 확인 화면에서 체크 → "승인하고 실행". 중간에 끊기면 "남은 쪽만 이어하기"(승인한 호출 안에서만). 새로고침하면 다시 잠깁니다. 버튼을 두 번 눌러도 한 번만 실행됩니다.

## 실제 조회를 하려면 (별도 승인 후)
지금 당장 폰만으로 실조회는 **불가**합니다(서버가 없고 승인도 없음). 가장 안전한 임시 방법은 PC에서 1회 실행하고 결과 요약만 폰으로 보는 것이며, 절차는 `docs/krx-one-page-guide-stage13.md`에 있습니다. 키는 채팅·폰 메모·사진에 남기지 마세요.
