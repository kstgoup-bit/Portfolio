# 사용자가 결정할 후속 절차
이번 단계에서 신청·계좌 개설·로그인·인증·키 발급은 수행하지 않았다. 다음 절차는 안내이며 자동 실행하지 않는다.

1. 먼저 `official-inquiry.md`의 권리·비용·보존·대조·키 관리 질문을 공식 Q&A에서 확인한다. 문의에 비밀값이나 투자자료를 넣지 않는다.
2. 신청을 별도로 결정한다면 [공식 이용절차](https://apiportal.koreainvestment.com/about-howto)와 [개인 고객 약관](https://file.koreainvestment.com/Storage/customer/guide/regards/openAPI_service_customer.html)을 직접 확인한다. 본인인증·계좌 연결은 사용자가 공식 서비스에서 수행한다. 계좌 개설도 별도 결정 사항이다.
3. [한국투자증권 공식 Open API 신청 페이지](https://securities.koreainvestment.com/main/customer/systemdown/RestAPIService.jsp)에서 진행한다. 로그인 화면으로 이동할 수 있다. 유료 해외 시세나 추가 상품을 자동 신청하지 않는다.
4. 키를 발급하더라도 App Key·App Secret·토큰·비밀번호를 채팅, 메일, GitHub, HTML, URL, 브라우저 저장소, 스크린샷 또는 시험 로그에 입력/첨부하지 않는다. 현재 HAS에 키를 붙여 넣는 절차는 제공하지 않는다.
5. KIS의 허용 여부를 확인한 사용자 전용 실행 환경·비밀 저장소를 별도 승인 후 구성한다. 접근 최소화·백업/기기 이전·복구를 사전에 검토하고, 기존 키를 자동 이동·삭제하지 않는다. 조회 전용 증권사 권한 지원 여부도 확인한다.
6. 권리·0원·안전한 인증·공식 현재 한도·확정 종가·독립 출처와 실제 실행기 검증이 모두 충족된 뒤 실제 조회 범위를 다시 승인한다. 이번 C단계 지시로 실조회를 시작하지 않는다.
