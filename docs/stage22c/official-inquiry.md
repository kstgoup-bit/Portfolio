# 공식 문의 문안 — 발송하지 않음
문의 경로: [KIS Developers Q&A](https://apiportal.koreainvestment.com/community/10000000-0000-0011-0000-000000000003). 계정 로그인이나 발송은 수행하지 않았다. 고객센터에 보낼 때 키·토큰·계좌번호·비밀번호·실제 투자자료를 첨부하지 않는다.

제목: 개인 직접 이용 고객의 KIS REST 일봉 종가 이용권·무료 범위·보존·비밀 관리 확인 요청

안녕하세요. 제휴 이용기관이 아닌 개인 직접 이용 고객으로, 직접 개발한 개인 전용 투자관리 프로그램 HAS에서 주문·계좌·잔고 조회 없이 종가 검증만 준비하고 있습니다. 공개 고객 약관과 아래 REST 경로의 적용 조건에 대해 서면 확인을 부탁드립니다.

대상 경로는 국내 `/uapi/domestic-stock/v1/quotations/inquire-daily-itemchartprice` 및 해외 `/uapi/overseas-price/v1/quotations/dailyprice`입니다. 대상은 MSFT·AVGO·GOOGL·NVDA·QTOP, 005930·000660·035420·069500·360750이며 각 1거래일의 정규장 종가만 확인하려 합니다. 비용0원, 인증/실패/재시도 포함 총40요청 이내이며 유료 신청이나 거래는 계획하지 않습니다.

1. 개인 고객에게 현재 적용되는 직접 이용약관·개정일·부속 데이터 이용조건 링크를 알려주십시오. 공개 2022년 시행 고객 약관보다 최신 조건이 있습니까?
2. 위 미국/한국 주식·ETF를 개인이 조회할 자격·필수 계좌 종류·해외 서비스 별도 신청이 있습니까? QTOP 등 ETF의 해당 조회 경로 지원 여부도 확인 부탁드립니다.
3. 위 두 REST 일봉 API가 현재 제 계정 조건에서 추가 비용 없이 제공됩니까? 미국 무료/유료 실시간 시세 신청 상태에 따른 종가 데이터 차이와 별도 요금·거래 실적 조건·무료 일별/초당 제한을 알려주십시오. 인증 발급·재발급 제한도 포함해 주십시오.
4. 개인 기기에서 본인만 보는 HAS 화면에 종가를 표시해도 됩니까? 공개 웹 배포나 제3자 제공은 하지 않습니다. 개인 로컬 파일 앱과 본인 전용 서버 실행의 허용 범위가 다릅니까?
5. 원시 응답과 정규화 종가를 로컬 디스크에 저장·백업할 수 있습니까? 30일/365일/장기 보존, 기기 이전, 백업 사본의 만료·삭제 조건을 각각 알려주십시오. 회사의 거래기록 보존 의무와 별개인 고객 시세 저장 권한을 문의드립니다.
6. 별도로 이용권을 확보한 독립 공급자의 동일 거래일 종가와 개인 내부에서 대조하고 일치 여부를 보존하는 것이 허용됩니까? 두 공급자의 가격 원문을 외부에 제공하지 않습니다.
7. 국내 위 인자 D·원주가1 및 해외 GUBN0·MODP0에서 반환되는 종가의 거래소·정규장/시간외 포함 범위·거래일/시간대 정의와 최종 확정 시각을 알려주십시오. 장 종료 후 무료 과거데이터가 갱신된다는 안내가 REST dailyprice에도 적용됩니까? 언제 유료 데이터와 같아집니까?
8. 분할·병합·배당·상장 변경·과거 정정이 위 인자와 수정주가 옵션에 어떻게 반영됩니까? 수정주가의 정확한 옵션 정의·소급 범위·정정 확인 수단을 알려주십시오.
9. 주문·잔고 권한이 없는 전용 시세 키 또는 권한 제한이 가능합니까? 불가능하다면 개인 소유 격리 실행기에서 키를 비밀 저장소로 관리하는 허용 방식이 있습니까? 제3자 클라우드/AI 실행 환경에 주입하는 행위가 키 위임 금지에 해당하는지도 확인 부탁드립니다. 답변 전 키를 외부에 제공하지 않겠습니다.
10. 호출 제한 초과·장애·서비스 종료 시 권장 중단/재시도 정책, 가격 정정/거래일 달력/종목 마스터 공식 확인 경로를 알려주십시오.
