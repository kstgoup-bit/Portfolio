## 재현 명령
Node와 npm 및 Playwright가 지원하는 Chromium이 필요하다. 기존 main이나 사용자 브라우저를 사용하지 않는다. `BROWSER_EXECUTABLE_PATH`는 해당 환경의 Chromium 실행 파일로 지정한다. 본 환경은 `/workspace/scratch/a983c2ddd102/test-tools/chromium`을 사용했다.

```bash
npm ci
npm test > unit.log 2>&1
export BROWSER_EXECUTABLE_PATH=/path/to/chromium
npm run test:mobile > mobile.log 2>&1
npm run test:mobile14 > mobile14.log 2>&1
npm run test:mobile15 > mobile15.log 2>&1
npm run test:mobile16 > mobile16.log 2>&1
npm run test:mobile17 > mobile17.log 2>&1
npm run test:mobile19 > mobile19.log 2>&1
npm run test:mobile20 > mobile20.log 2>&1
node tests/e2e-journey-stage20.cjs e2e-results.json > e2e.log 2>&1
node tests/lib/measure-stage21.cjs expanded.json > expanded.log 2>&1
node tools/scan-secrets.cjs
```

단위시험에는 tests/lib/no-network.cjs 가드가 적용된다. 브라우저 시험은 루프백/파일 이외 요청을 차단한다. 앱 시작 시 기존 외부 경로2종 시도가 차단된 기록은 실제 공급자 요청으로 성공한 것이 아니다. 이 가드는 운영 네트워크 방화벽을 대신하지 않는다.
