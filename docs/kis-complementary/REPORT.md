# GAS 유지·KIS 추가 비교: 구현과 직접 검증

작성: 2026-11-09. 독립 로컬 개발본이며 운영 연결이나 배포본이 아니다.

## 이번 진전

GAS 기존 경로는 그대로 두고 KIS 추가 자료를 비교할 별도 순수 함수와 휴대폰 중심 시험 화면을 만들었다. 기존 KIS 단계와 최신 클로 HEAD를 먼저 확인해 PC 실행기·미채택 중계·자격증명 경로를 다시 구현하거나 재가동하지 않았다.

비교하려면 종목·시장·거래소·통화·가격 종류·가격 조정 방식·거래소 시각이 정확히 일치해야 한다. 지연 가격은 지연 시간도 알려져 있고 같아야 한다. 시각 누락, 통합 시장이나 주간 거래 장소를 다른 거래소로 추정, 수신 시각을 거래소 시각으로 대체하는 입력은 비교에 사용하지 않는다.

조건이 맞아 가격 차이가 0.5% 이내라도 결과는 **수치 일치·미검증**이다. 원천이 같거나 불명확한 상태도 별도로 표시한다. 다른 공급자 이름만으로 독립 검증을 인정하지 않는다. 이 버전은 어떤 입력도 verified나 투자 신호 사용 가능 상태로 올리지 않는다. 최신성·실시간 연결·가격의 진위도 인증하지 않는다.

새 화면은 합성 예시 불러오기, 비교, 입력/결과 비우기만 제공한다. 네트워크 연결·파일 업로드·클립보드·저장·내보내기·키·계좌·주문 기능은 없다. 편집·반복 분석·뒤로/앞으로 복귀 때 이전 결과를 지워 오래된 판정을 남기지 않는다. 실제 모바일 렌더링은 아직 검증하지 않았다.

## 파일

- `has/kis-comparison.js`: 최대 8 KiB JSON 문자열 경계, 허용 필드 검사, 중복 키 거절, 유한한 가격 범위, 비교 결과 동결.
- `has/kis-comparison-fixtures.js`: 발명된 합성 자료. 실제 시세나 KIS 응답 표본이 아니다.

- `tests/kis-comparison*.test.cjs`: 구현·독립 반례·DOM 시험.

독립 반례에서 발견한 극소 가격의 무한대 차이, 중복 JSON 키의 모호성, 지연 시세에 0초를 선언하는 모순을 보완했다. 표시 반올림이 0.5% 경계 초과를 숨기지 않도록 시험했다. 종목·거래소·통화·종류·조정·시각 불일치, 같은 원천, 누락 정보, 비밀 필드·잘못된 입력의 재출력, 불변 결과와 입력 경계를 검증했다.

## 실행 범위와 제한

```sh
NODE_PATH=/workspace/scratch/a69a663b2cde/dabi-lab-closure/node_modules node tools/valuation-regression.cjs
NODE_PATH=/workspace/scratch/a69a663b2cde/dabi-lab-closure/node_modules npm run test:kis-comparison
```

기존 의존성만 사용했고 새 패키지 설치·외부 API 호출은 하지 않았다. 전체 `npm test`는 이전 네트워크 시험 실행 거부가 있어 재시도하지 않았다. 제외 목록은 기존과 같은 network-guard-stage19, kis-runner-stage21, us-pilot-stage18, krx-runner-cli, kr-krx-stage13 다섯 파일이다. **전체 무제외 통과가 아니다.**

Chromium 소켓 실행은 앞선 환경에서 거부되어 재시도하지 않았다. DOM·정적 모바일 스타일 검사는 실제 360/390/430px 렌더링이나 갤럭시 실기기 시험을 대신하지 않는다. 키보드/확대·화면 넘침·실제 기기 수명주기는 클로 후속 검토 항목이다.

## 보호한 것과 미완료

기존 앱, 서비스 워커, 장부/백업, GAS, quote-model, quote-crosscheck, market-data, source-readiness, 가치평가 엔진, relay-policy, KIS 실행기를 수정하지 않았다. 투자기록을 읽거나 변경하지 않았다. main·원격·운영·클라우드·키·주문·유료 서비스를 변경/실행하지 않았다.

이 비교기는 제공된 같은 시각의 자료에 대한 연구 도구다. 과거 또는 미래라고 쓰인 자료가 서로 같아도 최신성 검증으로 승격하지 않는다. 실제 KIS REST를 읽어 정규화하는 어댑터, 실제 조회, 권리 검증, 승인된 개인 중계, 운영 앱·참모 인계는 아직 구현/실행하지 않았다. 공식 표본에 거래소 시각·지연 의미가 없으면 추정으로 채우지 않는다.

## 클로 후속 검토 요청

사용자 경유로 전달할 패치다. 다른 외부 에이전트에게 직접 연락하지 않았다. 먼저 동봉된 VERIFICATION.json의 기준 트리와 패치 적용 결과를 비교한 뒤 독립 브랜치에서 검토한다.

1. 다른 종목/거래소·가격 종류·시각이 일치로 나올 수 없는지 반례를 확인한다.
2. 수치 일치·공식 공급자라는 이유로 독립 검증·최신성·투자 신호로 승격하는 연결이 없는지 확인한다.
3. 실제 키·네트워크·저장·주문 경로가 없고 기존 GAS·기록 경로가 그대로인지 확인한다.
4. 정상 권한의 별도 환경에서 새 화면의 모바일 렌더링·접근성·수명주기를 확인한다. 이번 환경의 거부를 우회하라는 요청이 아니다.
5. 최신 KIS 데이터 이용 정책/계정 조건과 실제 가림 응답 자료가 확보되면, 모바일 단독 운영과 비밀의 서버 보관을 충족하는 다음 읽기 전용 설계만 검토한다. 문서가 실제 키 사용·클라우드 생성·실전 호출·배포를 승인하지는 않는다.
