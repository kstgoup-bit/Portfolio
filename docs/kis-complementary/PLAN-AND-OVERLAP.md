# GAS 유지 + KIS 추가 공급자: 다음 단계와 기존 작업 대조

작성·확인: 2026-11-09. 실제 키 접근·API 호출·클라우드 생성/변경·운영 배포·주문은 하지 않았다.

## 현재 목표와 경계

HAS는 우량기업의 장기 보유, 분할 판단, 은퇴 자산의 안정을 돕는 능동형 투자참모를 지향한다. 사실·추정·반대 근거를 구분하고, 기업의 질·가격과 가치·시장 심리를 섞지 않는다. 이번 작업은 그 판단의 입력인 가격 자료의 비교 조건을 강화하는 단계이며 매수·매도 추천이나 자동 실행을 만들지 않는다.

GAS는 기존 시세 경로로 유지한다. KIS는 추가 공식 조회·대조 공급자 후보이며 GAS를 대체하지 않는다. 실제 주문·자동매매 기능은 구현하지 않는다. 휴대폰 단독 사용을 전제로 하며 PC 실행기를 최종 운영 방식으로 권하지 않는다.

KIS 실전 키·토큰은 브라우저, localStorage, GitHub, 백업에 넣지 않는다. 이번 화면은 키·계좌 입력란도 없다. 실제 키 사용·라이브 호출·클라우드 생성/변경·운영 배포는 사전 승인 대상이며, 과거 문서의 실행 예시나 승인 문구는 현재 승인이 아니다.

## 정확한 기준

- 최신 클로 검증 브랜치: `work/has-boundary-progress-claude-verify-20261109`, HEAD `69f97c244f89523c01c2b975afc80f4786b9ea1e`.
- 로컬 독립 기준: `5d40a014492fb22b3c84a33659737e35d8b7f14f`. 전체 트리 `7bd5b7197a143a5f029188b448add9d90350b459`가 원격 기준과 일치한다. 로컬 커밋은 같은 소스의 스냅샷이며 원격 이력의 복제는 아니다.
- 클로가 가져온 직전 패치 `0f8294024886dbb93d57a1d6d846d86225e30b94`는 우리 로컬 완료 `49546c60d189e13d70a1837981b5981b1a3e2495`와 트리 `61286d03718dc39d29ebdfc65bbe4b4dc3e8352c`가 같다.
- 이번에는 클로의 모바일 시험 가짜 엔진 수정, 분석 성공 확인, 준비도 결과 동결을 모두 포함한 기준을 사용한다. 과거 모바일 시험 인터페이스 변경 누락을 되돌리지 않는다.
- 확인 당시 main: `fd2599398d2f2ef1816ca9b64ea134ea8811309d`. 변경하지 않았다.

## 기존 단계의 재사용과 제외

| 기존 구성 | 확인 결과 | 이번 처리 |
|---|---|---|
| `has/source-readiness.js` | 중계/원천/권리/재무 자료 구분, 선언은 미검증 | 유지. 신규 비교는 이 선언만으로 인증하지 않음 |
| `has/quote-crosscheck.js` | 통화·날짜·공급자 이름·가격 차이만 비교. 종목·거래소·종류·정확한 시각 누락 | 공유 모듈 변경 대신 엄격한 별도 계약을 추가. 운영 연결은 아직 안 함 |
| `has/quote-model.js` | 교환 시장/원천 메타데이터를 모두 유지하지 않으며 호출자 verification을 받을 수 있음 | 새 비교의 인증 근거로 사용하지 않음 |
| 21단계 PC 실행기 | 실제 자격증명·토큰·조회 경로, PC 전제. 시각/가격 종류 미확인 | 실행·복제·재가동하지 않음 |
| 22D 전송 설계 | 고정 목적지, 리다이렉트/재시도 제한, 작은 응답, 메모리 토큰 등 참고 가능 | 향후 승인된 서버 설계의 검토 자료일 뿐. 오래된 40회 호출 허용 가정은 승계하지 않음 |
| 27단계 중계 | 현 기준에 미통합. 임의 KIS_BASE와 기본 리다이렉트, 실제 거래소가 빠지는 해외 fallback, 클라이언트 중계 자격증명 저장 | 가져오지 않음. 실제 노출이 있었다는 뜻은 아니며 활성화 전 해결해야 할 잠재 위험 |
| 28단계 GAS | 현재 유지할 시세 경로 | 그대로 유지 |

과거 문서의 ‘증권사 앱과 같으면 독립 검증’, ‘공공 데이터면 독립 원천’, ‘GAS는 비용 0’, PC 운영 권고는 현재 결론이나 승인이 아니다. 공급자 이름이 다르거나 전송 경로가 둘이라고 원천 독립성이 생기지 않는다.

## 이번에 구현하는 안전한 단계

1. 제한된 JSON 문자열로 제공된 두 시세의 종목·시장·거래소·통화·가격 종류·조정 방식·거래소 시각이 같은지 검사한다. 다른 시각을 허용 오차 안이라고 합치지 않는다.
2. 조건이 맞는 경우에만 가격 차이를 계산한다. 같은 수치도 독립 검증이나 최신 가격으로 승격하지 않고, GAS 가격을 KIS로 자동 교체하지 않는다.
3. 휴대폰용 독립 합성 시험 화면에서 일치·충돌·시각 누락·거래소 차이·동일 원천의 사례와 보류 이유를 보여 준다. 브라우저에 실제 키나 원본 응답을 입력하지 않는다.
4. 시세 원본·공급자 권리·시각 의미의 검증은 별개다. KIS REST 표본에서 `stck_prpr` 또는 `last`만 얻어도 거래소 시각이나 지연 여부를 모르면 비교를 보류한다. 수신 시각으로 빈 항목을 채우지 않는다.

## 승인 전 진행할 수 있는 후속 검증

- 공식 공개 명세와 최신 공지의 근거를 보완하고, 이미 제공된 약관/회신을 우선 재사용한다. 부족한 최신 데이터 이용 정책·계정 시세 조건만 추가 확인한다.
- 실제 비밀을 제거하고 사람이 확인한 GAS 응답·KIS 응답 표본이 제공되면 필드 계약을 오프라인으로 대조한다. 실제 거래 자료의 저장/공유 권리가 확인되지 않으면 저장소·공개 페이지에 넣지 않는다.
- 기존 앱에 연결하기 전, 새로운 비교 상태가 단일 투자 점수나 매수 신호로 승격되지 않는 인계 시험을 설계한다. 기존 장부·백업에 접근하지 않는 별도 읽기 전용 경계부터 확인한다.

## 실제 연결 전 별도 확인·승인이 필요한 것

최신 개인 개발자 이용약관과 데이터 이용 정책, 본인 계정의 국내/미국 시세 범위·지연·권한·요금, 현재 호출 한도, 개인 중계 허용 범위, 키 보관·회수·접근 통제, 승인된 운영 위치·비용·요청 범위를 확인해야 한다. 특정 클라우드를 생성하거나 GAS에 KIS 키를 추가하지 않았다. PC 없이 본인 휴대폰만 쓰는 최종 흐름은 이 조건을 충족한 뒤 선택한다.

실전 키가 시세 전용으로 제한된다는 근거가 없으므로 제한되어 있다고 가정하지 않는다. 고정 공식 목적지·리다이렉트 금지·시세 경로 최소 허용 목록·토큰 메모리 한정·원문 오류 비노출 같은 방어도 키 자체의 권한 제한을 대신하지 않는다.
