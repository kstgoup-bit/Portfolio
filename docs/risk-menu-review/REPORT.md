## 결론과 남은 1건

**확인된 메뉴 2건을 수정한 부분 완료 후보다. 체험판 전체 기능 통합 완료본은 아니다.**

- 기존 환호성 레이더를 위험관리 메뉴에서 바로 열 수 있게 했다.
- 기존 ‘원장 시범’ 메뉴·화면 제목을 ‘거래 기록·손익 계산 체험’으로 맞췄다.
- 기존 매매 점검, AI 참모, 곡소리, 종목분석 등 모든 내부 탭과 계산 기능은 보존했다.
- **‘가상 검증·실운용 준비’는 체험판의 정확한 소스·연결 대상이 미확인이다.** 그럴듯한 다른 실험실을 임의로 연결하거나 같은 기능을 이식했다고 표시하지 않았다. 이 1건의 원본 확인이 남아 있다.

## 실제 변경과 안전 경계

런타임 변경은 기존 파일 2개와 CSS 1개 추가뿐이다.

- `portfolio_v5.html`: CSS 연결, 환호성 바로가기, 거래 체험 메뉴·접근성 이름.
- `has/ledger-demo.js`: 화면 제목 1곳.
- `has/risk-menu-shortcuts.css`: 바로가기의 글자색·키보드 포커스·44px 목표 크기.

기존 탭 전환은 `.tab` 버튼의 순서와 배열 인덱스를 연결한다. 새 링크에는 별도 클래스를 써 기존 버튼 인덱스를 바꾸지 않았다. 환호성은 기존 `sell/index.html`을 여는 일반 링크이며 새 데이터 연결·주문 기능·수집 장치를 만들지 않았다. 기존 곡소리 하위 링크도 유지했다.

GAS, 수익률 계산, FG, 백업/복원, 매매 점검, AI 참모, 서비스워커, 저장 키와 실제 투자자료는 변경하지 않았다. 실제 데이터 접근·거래·운영 배포·main 병합·push도 수행하지 않았다.

## 폰 화면·브라우저 검증의 한계

이번 검증은 Node/JSDOM 합성 시험이며 실제 화면 렌더링이나 터치 검증이 아니다. 이 환경은 앞선 Chromium 시도에서 내부 소켓 제한으로 시작 전에 실패했으므로 같은 시도를 우회·재실행하지 않았다. 실제 갤럭시·360/390/430px 레이아웃 통과를 주장하지 않는다.

`tests/risk-menu-browser.cjs`는 이후 허용된 브라우저 환경에서 실행할 수 있는 **미실행** 합성 조각 검사다. 전체 앱을 시작하지 않고 가상 메뉴·원장 화면만 넣어 360/390/430/1280px에서 버튼 크기·가로 넘침·매매 점검 진입·합성 제목을 확인하도록 준비했다. 문법 검사는 했으나 그 스크립트 자체의 실행 성공도 아직 미검증이다.

## 클로에게 확인이 필요한 사항

1. 체험판 v5의 전체 SHA와 ‘가상 검증·실운용 준비’의 실제 연결 경로·소스를 제공해 달라. 이름만 비슷한 기존 실험실을 대신 연결하면 안 된다.
2. 체험판 거래 체험이 현재 `ledger-demo`와 같은 구현인지, 체험판에만 있는 승인된 입력·검증·설명 기능이 더 있는지 원문으로 대조해 달라.
3. 확인된 범위의 새 환호성 바로가기와 기존 매매 점검이 공존하는지, 폰에서 가로 스크롤·포커스·돌아오기와 긴 메뉴 제목을 실제 브라우저로 확인해 달라.
4. 체험판 보호용 합성 껍데기와 실제 앱 기능을 분리해 검토해 달라. 이번 패키지를 ‘체험판 전체 통합 완료’ 또는 운영 배포 승인으로 해석하지 말아 달라.
