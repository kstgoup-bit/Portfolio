# 클로 검토용 폰 확인 목록

실제 운영 자료 대신 별도 합성 환경에서 수행한다. 현재 패키지에서 실기기 통과를 주장하지 않는다.

1. 위험관리 메뉴를 가로로 넘겨 곡소리·환호성·거래 기록/손익 체험·AI 참모·매매 점검이 모두 접근 가능한지 확인한다. 기존 종목분석·AI자문·위험계·15계명·뉴스도 유지돼야 한다.
2. 환호성 바로가기가 기존 합성 연구 화면으로 가고, 곡소리로 돌아오는 링크와 브라우저 뒤로가기가 어떻게 동작하는지 확인한다. 실제 보유 자료·시세를 붙이지 않는다.
3. 거래 체험 제목과 합성 경고, 원화/해외 예시 손익, 시험 거래 추가·초과매도 거절·예시로 되돌리기·이전 화면 복귀를 확인한다. 실제 거래를 넣지 않는다.
4. 새 링크 뒤쪽의 AI 참모·매매 점검을 눌렀을 때 다른 탭이 켜지는 인덱스 밀림이 없는지 확인한다.
5. 360/390/430px 세로 화면에서 메뉴를 넘길 수 있는지, 문서 전체의 가로 넘침·잘린 버튼·포커스 누락이 없는지 확인한다.
6. ‘가상 검증·실운용 준비’는 이번 후보에 없다. 체험판의 실제 경로·소스를 확인해 후속 통합 범위를 결정한다.
