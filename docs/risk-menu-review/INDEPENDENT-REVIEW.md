## 최초 검토

검토한 차이에서 조치가 필요한 회귀를 발견하지 못했다. 런타임 변경은 원장 문구·접근성 이름, 동일 출처의 기존 환호성 화면 링크, 범위가 제한된 CSS다. 기존 탭 인덱스와 목적지가 유지된다.

현재 두 런타임 파일을 열거된 조각으로 역변환하면 기준 8005cd0의 해시와 정확히 일치함을 Git 기준과 별도로 확인했다. 집중·역사 보존·일일기록·백업 호환 관련 오프라인 시험 58/58을 실행해 통과했다.

## 새 CSS의 보호 파일 목록 보완 후 재검토

보호 검증을 느슨하게 만드는 문제는 발견하지 못했다. 기존 파일별 SHA와 이전 추가 파일의 역변환 검증을 유지하며, 추가 허용 목록은 새 CSS 하나만 확대하고 해당 파일도 정확한 SHA로 별도 검사한다.

관련 오프라인 회귀 57/57을 실행해 통과했다. 두 보호 검사 호출 지점인 daily-repair-protection과 kis-auth-independent를 포함한다. 이 57개는 첫 58개와 중복되는 별도 실행이며 115개의 고유 시험이라는 뜻이 아니다.

## 확인하지 않은 범위

Chromium, 실제 폰/시각 레이아웃, 실제 페이지 이동, 운영 배포, 외부 API, 실제 사용자 자료는 검증하지 않았다. 신규 선택적 브라우저 스크립트는 문법 검사만 통과했다. 정확한 체험판 소스 동일성과 ‘가상 검증·실운용 준비’ 기능은 미확인이다. 전체 체험판 메뉴 통합 완료로 표현하면 안 된다.
