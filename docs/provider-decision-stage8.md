# 시세 공급자 의사결정 자료 (8단계)

문서를 읽은 것과 실제 시세 API를 호출한 것은 다릅니다. 이번 단계의 실제 시세 API 요청은 **0건**입니다. 아래 `미확정`은 "허용" 또는 "금지"가 아니라 "모름"입니다. 근거와 확인일은 `kr-radar/data/providers.json`에 있습니다.

| 공급자 | 시장 | 확인된 사실 | 미확정(결정 필요) |
|---|---|---|---|
| 금융위_주식시세정보 | 한국 | 종가 등 시세 제공, 인증키 필수, 무료, 공공누리 4유형, 제3자 재배포 금지, **T+1**(영업일+1일 13시 이후), 10,000건/일 | **수정주가 제공 여부**, 초당 한도, 개인 앱 표시·저장·가공(변경금지와의 관계), 휴장 캘린더 |
| 금융위_KRX상장종목정보 | 한국 | 코드·ISIN·시장구분·종목명, 위와 같은 조건 | ETF·관리/폐지 상태 포함 여부 |
| KRX Data Marketplace | 한국 | 상업적 이용 유료 구매처(공공데이터포털 안내) | 가격, 약관 본문, 개인 이용 권리 |

| Alpha Vantage | 미국 등 | (공식 확인 실패) 제3자 해설: 무료 일 25·분당 5 | 공식 한도·가격·약관 전부 |

## 판정
- 파일럿 허용 공급자: **0개**. 필수 13개 항목 중 조정가격·캘린더·개인 표시·저장·가공·벤치마크가 모두 확인되지 않았습니다.
- 한국 일봉 단독 후보인 금융위 시세는 T+1이고 수정주가 미확인이라, 현재 설계(52주 고가를 동일 조정 기준으로 비교)를 충족한다고 말할 수 없습니다.
- Twelve Data Basic의 '비표시' 조건은 앱 화면에 가격을 보여주는 설계와 충돌할 수 있습니다.
