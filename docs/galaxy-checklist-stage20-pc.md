# PC 점검표 — 20단계 (약 10분, 순태씨 PC용)

이 점검은 **휴대폰 앱이 아니라 PC 크롬**에서 합니다. 기존 앱의 보유 종목·가계부는 건드리지 않고, 화면에도 나오지 않습니다(저장 공간이 따로 분리됨). 갤럭시 실기기 시험은 여전히 0회입니다.

## 준비
1. 받은 `HAS-stage20-source.zip`을 PC 바탕화면 등에 **압축 풀기**(폴더 안 구조를 그대로 두세요).
2. 폴더 안의 `portfolio_v5.html`을 **크롬으로 열기**(파일을 크롬 창으로 끌어다 놓아도 됩니다).
3. 잠금 화면이 나오면 평소 쓰시는 비밀번호를 입력합니다.
   - 처음 보는 빈 화면이 정상입니다(보유 종목 없음).

## 점검
| # | 할 일 | 기대 결과 | ○/×/메모 |
|---|---|---|---|
| 1 | 위 메뉴에서 🛡️ 위험관리 → 🧪 원장 시범 | 맨 위에 "시범 화면 · 합성 데이터 · 실제 보유·수익 아님" | |
| 2 | 아래로 내려 "기존 보유 → 원장 이전 미리보기" 확인 | "합성 보유 · 저장 안 함", 이력은 "이력 미확인", 수량 0 종목은 "제외" 안내 | |
| 3 | 시험 거래 추가 칸에서 「시험 거래 추가」 버튼을 누른 뒤, 바로 아래 안내문과 「바뀐 숫자 보러 가기 ↑」 버튼 확인. 그 뒤 새로고침(F5) | 「추가했습니다…」 안내가 뜨고, 버튼을 누르면 맨 위 「일반 계좌」 카드로 올라가 보유 수량이 15주→16주로 바뀌어 있음. F5 하면 추가한 거래가 사라짐 | |
| 4 | 화면 맨 아래 「← 이전 화면으로 돌아가기」 | 원장 시범에 들어오기 직전 화면(예: 종목분석)으로 돌아가고 오류 없음 | |
| 5 | 🛡️ 위험관리 탭이 아닌 "해외" 탭 → 위쪽 "가격 신뢰도" 띠의 "자세히 보기" | "미검증 가격 · 출처·기준시각 확인 필요" 문구 | |
| 6 | F12 → 휴대폰 모양 아이콘(기기 모드) → 폭 360 / 390 / 430으로 바꿔 현황·일반·배당 탭 보기 | 글씨가 읽히고, 버튼이 겹치지 않고, 좌우 스크롤이 생기지 않음 | |

## 참고
- 곡소리 레이더 탭은 이렇게 파일로 열면 **데이터를 불러오지 못할 수 있습니다**(브라우저 제한). 이번 점검 대상이 아니며 오류가 아닙니다.
- 인터넷이 연결된 PC에서는 앱이 원래 하던 대로 지수 조회 등 외부 주소 요청을 시도할 수 있습니다(새로 추가된 요청은 없음). 지수 새로고침 버튼은 누르지 않으셔도 됩니다.
- 막히면 화면 캡처와 함께 "몇 번 항목에서 무엇이 보였는지"만 알려주세요.

**결과 기록:** 항목별 ○/× 와 메모를 알려주시면, 보고서에 "PC 확인 N건(갤럭시 실기기 0회)"으로 구분해서 반영합니다.
