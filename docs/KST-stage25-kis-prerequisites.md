## 3. 순태씨가 확인하실 공식 화면·문의
1. KIS Developers 포털 > API 문서 > 국내주식 시세 / 해외주식 시세 각 API 화면(요청 URL, TR ID, 응답 필드, 실시간·지연 표기) 캡처
2. 포털 > 마이페이지(앱키 관리) 화면: 재발급·삭제 버튼, IP 등록 항목, 권한 항목 유무 캡처(키 값 가리고)
3. 2026-10-27·10-29 공지 본문 캡처
4. KIS 고객센터 서면 문의: ① 시세 조회 전용 키 또는 주문 권한 제한 가능 여부 ② "본인 전용 서버가 키를 보관하고 본인 휴대폰 앱에만 시세를 전달"하는 구성이 약관상 개인 이용에 해당하는지 ③ 현재 초당 호출 한도·토큰 유효시간 ④ 해외(미국) 시세의 실시간/지연 구분과 별도 신청·비용 여부 ⑤ 키 유출 시 폐기 절차
5. 호스팅 사업자 요금표(중계 서버를 만들 경우)

## 4. 결론
이번 단계에서도 **KIS 연결 구현에 착수할 조건은 충족되지 않았습니다.** 공식 명세 대조(1·2·5)와 약관 해석(6)이 선행 조건입니다. 앱의 AI 참모는 검증 시세가 주입되지 않는 한 모든 종목을 "판단 보류"로 표시하므로, 연결 전에도 잘못된 매수·매도 의견은 나오지 않습니다.
