# HAS 실제 데이터 연결 1단계 검토 후보

기준: `kstgoup-bit/Portfolio` main `c8169036bb0bba5b1a0fb810c3d8fdbf8ca356d5`.
원격 branch GET 및 recursive tree로 확인. 기존 속도 최소안은 이미 기준본에 포함되어 재적용하지 않았다. 이 산출물은 별도 로컬 후보이며 원격 브랜치 생성·main 병합·운영 배포를 하지 않았다. 개발 커밋 SHA는 아직 없다.

## 구현
- GAS `type=history` 기존 응답 형식을 재사용. 보유종목과 QQQ·SPY·069500을 시장별 최대 12개씩 조회하는 연결 코드.
- 곡소리·환호성·AI 참모에 같은 가격 근거 패널. 사용자 새로고침 버튼에서만 요청하며 시작시 새 외부 요청 없음.
- 기존 설정 GAS 주소만 허용, JSONP 10초 제한·콜백 정리. 공급자에 종목 코드·시장만 보냄. 계좌명·수량·평단·메모·비밀키는 보내지 않음.
- 이전 날짜 가격 관측으로 52주 고점 대비, 1·3·6개월 가격수익률, 같은 통화·정확히 같은 두 관측일의 지수 차이 계산. 당일 막대 제외. 미검증 조정 기준을 검증된 종가로 바꾸지 않음.
- 실패·과거 응답·7일 이상 오래된 값은 지난 성공값/기준일 또는 자료 부족 표시. 동시 요청 중복 제거. 당일 성공 메모리 캐시는 세 화면에서 공유.
- 종목별 상세를 접어 세로 길이 축소. 환호성은 같은 앱의 가격 근거 화면으로 이동하고 뒤로가기로 곡소리 목록 복귀. 기존 sell 합성 연구 파일은 그대로 보존.
- 모든 계산 `signalHold:true`. AI 판단 엔진은 미검증 GAS를 검증 근거로 승격하지 않고 판단 보류 유지. 가격 근거는 AI 화면 옆에 표시하는 단계다.

## 시험 결과
`node --require ./tests/lib/no-network.cjs --test`로 신규 가격 core·DOM·통합, 기존 speed·staff·advisor evidence·daily protection·backup contract·risk menu 합계 **152 통과 / 실패 0**. 최종 로그 `evidence/final-focused.log`.
합성 응답만 사용. 실제 GAS/KIS 호출·실제 계좌 자료 변경 없음. DOM 시험은 Chromium 레이아웃 또는 갤럭시 실기기 시험을 대체하지 않는다.

전체 npm test는 실행 후 결과 수집이 api.tiingo.com 실호출 우려로 차단되었다. 해당 문자열은 네트워크 차단 자체를 검증하는 시험이고 preload는 외부 net/dns/tls/fetch를 차단한다. 코드 확인 후 기존 세션 결과 수집을 재시도했으나 세션이 종료되어 완료 요약을 확보하지 못했다. 따라서 전체 회귀 통과로 보고하지 않는다. 초기 로그의 예상 보호핀 오류는 새 연결부 exact projection 및 새 메뉴 목적지 계약을 반영해 위 152개 집중시험에서 재검증했다.

## 미완료 / 운영 전 조건
1. 실제 승인된 GAS 호출로 응답·권한·데이터 범위를 확인해야 한다. 현재는 연결 코드+합성시험 완료이지 실연동 가동 확인이 아니다.
2. 페이지 재실행 이후 지속되는 하루 1회 캐시는 미구현. 저장 키·백업 허용목록 변경을 피한 메모리 전용 단계다.
3. 사용자 확신 종목 지정·해제 UI와 25%/10% 한도 적용은 미구현. QTOP·MSFT·AVGO를 자동 지정하지 않는다.
4. 관심종목 연결은 미구현. 보유종목+지수만 대상이다.
5. advisor-evidence의 엄격한 종가/분할조정/365일 근거 계약을 GAS만으로 충족하지 못한다. 기준을 완화하지 않으며 재무·기업가치·공시 결합 및 매매 판단 활성화는 후속 단계다.
6. PC·360/390/430px 실제 브라우저, 전체 회귀를 다시 실행해야 한다. `준비 중` 표시는 아직 제거하지 않았다.
7. 실제 수집 장치·자동 알림·KIS·주문·자동매매·서비스워커·복원 장치는 변경하지 않았다.
8. 별도 SW 후보와 통합할 때 새 JS 2개 및 변경 HTML/radar/advisor 해시를 manifest에 다시 생성해야 한다. GAS 응답은 SW 캐시 대상 아님.

## 보호 증빙
원본 원장·백업 저장 로직·서비스워커 불변. 기존 보호핀은 바꾸지 않고 `live-data-projection`이 정확한 변경 부분을 역변환해 기존 검증층으로 넘긴다. 신규 모듈은 별도 SHA256 고정.
