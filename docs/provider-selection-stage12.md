- 한국: 두 후보 모두 무료 → 월 $0. 단 분당·일 한도 내(10,000건/일 대비 하루 약 7회).

## 파일럿 실행 계획(승인 후)
1. 신원: KRX 승인 조회 1~3회 → 후보 73 중 VERIFIED 산정 → 한국 파일럿 ≤5 확정.
2. 시세: 미국 `MSFT, GOOGL, AVGO, VRT, JPM` + `SPY, QQQ`; 한국 확정 종목 + `KOSPI, KOSDAQ`. 일봉 종가 위주, 읽기 전용.
3. 매 항목: `validateBar` → (2곳일 때) `reconcile` 0.5% → `high52w`(동일 수정기준·이력·공백·분할 검사) → `signals.report` → `decide`(신원 미검증·가격 부재·매수/매도 충돌 시 HOLD).
4. 최소 승인 체크리스트(`pilot.checklist`): 사용자 파일럿 승인, 한국 신원 검증 완료, 공급자 약관 검토, 수정주가 기준 확정, 거래소 휴장일 캘린더 구현, 키 보관 계획 승인, 백업 확인, 롤백 계획, **유료 플랜 사용자 승인**.
