# 실제 데이터 공급자 연결 설계 — 미실행 제안

현재 구현은 브라우저에서 동일 출처의 고정 JSON만 읽는다. 실제 수집 서버·API 키·유료 리소스는 없다. ChatGPT 예약 감시와 앱 수집 서버는 별개이며 이번 작업은 어느 예약 감시도 만들거나 실행하지 않았다.

## 어댑터 계약

`{id, mode, load({signal}): Promise<Snapshot>}`. `mode`는 `demo` 또는 `real`이며 응답도 동일 모드여야 한다. Snapshot은 `schemaVersion:1`, `quotes`, `assessments`를 포함한다. 중복 티커는 응답 전체를 거절한다. 고정 JSON이 테스트 공급자 구현이다. `collect()`는 8초 제한·취소 신호를 제공하며 자동 무제한 재시도하지 않는다. UI의 수동 재시도로 복구한다.

가격 필수 메타데이터: 티커, 뉴욕 종가일, 통화 USD, 시간대 America/New_York, split-adjusted, 출처명/URL, 종가, 52주 고가·구간, 동일 3개월 주식/SPY/업종 ETF 수익률·구간·수정 기준. 결측/불일치는 관련 계산을 평가 불가로 처리한다. S&P 500의 대용으로 SPY를 쓰는 차이, 가격 수익률/배당 포함 수익률의 선택은 실제 공급자를 정할 때 명시해야 한다. 기존 코드는 가격 수익률을 전제로 한다. 3개월·52주 기간 허용 범위는 MVP의 계약 검증이며 실제 거래일 정책은 공급자에 맞춰 확정한다.

실제 어댑터는 화면에 연결하지 않았다. UI는 명시적인 실제 데이터 미연결 상태다. 테스트 객체를 실제 모드로 바꿔 인터넷 데이터처럼 보이게 하는 기능도 없다.

## 승인 전 검토 항목

| 항목 | 필요한 확인 |
|---|---|
| 라이선스 | 개인 PWA 표시, 저장, 가공·캐시, 과거 데이터, 재배포 권한을 공급자 약관과 계약에서 확인 |
| 커버리지 | 검증된 약 200개 미국 종목 및 SPY·업종 ETF. 상장폐지/티커 변경/복수 주식 클래스 정책 |
| 정합성 | 뉴욕 거래일/휴장/서머타임, 마감 후 데이터 확정 시점, 분할·배당 조정, 동일 기간 수익률 |
| 한도 | 배치 지원·분당/일간 요청·200종목 EOD 수집·재무 갱신 빈도에 필요한 플랜 |
| 오류 | HTTP 429·Retry-After, 타임아웃, 부분 실패, 재시도 최대 횟수, 공급자별 장애 격리 |
| 최신성 | 요청 시각과 관측 종가일 분리. 최근 성공값을 쓸 때 stale 표시와 실제 성공 수를 표시 |
| 비밀 | 서버의 secret 환경변수/비밀 저장소. 브라우저·저장소·localStorage에 새 비밀키 저장 금지 |
| 개인정보 | 서버는 공개 티커 목록만 수집. 사용자 보유·잔고·거래 기록을 받지 않음. 향후 전송에는 별도 동의 |

## 예상 부하와 비용 산정 방법

이번 단계의 새 외부 서비스 비용은 0이다. 로컬 시험은 고정 데이터만 사용하며 새 유료 리소스를 생성하지 않았다. 공급자를 선정하지 않아 현재 요금·무료 한도를 확인한 상태는 아니다.

계획 가정: 거래일 약 22일/월, 종목 200개, 종가 하루 1회. 1종목 1요청이면 약 4,400 종목 요청/월에 SPY·업종 ETF와 재시도·재무 갱신을 추가한다. 공급자가 200개 배치를 허용하면 호출 수는 크게 줄어든다. 52주·3개월 이력은 초기 적재 후 증분 갱신하되 분할 발생 시 재조정한다. 재무·뉴스는 가격과 다른 갱신 주기를 둔다.

예상 월 운영비 = 선택한 데이터 라이선스/요청 플랜 + 서버 실행/예약 + 저장·전송 + 관측/장애 대응. 금액은 실제 공급자 견적과 수집량을 확인한 후 제시한다. 사전 계획 예산으로 서버 부분에 월 0~10달러를 가정할 수 있으나 검증된 상품 가격·총 운영비가 아니며 데이터 라이선스는 별도다. 승인 전 구매·계정 생성·배포를 하지 않는다.

## 다음 단계 구현 순서

공급자 공식 약관·견적 확인 → 실측 호출량·가격 정합성 검증 → 별도 서버 설계 승인 → 비밀 저장 및 읽기 전용 캐시 API → 부분 실패/신선도/성공 수 표시 → 검증 목록으로 실데이터 대조 시험 → 실제 기기 PWA 갱신 시험. main 병합과 운영 배포는 이 작업에 포함되지 않는다.
