남은 제한 및 다음 확인
- 실제 브라우저 lifecycle 시험은 여전히 미실행. 직전 차수에서 Chromium이 페이지 시작 전 socket() Operation not permitted로 실패했고, 이번에는 같은 제한을 우회하거나 반복 실행하지 않았다.
- 허용 환경에서의 실행용 하니스: HAS_CHROMIUM_EXECUTABLE=/usr/bin/chromium node tests/sw-speed-lab/browser-lifecycle.cjs
- 하니스는 합성 2자산 앱으로 구 SW→후보 대기/활성화·오프라인·다른 캐시 보존·부분 소실 복구·no-claim을 검사하도록 준비된 것이며, 실제 앱 브라우저 통과 증거가 아니다.
- 일부 자산 소실은 현재 세대의 정확한 hash/MIME/size 응답만 10초 제한으로 복구. 오프라인/새 세대 응답은 실패. marker·전체 cache 소실 자동 복구 없음.
- activate 거절은 구 SW로 rollback하지 않는다. legacy cache 전역 삭제와 다중 등록/rollback 상호작용 및 업데이트 안내도 해결 필요.
- 신규 400종목 선별 요청의 앱 변경은 아직 이 main에 없으며 이 작업 범위에 추가하지 않았다. 이후 런타임 파일이 바뀌면 다시 manifest 생성과 전체 검증이 필요하다.
- 운영 반영·push·main 병합은 하지 않았다. 실제 전환 및 cold/warm 기기 측정 후 별도 운영 승인 필요.
