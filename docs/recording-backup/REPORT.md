# HAS 백업과 자산 기록 안전 보완

작성일: 2026-11-10

## 목적과 기준

이 작업은 일반계좌와 지수 이력의 백업 보존, 시세가 없는 종목으로 인한 자산 기록 중단, 복원 및 수동 가격의 안전한 처리에 집중한다. 운영 자료를 읽거나 변경하지 않고 별도 작업본과 합성 자료로만 개발한다. 실제 주문과 자동매매 기능은 만들지 않는다.

- 원격 기준: `work/has-gas-history-claude-20261110`, `12cd44955f328755ab4713e7c6b39c934cc86dec`.
- 기준 소스 트리: `256fde8a76cae63cdd64c2524047f5fa00f24a52`. 563개 파일의 Git blob 해시를 원격 목록과 대조했다.
- 동일 트리로 만든 로컬 기준 커밋: `3098edc06f99e9bfd1b85ccd75b67b950a59978e`. 원격과 소스는 같지만 Git 이력은 다르다.
- 독립 브랜치: `work/has-recording-backup-20261110`.
- 운영 main 확인값: `fd2599398d2f2ef1816ca9b64ea134ea8811309d`.

## 운영과 개발본의 차이

운영 main의 예전 내보내기는 `genStocks`를 포함하지 않고 예전 가져오기도 이를 복원하지 않는다. 그러나 이번 기준 개발본에는 이미 `backup/core.js`와 `backup/ui.js`의 v6 백업이 있으며, `v5_gen`과 `v5_benchHist`를 포함한다. 따라서 이번 작업이 누락 필드를 처음 구현했다고 주장하지 않는다. 기존 v6를 재사용하여 손상 검증, 누락값 보존, 실제 복원 전 보호와 시험을 보완한다. 운영 main은 바꾸지 않는다.

직전 다비 29단계 소스는 클로 `8dffe3397a766d00a863f426c2f9511510998ce3`에 트리 `284c462a637406623238d5ab1fc732d616804fdf` 그대로 반영되었다. 이후 클로의 점검 시험 변경, GAS history 초안, 보고서, 윌리엄스 연구 의견서를 보존한다. 윌리엄스 전략 연구나 실거래 신호 구현은 이번 범위가 아니다.

## 원인 확인 범위

실제 금현물 `M04020000`의 GAS null 응답과 폰 화면은 사용자가 클로에게 전달했다는 보고서의 증거다. 이번 작업에서 실제 주소를 호출하거나 실제 보유내역을 읽지 않았다. 합성 재현에서는 일반계좌의 한 종목이 미갱신이면 일반 및 전체 자동 기록이 막히고 나머지 계좌는 독립적으로 기록됐다. 이전에 성공한 세션 신선도 표시가 남을 수 있고 수동 기록 경로도 있으므로, 과거 기록 누락 전체의 원인을 확정하거나 드문 기록점을 우연한 시세 성공으로 단정하지 않는다.

## 구현한 보완

### 기존 v6 백업 재사용

백업의 바깥 JSON과 내부 문자열 JSON에서 중복 키, 과도한 크기·중첩, 손상 값, 지수 이력과 출처 메타데이터를 검사한다. 일반계좌와 지수 이력, 새 수동 기록의 원문을 왕복 보존한다. 구형 백업에서 빠진 계좌·그룹은 유지하고 명시적으로 빈 배열인 경우와 구분한다. API 키·비밀번호·GAS 주소의 기존 제외 정책은 유지한다.

미리보기 뒤 자료나 저널이 바뀌면 적용을 거부한다. 복원 중단·손상 상태에서 자동 복구하지 않고 쓰기를 막는다. 원문은 보존하며 지원하지 않는 사본은 정상 복원이나 되돌리기에 쓰지 않는다. 새 내부 저널 v2는 이전 값과 예정 값을 함께 확인하지만, localStorage의 원자성 한계를 없애지는 못한다. 정상 계좌 자료의 v6 백업 형식은 유지한다.

### 수동 가격을 명시한 새 자산 기록

특정 금현물 코드를 하드코딩하지 않았다. 사용자가 종목별로 수동 가격 방식을 선택하고 실제 가격·단위·통화·기준 일시·1~4일의 KST 달력 날짜 허용 기간을 입력해야 한다. 기준 일시가 비었거나 미래 또는 허용 기간 밖이면 기록을 보류한다. 매입가를 현재가로 쓰거나 환율 1370을 만들어 넣지 않는다.

수동 값과 기존 GAS 수신값 모두 미검증으로 표시하고 매매 판단 자료로 승격하지 않는다. 수신 시각을 가격 기준 시각으로 바꾸지 않는다. 새로운 기록에는 종목별 출처·기준 시각 또는 미확인 상태·수동 포함 여부가 남는다. 미갱신·잘못된 단위·오래된 값 등 기록 보류 이유는 계좌와 종목별로 표시한다.

기존 같은 날 점은 교체하지 않는다. 과거 점을 생성하지 않으며 옛 기록의 메타데이터를 채워 바꾸지도 않는다. 저장 실패 때 메모리만 성공한 것으로 처리하지 않는다. 복원 뒤 도착하는 옛 시세·지수 응답 및 예약된 재시도는 무효화한다. 기존 자동 연금 예수금 이름 변환은 제거해 다시 읽기만으로 복원 원문이 바뀌지 않게 했다.

### GAS history 경계

요청 종목·시장과 응답의 종목·통화·거래소·시간대·일봉 의미가 일치해야 한다. 원본 숫자 정밀도를 유지하며 범위 밖 값, 충돌하는 같은 날짜, 잘못된 시각을 거절한다. 저장소의 우선주 코드 00680K도 합성 시험에 포함한다. 기존 기본 주식·환율 요청 경로는 바꾸지 않는다.

Yahoo 응답과 조정 기준은 계속 미검증이다. 공식 종가·확정성·달력을 인증하지 않고 날짜별 막대에 임의 장 마감 시각을 넣지 않는다. 실제 Yahoo/GAS 호환성이나 거래소 별칭은 아직 실표본 검증이 필요하다.

### 독립 검토에서 보완한 반례

우선주 영숫자 코드, 같은 티커의 서로 다른 보유 ID, 정상 소수 초 일시 입력, 원가가 없는 옛 기록, 복원 뒤 늦은 재시도, 복원 직후 이름 자동 변경을 확인하고 관련 회귀를 추가했다. 마지막 사례는 복원→다시 읽기→되돌리기→다시 읽기 과정에서 이름·티커·분류의 원문 보존까지 검증했다.

## 시험 기준과 제한

수정 전 허용 회귀는 1,259개 통과했다. 최종 검증은 다음과 같다.

- 허용 회귀 93개 파일, **1,408/1,408 통과**. 실패·취소·건너뜀 0.
- 집중 시험 **211/211 통과**. 위 회귀에 포함된 수치이며 중복 합산하지 않는다.
- 독립 검토 **32/32 통과**. 해당 사례도 최종 회귀에 포함했다.
- 기존 데이터 워크벤치·가치평가·조언 화면 DOM 시험 3종 통과.
- 변경된 JS/CJS 및 GAS 18개 파일 구문 검사, HTML 인라인 구문 검사, 공백 검사 통과.
- 해당 시험 실행 중 외부 접속 시도 0. 비밀 형태 스캐너 발견 0건이며 비밀 부재의 완전한 증명은 아니다.
- 기존 장부, 별도 매매 점검, 가치평가·참모·종가 근거·KIS 비교 모듈, PWA manifest/service worker, 예전 화면의 보존 대상 해시 일치.

원래 시험은 과거 단계의 파일 해시 및 HTML 문구 횟수를 고정한다. 이번 승인 범위의 백업 코드 변경은 별도 검토 핀으로 명시했고, HTML은 27개 명시적인 변경 구간을 역적용하면 기준 원격 HTML 해시와 정확히 일치하도록 검증한다. 과거 단계 검증과 새 기능 검증을 구분했으며 시험을 건너뛰거나 허용 목록에서 제거하지 않았다. 자동 복구 기대 시험 2개는 중단 상태의 쓰기 없는 거부로 바꿨다. GAS 시험도 원본 정밀도 보존·일치하는 메타데이터·잘못된 묶음 전체 거부라는 새 계약에 맞춰 수정했다.

검증 로그와 독립 검토는 이 폴더에 함께 포함했다. 최종 로컬 커밋·트리·패치 재적용 결과는 패키지 루트의 VERIFICATION.json, 각 파일 해시는 SHA256SUMS를 참조한다. ZIP 전체 해시는 전달 메시지에 별도로 제공한다.

전체 `npm test`는 실행하지 않는다. 기존 접근 제한이 있었던 다음 다섯 시험은 명시적인 회귀 목록에서 계속 제외한다: `network-guard-stage19.test.cjs`, `kis-runner-stage21.test.cjs`, `us-pilot-stage18.test.cjs`, `krx-runner-cli.test.cjs`, `kr-krx-stage13.test.cjs`. 제외 시험 통과나 전체 시험 통과로 표현하지 않는다.

이 환경에서 실제 Chromium 실행은 이전에 소켓 권한 제한으로 차단되었다. 우회하거나 재시도하지 않는다. Node 및 가짜 DOM 검증은 실제 Android 폰, PWA 설치, 브라우저 레이아웃 검증과 다르다.

## 적용과 자료 이전

데이터 이전은 계획만 작성한다. 실제 사용자 저장소 읽기, 삭제, 복원, 변경은 수행하지 않는다. 현재 운영에 적용하거나 GAS를 다시 배포하지 않는다. 원격 push, main 병합, 클라우드 변경, 실제 API 키 사용, 실시간 호출, 유료 서비스, 주문 및 자동매매는 이번 결과에 포함되지 않는다.

기존 백업을 버리거나 운영 앱을 삭제·재설치하지 않는다. 향후 승인된 적용 전에 합성 백업 왕복과 기존 형식 거부/보존 시험, 실제 모바일 확인, 현재 자료의 안전한 보존 절차를 별도로 완료해야 한다. 없는 과거 가격이나 빠진 과거 자산 점을 만들어 채우지 않는다.
