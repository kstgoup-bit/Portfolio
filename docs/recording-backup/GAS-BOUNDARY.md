# GAS history 입력 경계 보완

2026-11-10 · 독립 개발본 · 합성 시험만 수행

## 범위와 상태

`gas/has-history-request.gs`의 새 history 경로만 보완했다. 기존 기본 주식 요청과 환율 요청, 실제 GAS 프로젝트, 배포, 키, main은 변경하지 않았다. 이 파일은 로컬 코드이며 실제 서비스에 반영됐다는 뜻이 아니다.

입력 형태를 더 엄격하게 확인해도 Yahoo 응답은 계속 비공식·미검증이다. `source: 'yahoo-chart-v8'`, `adjustment: 'unverified'`를 유지한다. 공급자가 자기 응답에 적은 종목·거래소 정보의 일치 확인은 독립 출처 검증이 아니다.

## 재현한 위험과 보완

| 기존 위험 | 현재 처리 |
| --- | --- |
| MSFT 응답을 요청한 QQQ로 다시 이름 붙임 | 공급자 `meta.symbol`과 실제 조회 심볼이 정확히 일치해야 한다. |
| 다른 통화·시장·거래소·시간대 응답 통과 | 예상 USD/미국 또는 KRW/한국, 지원 거래소 코드, 시간대와 교차 확인한다. |
| 같은 날짜의 다른 값이 마지막 값으로 덮어써짐 | 시각과 가격이 모두 동일한 중복만 제거한다. 같은 날짜에 시각·가격·null 상태가 다르면 전체 종목을 `null` 처리한다. |
| `0.00001`이 반올림되어 0으로 변함 | 원래 숫자 정밀도를 보존한다. 표시용 반올림은 하지 않는다. |
| 유한한 `1e308`을 곱해 Infinity가 되고 JSON에서는 null이 됨 | 곱셈 반올림을 제거하고 숫자 범위를 검증한다. |
| 음수·비정상 메타 가격, 비정상 날짜·미래 시각 | 유효한 숫자·정수 epoch 초만 허용한다. 잘못된 값은 전체 종목을 `null` 처리한다. |
| 잘못된 입력 키·콜백·원문 오류 반사 | 고정 오류와 제한된 식별자만 반환하며 공급자 오류 원문은 내보내지 않는다. |

## 지원 계약

### 요청

- `market`은 정확히 `US` 또는 `KR`이어야 한다.
- `tickers`는 원시 문자열, 최대 512 UTF-16 코드 단위, 쉼표로 나눈 항목 최대 12개이다. 전체를 먼저 검증하므로 일부 잘못된 항목이나 초과 항목을 조용히 무시하고 조회하지 않는다.
- 공백 제거와 대문자 정규화 뒤 중복 티커는 한 번만 조회한다. 응답 키는 정규화한 티커이다. 빈 항목·잘못된 티커는 전체 `{error:'bad-request'}`이며 조회 횟수는 0이다.
- US는 영문자로 시작하는 최대 15자 영문 대문자·숫자 티커 및 점/하이픈으로 나눈 접미사를 지원한다. `^` 지수, `=` 환율, `.KS`/`.KQ`는 이 US history 경로의 지원 대상이 아니다.
- KR은 숫자로 시작하는 여섯 자리 영문 대문자·숫자 코드를 허용하고 `.KS`, `.KQ` 순으로 시도한다. 저장소의 우선주 코드 `00680K`도 지원한다. `M04020000` 같은 금현물이나 이미 접미사가 붙은 입력은 지원하지 않는다. 기본 시세 경로의 지원 범위를 바꾸는 규칙이 아니다.
- 최대 조회 수는 US 12회, KR 24회이다. 고정 Yahoo 호스트의 GET 요청이고 리다이렉트를 따라가지 않는다.

### 공급자 응답

- 파서 시그니처는 `hasParseYahooChart_(text, symbol, market)`이다. 직접 호출도 예상 시장을 명시해야 하며, 시장이 없으면 `null`이다. fetch helper도 시장을 전달한다.
- 원시 문자열 최대 1,048,576 UTF-16 코드 단위만 JSON으로 파싱한다. 이 제한은 응답을 읽은 **후** 적용된다. 네트워크 다운로드 바이트 한도 또는 GAS 실행시간 보장은 아니다.
- chart 결과와 quote 배열은 각각 하나여야 한다. chart 오류는 없어야 한다. timestamp와 close 배열 길이가 같고 원시 행 수는 2~400이어야 한다. 중복 제거 전 행 수에 한도를 적용한다.
- `symbol`, `currency`, `exchangeName`, `exchangeTimezoneName`, `instrumentType`, `dataGranularity`는 필수이다. `instrumentType`은 `EQUITY`/`ETF`, `dataGranularity`는 `1d`만 지원한다.
- US: `USD`, `America/New_York`, 지원 코드 `NMS/NGM/NCM/NYQ/ASE/PCX/BATS`이다. KR: `KRW`, `Asia/Seoul`이며 `.KS`는 `KSC`, `.KQ`는 `KOE`여야 한다.
- `fullExchangeName`은 없으면 코드로 표시한다. 제공됐다면 코드에 맞는 보수적인 이름 목록과 일치해야 한다. 알려지지 않은 코드/이름은 승인하거나 자동 변환하지 않는다. 공급자 별칭 변경은 실제 표본 검토 후 별도 업데이트해야 한다.
- 요청한 `.KS`에 `.KQ` 자료가 반환돼도 붙이지 않는다. 별도로 `.KQ`를 조회한 결과가 `.KQ` 요청과 일치할 때만 채택한다.

### 숫자·날짜

- 가격 지원 범위는 `1e-8` 이상 `1e12` 이하의 유한한 숫자이다. 숫자 문자열, 불리언, 0, 음수, 범위 밖 값은 거절한다. 이 수치 범위는 안전한 파서 지원 한도이며 시장 유효성을 인증하는 기준은 아니다.
- close의 명시적 `null`은 결측으로 남겨 해당 날짜 값을 만들지 않는다. 손상된 다른 유형의 값은 결측으로 바꾸지 않고 전체 응답을 거절한다. 결측 처리와 중복 제거 후 유효 날짜가 최소 두 개여야 한다.
- 선택적 `regularMarketPrice`와 `fiftyTwoWeekHigh`는 없거나 null이면 null이다. 제공된 잘못된 값은 전체 종목을 거절한다. 52주 고점과 종가의 수정 기준이 같다고 가정하거나 고점을 계산해 채우지 않는다.
- timestamp는 2000-01-01 이후, 현재 실행 시각 이하의 정수 epoch **초**여야 한다. 초/밀리초 혼동, 소수 초, 미래·범위 초과 시각을 거절한다. 제공된 행의 최장 범위는 370일이다. 오래된 자료를 최신이라고 인증하지 않는다.
- `regularMarketTime`은 선택적이다. 있으면 같은 시각 검증을 통과하고 제공된 가장 늦은 bar timestamp보다 빠르지 않아야 한다. 공급자 최근 거래 시각일 뿐 각 bar의 마감 시각이 아니다.
- 날짜는 예상 거래소 시간대로 변환하고 실제 달력 날짜 문자열인지 확인한 뒤 오름차순 정렬한다. bar 형태는 기존 `{d,c}`를 그대로 유지한다. 새 timestamp, 오후 4시/3시 30분 같은 마감 시각, 빈 거래일 가격을 만들어 넣지 않는다.

## 세션과 신뢰 경계

`interval=1d`와 날짜 일치는 확정 종가 근거가 아니다. 당일 bar는 장중 값일 수 있다. 주말·휴일·조기 폐장·임시 거래 중단을 판단할 공인 캘린더를 이 파서는 갖고 있지 않다. 따라서 날짜가 계산되었다고 거래 세션이 유효하거나 완료됐다는 플래그를 추가하지 않는다. 합성 주말 timestamp 시험은 날짜 변환만 확인하며 거래 세션 인증을 뜻하지 않는다.

원시 Yahoo timestamp를 각 bar에 새로 노출하지 않았다. 기존 date-only 계약에서 확정 시각을 복원할 수 없으므로, 후속 소비자는 `d`를 임의 마감 시각으로 바꾸거나 `regularMarketTime`을 모든 bar에 복제해 사용하면 안 된다. 별도 달력·출처·수정 기준·최신성 근거 없이 이 응답을 공식 종가, 수익률 비교 또는 매매 판단의 검증 자료로 승격할 수 없다.

## 기존 시험의 계약 수정

원래 가짜 응답에는 `meta.symbol`과 `dataGranularity`가 없었고 KR 예시에는 US 거래소 이름이 남아 있었다. 새 시험은 일치하는 필수 메타를 넣었다. 기존 4자리 반올림 기대값은 원본 정밀도 보존으로, 동일 날짜 last-wins 기대값은 정확히 같은 행의 중복 제거로 바꿨다. 12개 초과 입력은 앞 12개만 조회하는 대신 조회 전 고정 오류를 기대한다. 이는 안전 경계의 명시적인 변경이며 기존 기본 stock/FX 응답 변경이 아니다.

## 검증

실행 명령:

```sh
node --require ./tests/lib/no-network.cjs --test tests/gas-history-draft.test.cjs tests/gas-history-boundary.test.cjs
```

결과: **37/37 통과**, 실패·취소·건너뜀 0. 기존 초안 시험 7개와 새 경계 시험 30개이다. 가짜 UrlFetchApp, ContentService, 고정 시각 및 Intl 날짜 변환으로 실행했다. 실제 Yahoo/GAS 네트워크 호출은 없다. `git diff --check`도 통과했다.

새 시험은 저장소의 영숫자 KRX 우선주(00680K) 호환성, 종목/시장/통화/거래소/시간대 불일치, 필수 메타 결측, 비정상 배열·원문, 가격 범위, 중복 충돌, 전부 null, 요청·행·응답 크기 제한, 날짜/DST/미래 시각, 콜백 반사, 원문 오류 비노출을 다룬다.

한계: 실제 GAS 런타임·현재 Yahoo 스키마·실제 조회 지연/쿼터·배포된 endpoint는 확인하지 않았다. 이 작업에서 전체 npm/network 관련 5개 suite 및 Chromium을 재시도하지 않았다. 제한된 합성 시험 통과를 전체 회귀·실서비스 통과로 보고하지 않는다. 원격 push·운영 배포는 수행하지 않았다. 최종 로컬 커밋과 통합 검증은 전체 보고서 및 패키지 VERIFICATION.json을 따른다.
