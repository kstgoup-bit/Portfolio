# 환호성 매도 레이더 연구 설계 — 2026-10-29

## 구현 범위

`sell/core.js`는 입력을 변경하지 않는 합성 전용 순수 함수다. `sell/index.html`은 별도 연구 페이지이며 실제 보유·localStorage·백업·주문·실제 공급자와 연결하지 않는다. 곡소리 레이더의 연결은 이 페이지로 가는 링크뿐이다. 기존 매수 배점·신호는 바꾸지 않았다. 결과는 투자 지시가 아닌 검토 상태이며 자동 행동은 항상 false다. 고정 연구일을 화면에 표시하고 최신 실제 데이터로 보이게 하지 않는다.

## 데이터와 판정

- 합성 전용 id `SELL-DEMO-*`, 최상위 synthetic 모드와 시세 synthetic 표시를 모두 요구한다. 실제 모드/종목 코드와 혼합은 차단한다. 표시는 계약 검증이며 값 자체의 진위 인증은 아니다.
- 시세는 USD·동일 분할 기준 취득가와 split-adjusted 가격이 필요하다. 연구일에서 4달력일 초과·미래·비정상 날짜·비정상 가격은 평가 불가다. 실제 거래일 캘린더와 배당/세후 총수익률 계산은 미구현이다.
- 고평가: 현재 배수 > 3년 이상 과거 상단, 성장률 ≤ 전망 성장률, FCF 수익률 < 2%의 동시 조건이다. **범용 적정가치 모델이 아닌 연구용 고정 가정**이다. 배수 종류·기간 비교의 적절성은 후속 분석가 검증이 필요하다. 금융주/적자 고성장주에 그대로 적용하지 않는다. 가격 수익률과 투자 논리 악화를 분리한다.
- 투자 논리: 경쟁력·실적·현금흐름·부채·점유율 5요소의 stable/structural-deterioration/uncertain 구분을 명시적으로 입력한다. 코드가 단기 하락으로 구조적 악화를 추론하지 않는다. 1요소라도 uncertain이면 전체 평가는 불가다. 구조적 악화의 실재 여부는 자료 검토자의 책임이다.
- 밸류에이션·논리·교체 근거는 HTTPS canonical 출처·기준일·확인일·설명·반대 근거를 요구한다. 기준일 120일, 확인일 30일 초과는 연구용 보수적 차단이다. 재무 발표 주기 예외는 수동 검토 후 정책 변경 대상이다. 합성 출처 example.invalid는 실제 근거가 아니다.
- 집중도 = 분류별 기준통화 평가액 합계 / 전체 평가액 합계. 계좌/종목/업종 각 한도와 비교해 **초과**만 경고한다. 평가액은 환산 완료한 `BASE` 입력만 받는다. 환율·현금·부채 반영과 실제 보유 연결은 미구현이다. 한도 없으면 추정 기본값으로 계산하지 않는다.
- 교체 비교 = (대안 연간 기대수익액 − 현재 연간 기대수익액) × 기간 − 세금 − 거래비용. 모든 금액은 동일 기준통화이며 기대수익률 퍼센트가 아니다. 질 점수는 0~100 입력 가정이다. 현금 필요액 ≤ 가용현금, 대안 질 ≥ 현재 질, 순 기대차익 > 0일 때만 검토 가능하다. 세법 자동 계산·할인율·변동성/확률·세금연기 효과는 미구현이다. 비용 누락은 미확인, 대안 주가 낙폭은 판단 입력으로 사용하지 않는다.

전체 상태 우선순위는 필수 근거 결측 → 평가 불가; 구조적 악화 → 투자 논리 훼손 재검토; 한도 초과 → 비중 점검; 고평가와 유효한 교체 검토 → 일부 매도 검토; 고평가이나 교체 검토 불충분 → 평가 불가; 나머지 → 장기 보유 검토다. 상충/결측이 있어도 독립 경고 flags와 반대 근거를 보존한다. 이는 실제 권고나 매도 수량 결정이 아니다. 교체 자료가 없어도 논리/비중의 독립 검토는 가능하나 고평가로 일부 매도 검토를 만드는 데는 부족하다.

수익률 = (동일 분할 기준 가격 / 취득가 − 1) × 100. +20·+30·+50·+100·+200% 도달은 **검토 알림 예시**만 만든다. 음의 수익률·급등·급락 자체로 논리 훼손/매도를 결정하지 않는다.

## 계좌별 적용 정책 — 설계, 미적용

| 구분 | 제안 | 승인 전 동작 |
|---|---|---|
| 연금 장기 코어 | 긴 검토 주기, 연금 인출/세금/장기 자산배분 검토, 승인된 계좌별 종목·업종 한도 | 기존 행동 유지, 자동 신호/주문 없음 |
| 해외 직투 새틀라이트 | USD 원가와 기준통화 자산 비중 분리, 환차손익·해외 양도세·거래비용 반영 | 기존 행동 유지, 자동 신호/주문 없음 |
| ISA·일반 | 계좌 세제와 만기·현금 필요성 구분 | 기존 행동 유지 |

현재 구현의 집중도 한도는 **합성 입력의 포트폴리오 수준 계좌/종목/업종 한도**다. 서로 다른 계좌마다 개별 종목 한도를 저장하는 설정 UI·승인 기록·실제 연동은 설계만 있으며 구현하지 않았다. 합성 예시 60%는 제안 기본 투자 한도가 아니다. 실제 데이터 외부 전송 경로는 없으며 신규 저장 키도 없다.

## 합성 사례와 시험

A 정상 가정 → 장기 보유 검토; B 한도 초과 → 비중 점검; C 고평가+교체 순편익 → 일부 매도 검토; D 구조적 악화 → 논리 재검토; E 결측 → 평가 불가. 단위시험은 오래된/미래 시세, 분할 기준 불일치, 급등·급락, 결측, 구조 악화와 고평가 분리, 반대 근거, 세금·비용·현금·대안 질, 정확한 한도, 입력 불변, 실제/합성 혼입을 검증한다. 모바일은 360/390/430px 목록·상세·뒤로·새로고침·오류복귀·기존 로드 상태에서 오프라인 탐색·XSS·터치를 확인한다. 첫 방문 또는 오프라인 새로고침 제공은 보장하지 않는다. 운영 SW를 변경/등록하지 않는다.
