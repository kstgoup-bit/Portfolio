## 3. GitHub 개발 브랜치 업로드 — 조건부 수행

1. 현재 GitHub 연결 앱의 해당 저장소 읽기/쓰기 범위와 브랜치 생성 가능 여부를 확인한다. 확인 가능한 사실과 추정을 구분한다.
2. 권한이 실제로 허용되는 경우에만 `main`에서 독립 개발 브랜치를 생성하고, 2·3단계 패치와 이번 4단계 변경을 순서대로 반영한다. 파일 무결성 및 최종 커밋 SHA를 대조한다.
3. 권한이 허용된다면 **Draft PR만** 생성해 변경사항과 시험 증거를 첨부한다. 자동 병합·운영 배포는 하지 않는다.
4. HTTP 403이 계속되면 한 차례 원인을 기록하고 중단한다. 로컬 브랜치, `git format-patch`, 전체 소스 ZIP, 적용 방법을 전달한다. 사용자가 공식 GitHub 연결 권한을 조정하거나 자신의 인증된 개발 환경에서 적용하도록 안내한다.

## 4. 실제 미국 주가 공급자 선정과 5종목 파일럿

### 4.1 공급자 비교

3단계 `docs/data-provider-comparison-stage3.md`를 기준으로 Alpha Vantage, Twelve Data, Massive를 공식 가격·문서·이용약관으로 다시 확인한다. 다음 항목을 표로 비교한다.

- 개인 비상업적 사용 시 API 조회·저장·화면 표시·재배포 가능 범위
- 미국 주식 일별 종가, 52주 고가, 주식분할·배당 조정, 기준일·시간대, 지연 여부
- SPY 및 업종 ETF의 동일 기간 데이터 제공 여부
- 200종목 × 거래일 기준 필요한 호출량, 속도 제한, 비용과 무료 한도
- 서버 측 비밀키 보관, 캐싱·재시도·실패 시 표시, 서비스 중단 위험

공식 문서로 확인되지 않은 가격·권리는 **미확인**으로 표시한다. 무료 호출 가능 여부만으로 사용권을 확정하지 않는다.

### 4.2 파일럿 조건 및 대상

- 파일럿 후보: `MSFT`, `GOOGL`, `AVGO`, `VRT`, `JPM` (미국 기술·반도체·산업 인프라·금융을 포괄하는 고정 5종목; 필요시 사유를 남기고 교체).
- 승인된 이용권과 사용 가능한 인증 수단이 확보된 경우에만 실제 API를 호출한다. **비밀키는 코드·로그·보고서·ZIP·브라우저 localStorage에 넣지 않는다.**
- 각 종목에 대해 티커, 거래소, 최신 미국 정규장 종가 기준일, USD 가격, 52주 고가 및 관측기간, 조정 방식, 데이터 출처, 조회시각, 지연 여부를 기록한다.
- 동일 기준의 SPY·업종 ETF 수익률을 확인할 수 있을 때만 상대하락 신호를 계산한다. 근거가 부족하면 `평가 불가`로 표시한다.
- 다른 공식·신뢰할 만한 공개 자료와 표본 대조한다. 차이는 숨기지 않고 기록한다.
- 공급자 권리·인증·가격 데이터가 확보되지 않으면 **실제 조회 0건**으로 명시하고, 가짜 실시간 값을 만들지 않는다. 대신 공급자 어댑터와 고정 합성 응답으로 계약·오류·누락 시험을 구현한다.
- 데이터 조회는 읽기 전용이며 자동매수·실거래·알림 남발 기능을 구현하지 않는다.

## 5. 200종목 확대를 위한 검증 가능한 준비

- 기존 후보 16개를 무조건 활성화하지 않는다. 종목별 상장 상태, 시총 기준, 재무 건전성, 업종, 데이터 출처·검증일을 명시한다.
- 적격성 검증을 통과한 기업만 활성 목록으로 이동한다. 확인 불가 기업은 보류, 기준 미달은 제외로 분리한다.
- 최대 200개 감시를 목표로 **종목 목록의 버전 관리와 증분 검증 절차**를 마련하되, 실제로 검증한 종목 수만 보고한다.
- 200개 동시 수집을 실행했다고 주장하려면 실제 공급자·호출량·성공률·비용 증거가 있어야 한다. 그렇지 않으면 합성 부하시험이라고 표시한다.
- 레이더 점수는 사업 경쟁력25, 성장·재무20, 과잉반응15, 밸류20, 악재 일시성10, 촉매10의 100점 체계를 유지한다. 가격 낙폭만으로 높은 점수를 자동 부여하지 않는다. 근거·반대 시나리오가 없으면 평가 불가.

## 6. 앱 통합 및 모바일·보존 시험

- 기존 위험관리 메뉴의 레이더 UI와 3단계 전체 백업 v6 기능을 유지한다.
- `실제 데이터`, `데모`, `미연결`, `오류`, `기준일 지연` 상태를 명확하게 구분한다.
- 360·390·430px에서 메뉴 진입, 목록·검색·정렬·필터·상세·뒤로가기·새로고침, 데이터 실패/재시도, 가로 넘침, 44px 터치 영역을 확인한다.
- 일반·ISA·해외·연금 계좌별 합성 데이터 추가·수정·삭제 및 전체 백업→복원→되돌리기 회귀시험을 실행한다. 복원 중 저장공간 부족·손상 파일·중단 상황을 포함한다.
- 서비스 워커 변경이 필요해 보이더라도 운영 반영 없이 별도 제안·독립 시험으로만 남긴다.
- Chromium 모바일 재현과 **실제 Android 기기 시험을 구분**해 보고한다. 실제 기기에 접근할 수 없다면 미실시로 기록한다.
