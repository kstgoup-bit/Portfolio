## 핵심 발견
1. **호출하지 않은 이유**: Alpha Vantage·Twelve Data·Massive는 개인 무료 조회·표시·저장 조건이 약관상 불분명하거나 제한적이고, Tiingo는 개인 사용 문구가 가장 명확하나 표시·저장이 불분명하며 약관 본문을 직접 열람하지 못했습니다. 무료 키는 사용자 본인 가입이 필요합니다. (`provider-terms-stage18.md`)
2. **기존 앱의 현재가는 출처 미보증**: 비공식 야후 주소를 무료 제3자 중계로 받아옵니다. HAS 기준 "검증된 실제 가격"이 아닙니다.
3. **기본 비밀번호는 화면 가림 수준**이며 데이터는 평문 저장. API 키는 URL 쿼리로 직접 호출. 12px 미만 글씨 선언 143/634.
4. 서버 없이 키를 안전히 쓰는 방법은 **순태씨 PC 로컬 실행기 + 환경변수**뿐(브라우저 직접 호출 부적합).
