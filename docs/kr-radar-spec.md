# 국장 레이더 설계 명세 (7단계, 합성 연구 전용)

기준일 2026-10-29. 구현 범위는 `kr-radar/`의 순수 함수와 합성 시험까지다. 실제 시세 연결·보유 데이터 읽기·알림·주문·운영 UI는 없다.

## 1. 판정 상태 (모든 결과는 `automaticAction:false, order:null, notification:null, actualActiveCount:0`)

| 구분 | 상태 | 뜻 |
|---|---|---|
| 매수 | 평가 불가 | 데이터 결측·오래됨·형식 오류. 점수 없음 |
| 매수 | 제외 / 판단 보류 | 상폐·관리종목·SPAC 등 제외, 거래정지·미확인·가치함정·지배구조 우려는 보류 |
| 매수 | 위험 우선 · 보류 | 유상증자·CB·BW·물적분할·비적정 감사의견 등 위험 표식은 총점보다 우선 |
| 매수 | 신호 없음 | 낙폭·상대 부진 신호가 없으면 품질이 좋아도 점수를 내지 않음 |
| 매수 | 관찰 / 심층 분석 후보 / 최우선 분석 후보 | 점수 55 / 70 / 85 이상. 분석 우선순위일 뿐 매수 지시 아님 |

| 매도 | 장기 보유 검토 / 비중 점검 / 일부 매도 검토 / 투자 논리 훼손 재검토 | 미국장 엔진과 같은 이름 |

| 통합 | 상충 근거 재검토 / 위험 확인 우선 / 정보 제공 / 평가 불가 | 매수·매도 결과가 충돌하면 평균내지 않고 분리해 재검토 |

## 2. 매수 100점 모델 (초안)

가중치는 **백테스트·성과 검증을 거치지 않은 설계 가정**이다. 추천 정확도를 주장하지 않는다.

| 요소 | 배점 | 산출 | 한계 |
|---|---|---|---|
| 사업 경쟁력·업황 | 20 | 평가자 입력 + 근거(출처·기준일·연결/별도·재무 기간·공시번호·반대 시나리오) | 정성 판단. 경영진 신뢰·정책 변화는 계량 불가 |
| 재무건전성·현금흐름 | 20 | 위와 동일 (ROE·현금흐름·부채는 근거 문장에 명시) | 업종 간 비교 불가, 금융업은 별도 |
| 낙폭·과잉반응 | 15 | 낙폭 구간점수(20%→5, 30%→8, 35%→11, 45%→13) + 시장 대비 −15%p 이하 +1 + 업종 대비 −10%p 이하 +1 | 구간은 미국장 엔진의 기본 임계와 같은 연구 가정. 하락 원인은 점수에 없음 |
| 업종 보정 밸류에이션 | 15 | 아래 3절 | 자체 PBR 범위 기준이며 업종 평균과의 비교가 아님 |
| 주주환원·지배구조 | 15 | 배당(≤5) + **실제 소각**(≤6, 공시번호 필요) + 지배구조 이상 없음(4) | 자사주 취득만으로는 0점 |
| 악재 일시성·희석 위험 | 10 | 평가자 입력 + 근거 | 위험 표식은 점수와 별개로 우선 차단 |
| 회복 촉매 | 5 | 평가자 입력 + 근거 | 촉매 시점 예측 불가 |

점수 미산출 조건: 신호 없음, 근거 하나라도 누락·형식 오류·기준일 경과(150일)·확인일 경과(30일)·정정공시로 대체, 시세 기준일 4일 초과, 정규장 아님, KRW·KST 아님, 수정주가 기준 불일치, 업종 구분·사이클 위치 미확인(경기민감), 금융업 자본적정성 미확인, 위험 표식(알 수 없는 표식 포함).

과최적화 위험: 구간과 가중치는 소수의 합성 사례로만 점검했다. 실제 데이터로 구간을 조정하면 같은 데이터에 맞춘 과적합이 될 수 있으므로, 조정은 기간을 나눈 사후 검증과 사용자 승인 후에만 한다.

## 3. 국내 특화 평가

- **PBR 단독 매수 금지**: 낮은 PBR이어도 ROE가 과거 중앙값의 70% 미만이거나 적자, 이익 감소 추세(저평가 착시), 경기민감 업종의 이익 정점이면 `trap-risk`로 점수를 3점 이하로 제한하고 보류한다.
- **경기민감(반도체·조선·자동차)**: 사이클 위치(`trough/mid/peak/unknown`)가 `unknown`이면 평가 불가. `peak`에서는 낮은 PER·PBR을 신뢰하지 않는다. 저점에서의 높은 PER은 감점하지 않는다(PBR 위주).
- **금융**: 자본적정성 확인과 자기자본비용 가정이 필요하고, 적정 PBR = ROE ÷ 자기자본비용 대비 비율로 본다. 부채비율 규칙은 쓰지 않는다.
- **주주환원**: 자사주 *취득*과 *소각*을 구분한다. 소각은 공시번호(14자리)와 출처가 있어야 인정한다. 배당 삭감은 배당 점수 0.
- **희석·지배구조 위험**: 유상증자, CB/BW, 물적분할, 대주주 이해상충, 횡령·배임, 감사의견 비적정, 계속기업 불확실성, 자본잠식은 위험 표식으로 총점보다 우선한다.
- **정정공시**: 근거의 공시가 정정본으로 대체되면 그 근거는 무효이고 최신 정정본 근거가 있어야 한다.

## 4. 매도 정책

- 수익률은 정보 표시용이다. +20/+30/+50% 등 어떤 수익률도 매도 신호나 상태 입력이 아니다(500% 수익도 다른 근거가 없으면 `장기 보유 검토`).
- `투자 논리 훼손 재검토`: 5요인(경쟁력·실적·현금흐름·부채·점유율) 중 구조적 악화, 또는 대주주 이해상충·물적분할.
- `비중 점검`: 사용자가 승인한 가정 한도(계좌·종목·업종)를 초과.
- `일부 매도 검토`: 고평가 괴리(과거 상단 초과 AND 성장 ≤ 전망 AND FCF 수익률 < 2%) 또는 경기민감 이익 정점(평균 대비 1.3배 이상) **그리고** 교체 근거(대안의 질·순 기대차익·현금 필요)가 모두 있을 때만.
- 고평가·이익 정점만 있으면 `평가 불가`(교체·현금 필요 검토 필요).
- 자사주 취득만 하고 소각하지 않은 경우, 배당 삭감은 사유로 표시하되 단독으로 상태를 바꾸지 않는다.
- 거래정지·상폐 위험·관리종목은 `긴급 위험 확인`. 체결 자체가 불가능할 수 있다는 점을 함께 표시한다.

## 5. 종목 분류와 계좌

- 분류 함수 `classifyInstrument`: 보통주만 개별주 규칙. 우선주·ETN·리츠는 보류(별도 규칙 미정), SPAC·상폐·관리종목·레버리지/인버스 ETF는 제외. 상태 항목 하나라도 미확인이면 보류. 종목명과 유형이 어긋나면(ETF 표기인데 보통주 등) 보류.
- **ETF는 별도 그룹**: 국내주식형·해외주식형·커버드콜만 ETF 규칙 대상이고 개별주 PER/PBR·실적 규칙은 적용하지 않는다. 채권·원자재·기타는 보류. 이번 단계에서 ETF 점수 모델은 구현하지 않았다.
- **계좌별 편입 가능성은 추정하지 않는다.** `accountReview`는 사용자가 날짜와 https 출처를 붙여 확인한 규칙이 있을 때만 답하고, 없으면 `확인 필요`다.
- 역할: 연금저축·IRP → `core`, 일반 → `satellite`, ISA → `undetermined`(정책 미정). 코어와 새틀라이트 정책은 섞어 적용하지 않는다.
