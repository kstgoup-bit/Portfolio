# 감시 화면 설계(작업 D)와 변경 제안서(§9)

## 감시 화면 표시 항목
공급자 / 기준일 / 가격 유형(종가·지연·실시간) / 통화 / 유효기간(기준일+4일) / 갱신 오류 / 종목별 검증상태.
집계: 활성 감시(실조회+가격검증+유효+오류없음)와 실가격 검증 수, 합성, 캐시, 미검증을 **따로** 표시. 캐시는 실제 감시로 세지 않음.

## 신호 해석 주의 (화면에도 표시)
단순 하락률은 투자 판단이 아닙니다. 거래정지·상장폐지·실적 악화·기업행위(분할·배당)로 오탐이 날 수 있어 사람이 확인해야 합니다. 실데이터 백테스트는 승인 ③ 전 실행하지 않으며 합성 백테스트는 연구용입니다.

## 변경 제안 (자동 채택 아님, 금지사항 해제 아님)
1. **목표 역산 대시보드**: 5년 10억 목표에 필요한 연수익률·월 투입액을 계산 표시(입력은 본인이 직접). 근거: 목표 대비 위치가 보여야 무리한 집중투자를 줄임.
2. **최악 시나리오 카드 고정**: 위험 화면 맨 위에 "가장 큰 종목 −40% 시 내 자산 변화".
3. **충동 매도 점검**: 매도 전 판단기록(이유·재검토일) 한 줄을 요구하는 선택 기능.
4. 공급자 선정은 표시 권리 확인 후(승인 ① 선행조건).
