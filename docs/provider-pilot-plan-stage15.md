# 시세 공급자 소규모 파일럿 계획 (15단계, 계획·설정 화면만)

상태: **미실시.** 실제 시세 검증 0건, 호출 0회, 활성 감시 종목 0개(합성 0/캐시 0/실조회 0). 유료 가입·실호출·외부 전송은 별도 명시적 승인 후에만 가능. 화면(`mobile-lab/invest.html` 시세 파일럿 탭)의 사용 스위치는 잠겨 있고 꺼짐입니다.

- 후보: MSFT, GOOGL, AVGO, VRT, JPM (검증용 예시, 보유와 무관). 읽기 전용, 1개월.
- 점검: ① 공급자 가격 vs 독립 기준값 일치율(종목·일자별, 허용오차 사전 합의) ② 결측·지연 일수 ③ 수정주가·배당·분할 처리 ④ 호출량·월 예상 비용(상한 설정) ⑤ 사용권·저장권·재배포 조항(문서 확인, 개인 사용 가능 여부) ⑥ 네트워크 실패 시 기존 기록 무변경.
- 승인 전 선결: 공급자 선택, 비용 상한, 키 보관 방식(저장소·채팅에 키 금지), 약관 확인.
- 합격 기준 예: 5종목 × 20거래일 종가 일치율, 결측 0 또는 설명 가능, 조정 방식 문서화.
- KRX 종목 식별 조회는 "어떤 종목인지" 확인이며 가격 제공이 아닙니다.
