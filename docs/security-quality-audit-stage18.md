# 보안·모바일 품질 조사 (18단계 작업 D) — 비밀값 비출력, 수정 없음

## 1. 기본 비밀번호 상수 (코드 경로)
- `portfolio_v5.html` 2285행: 기본 비밀번호 상수 `PW_DEFAULT` 정의. 7127·7716행: 저장된 `v5_pw`(localStorage)가 없으면 상수와 비교. 7720행: 일치 시 `sessionStorage v5_auth=1`로 통과, 7736행에서 자동 통과 판단.
- 의미: 이 잠금은 **화면 가림 수준**이다. 소스를 보는 사람은 누구나 상수를 알고, 개발자도구로 `sessionStorage v5_auth`를 직접 1로 쓰면 통과된다. 데이터는 암호화되어 있지 않다(localStorage 평문).
- 위협: ① 저장소가 공개되면 기본값 노출 ② 기기를 잠시 빌려주면 화면 잠금만 믿을 수 없음 ③ 기본값을 바꾸지 않은 상태 유지.
- 최소 대안(승인 필요, 이번엔 미적용): 첫 실행 시 기본값 사용 중이면 변경 안내 배너 → 상수를 소스에서 제거하고 첫 설정 화면으로 대체. 진짜 보호가 필요하면 기기 잠금(삼성 보안 폴더 등)이 더 효과적.
- 지시: 공개 저장소 전환 금지(유지).

## 2. 브라우저 저장 API 키 (코드 경로)
- `v5_geminiKey`, `v5_alphaVantageKey`: 입력 시 localStorage 저장(1969·1987행), 요청 때 URL 쿼리(`?key=…`, `&apikey=…`)에 붙여 **직접** 호출(2046·2083·2138·2690·6570행). 
- 위험: URL 쿼리의 키는 브라우저 기록·프록시·공급자 로그에 남을 수 있음. 같은 출처의 어떤 스크립트든 읽을 수 있음. 백업은 허용 키 목록 방식이라 이 키들은 **백업에서 제외**됨(`backup/core.js`, 시험으로 확인).
- 확인 범위: 코드 경로상 키가 들어간 요청은 프록시를 거치지 않는 직접 호출이며, 프록시를 거치는 요청(야후 지수·뉴스 RSS)에는 키가 없음.
- 최소 대안: 키 필요 기능은 쓸 때만 입력하고 세션 메모리에만 두기(저장 안 함), Gemini는 헤더(`x-goog-api-key`) 방식 검토. 이번엔 미적용.

## 3. 기존 앱의 가격 출처 (신규 발견, 중요)
앱은 시세를 **야후 파이낸스 비공식 주소**(`query1/query2.finance.yahoo.com`)에서 **무료 제3자 중계(allorigins.win, corsproxy.io, codetabs.com, corsproxy.org)** 를 통해 가져온다(2663~2739, 2917, 4289행). 의미: 중계 서버가 값을 바꿀 수 있고, 약관상 개인 사용 허용 여부가 확인되지 않았으며, 공급자·기준 시각이 보증되지 않는다. 따라서 **앱이 보여주는 현재가는 HAS 기준의 "검증된 실제 가격"이 아니다**(미확인). 이번 단계에서 이 코드는 실행·변경하지 않았고, 시험은 외부 요청을 모두 차단했다.

## 4. 작은 글씨·대비 (측정)
`portfolio_v5.html`의 `font-size` 선언 634개 중 **12px 미만 143개**(9px 20, 10px 49, 10.5px 1, 11px 69, 11.5px 4), 투명도(rgba) 색 선언 97개, 터치 영역 `min-height:44px`류 3곳. 순태씨 원칙(12px 이상·진한 색)과 어긋남. CSS 일괄 상향은 레이아웃 깨짐 위험이 있어 **이번엔 변경하지 않고**, 화면별 시험과 함께 별도 승인 후 진행을 권장(우선순위: 잠금화면 10px 문구, 하단 탭, 표 보조 글씨).

## 5. 자동 시험 범위와 한계
360/390/430px 진입·탭·뒤로가기·오프라인·백업 화면은 기존 25묶음과 17단계 10묶음이 다룸. **실제 갤럭시 기기 시험 0건.** 체크리스트: `docs/galaxy-checklist-stage18.md`.
