# 거래원장 설계·불변조건 (17단계 작업 D) — 설계, 실데이터 적용 없음

## 거래 유형
매수 BUY, 매도 SELL, 배당 DIV, 수수료 FEE, 세금 TAX, 환전 FX, 현금 입금 DEPOSIT·출금 WITHDRAW, 주식분할 SPLIT, 계좌 이전 TRANSFER_IN/OUT.
공통 필드: `txId`(고유), `accountId`, `type`, `ticker?`, `qty?`, `price?`, `currency`, `fxRate?`, `fxDate?`, `occurredAt`, `settledAt?`, `note?`. 키는 새 이름(예: `has_ledger_v1`)을 쓰며 `v5_ledger`(가계부)와 섞지 않는다.

## 계좌 분리
일반/국내/해외 직접/연금 4계좌를 `accountId`로 분리 집계. 계좌 간 합산은 화면에서 명시한 합산 보기에서만. 해외 직접투자 양도세는 추정치(가정 표기), 국내·연금 세금은 검증 전 계산하지 않음. 세무 자문처럼 표시하지 않음.

## 불변조건 (자동 시험 대상)
1. 계좌·종목별 보유 수량 ≥ 0 (매도가 보유를 초과하면 해당 종목 손익은 "계산 불가", 거래는 삭제하지 않고 표시).
2. 현금 잔액 = Σ입금 − Σ출금 − Σ매수대금 + Σ매도대금 + Σ배당 − Σ수수료·세금 ± 환전 (계좌·통화별).
3. 실현손익 + 미실현손익 = 총손익 (같은 원가 방식, 수수료 반영 규칙 동일).
4. SPLIT은 총원가 불변, 수량·단가만 변환.
5. 같은 `txId` 중복은 병합(내용 동일) 또는 충돌 표시(내용 상이) — 자동 덮어쓰기 금지.
6. 외화 거래는 `fxRate` 없으면 원화 환산 "계산 불가".
7. 내보내기→복원 후 모든 집계값이 비트 단위로 일치(복원 왕복 시험).
8. 거래 순서를 바꿔 입력해도 `occurredAt`·`txId` 정렬로 결과 동일.
9. 이전(TRANSFER)은 원가·취득일을 승계, 손익 발생 없음.

## 현황
15단계 원장(`invest/ledger.js`)은 BUY/SELL/배당 일부와 44항목 원가 검증표를 통과(합성). 위 SPLIT·TRANSFER·현금·환전 불변조건은 **설계만, 미구현**(부분 완료).
