## 3. 휴대폰 단독 사용을 충족하는 안전한 대안 비교 (구현·생성은 하지 않음)
공통 전제: **실전 키를 브라우저(앱·GitHub·백업·localStorage)에 넣지 않는다.** 주문·계좌조회·자동매매 경로는 어떤 안에서도 만들지 않는다.

| 안 | 구조 | 휴대폰 단독 | 키 위험 | 비용·약관 | 시세 신뢰 | 승인·선결 | 평가 |
|---|---|---|---|---|---|---|---|
| A. 개인 HTTPS 중계(서버리스) | 서버가 KIS 키 보관, 폰 앱은 시세만 조회 | 가능 | 서버 비밀 저장소에 실전 키 존재(주문 권한 있음, 정책 코어로 시세 경로만 허용) | 호스팅 요금·KIS 약관 해석 미확인 | 공급자 표기에 따름 | 클라우드 생성 승인, KIS 약관 문의 | 가장 완결적이나 선결조건 가장 많음 |
| B. 집 PC 실행기 → 시세 스냅샷 파일 | PC에서 하루 1~2회 조회(키는 PC 환경변수에만), 결과 JSON을 안전한 저장 위치에 올리고 폰 앱은 읽기만 | 폰은 읽기만(PC 필요) | 키가 폰·클라우드에 없음 | 클라우드 저장소 필요 시 승인 | 종가·준실시간 | KIS 1회 실행 승인(승인 B) | **지금 가장 안전**. 실시간 감시는 포기, 정확한 종가 기준 판단에 적합 |
| C. 공공 시세 API(금융위 주식시세, 공공데이터포털) | 읽기 전용 서비스 키로 전일 종가 조회 | 가능 | 시세 전용 키(주문 불가), 노출 시 호출량 도용 위험만 | 무료·약관 별도 확인 | 종가 T+1(독립 검증가로 적합) | 키 발급(사용자), CORS 가능 여부 미확인 | KIS와 **독립된 검증 가격**을 만드는 데 유용(교차검증 `quote-crosscheck` 연계) |
| D. KIS 모의투자 키로 시세만 | 모의 키·계좌로 시세 조회(실전 주문 권한 없음) | 중계·PC 필요 | 실전 주문 불가 → 위험 격리 | 모의 신청 필요 | 모의 서버가 지원하는 시세 범위·정확도 **미확인**(모의 한도는 더 낮음) | 모의투자 신청, 지원 범위 문의 | 키 위험은 최소지만 시세 품질 미확인 |
| E. 사용자 직접 입력 | 지금 방식 | 가능 | 없음 | 없음 | **미검증**(앱이 판단 보류로 처리) | 없음 | 현 상태 유지 |

**권고 순서**: ① E를 유지(지금과 동일, 판단 보류) → ② C로 독립 검증가 확보 가능성을 먼저 확인(키 발급은 사용자 몫, 호출은 별도 승인) → ③ B로 KIS 종가 스냅샷(승인 B 필요) → ④ 약관·권한 문의 회신 후에만 A를 판단. D는 KIS가 "모의 시세 지원 범위"를 답하면 B의 키 위험을 줄이는 선택지로 검토.
브라우저에 실전 키를 직접 넣는 방식은 **채택하지 않습니다**(요청대로).

## 4. 순태씨께 필요한 것 — 최소 3가지 (이전 5가지에서 축소, 같은 항목 반복 없음)
1. **KIS Developers 포털 "서비스 이용안내"(about-howto) 본문 화면 캡처** — 이용료·호출 한도·토큰·앱키 재발급·IP 유무가 한 번에 확인됩니다(제 도구로는 본문이 읽히지 않았습니다).
2. **포털 "이용약관" 팝업 본문 캡처** — 개인용 중계 허용(항목 6) 판단용. 키 값은 가리고.
3. **KIS 고객센터 문의 1건**(복사해서 보내시면 됩니다): "KIS Developers 실전 앱키를 시세 조회 전용으로 제한할 수 있습니까? 본인 1인 전용 서버가 키를 보관하고 본인 휴대폰 앱에만 시세를 전달하는 구성이 약관상 개인 이용에 해당합니까? 해외(미국) 시세는 실시간입니까 지연입니까, 별도 신청·비용이 있습니까? 실전 초당 호출 한도는 얼마입니까?"
(이미 전달하신 이전 단계 캡처는 다시 요청하지 않습니다. 위 1~3의 회신이 오기 전에는 KIS 연결 구현에 착수하지 않습니다.)

## 5. 결론
KIS 실제 시세 연결에 필요한 선결사항은 **확인된 것과 아닌 것이 분리되어 명확히 정리**되었습니다. 이번에 새로 공식 확인된 것은 "해외 지연 시세 항목 존재", "접근토큰 폐기 API 존재", "모의/실전 키 분리"이며, 주문 권한 제한·IP·약관 해석·현행 한도·비용은 여전히 미확인입니다. 연결 구현·서버 생성·실전 호출은 하지 않았습니다.
