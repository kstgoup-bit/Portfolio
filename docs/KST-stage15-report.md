## 2. 구현 범위
**A. 투자기록·손익 (`invest/ledger.js`)** — 별도 거래기록(매수·매도·분할·배당·종목변경·입출금, 계좌 4종) 기반 이동평균 원가, 수량·평균단가·실현/평가손익·총손익·단순수익률, XIRR·TWR, 해외 양도세 **추정**(확정 아님), 앱 보유 읽기 전용 변환 및 대조, CSV/JSON 가져오기·내보내기·id 병합(충돌은 덮어쓰지 않음). 자료 부족은 숫자를 만들지 않고 "자료 부족/계산 불가". 검증표 44항목 전부 일치(`docs/KST-stage15-ledger-verification.md`).
**B. 위험관리 (`invest/risk.js` + 화면)** — 전체·계좌·종목·테마 비중, HHI·실효 종목 수, ETF 간접 노출(검증된 최신 자료만, 없으면 미확인), 사용자 설정 기준 초과 시 "점검 알림"(매도 지시 아님), 하락 시나리오 손실액·비율·계산식·가정 표시(겹침은 합산하지 않음), 투자 판단 기록(근거·반증 조건·점검일·변경 이력은 추가만 가능, 파일 내보내기/가져오기).
**C. 백테스트 1차 (`invest/backtest.js`)** — `docs/backtest-design-stage15.md` 참조. 미래정보 누출 검사, 훈련/검증 분리, 후보 탐색 과최적화 경고, 비용·초과수익, 메타데이터 경고, 재현 지문, 합성 생성기.
**화면** — `mobile-lab/invest.html`(위험·손익·백테스트·시세 파일럿 탭). 파일은 화면 안 메모리에서만 읽고 저장·전송하지 않음, CSP로 네트워크 차단. 스크린샷 `docs/stage15-screens/`(합성 자료).
**시세 파일럿** — 계획·설정 화면만(`docs/provider-pilot-plan-stage15.md`). 사용 스위치 잠김.

## 3. 미구현·한계·위험
- 앱(`portfolio_v5.html`) 본체에는 연결하지 않음: 거래기록·판단 기록의 앱 내 저장은 **백업 스키마 확장**이 필요해 별도 승인 항목. 현재는 실험실에서 파일로 보관.
- 앱은 종목별 합계만 저장하므로 실현손익은 거래기록을 따로 가져와야 계산됨. 기록 누락 시 결과가 틀릴 수 있어 대조 기능으로 불일치를 표시.
- 세금: 국내 과세·연금 인출세는 계산하지 않음(미확인), 해외 양도세는 사용자 입력 가정의 추정치.
- 환호성은 가격 기반 대용 규칙뿐. 실데이터 연결·사용권·상장폐지/생존편향 자료 미구현. 합성 결과는 투자 판단에 사용 불가.
- 실제 갤럭시 기기 시험, 실제 시세 검증, 실데이터 백테스트 모두 미실시.
- 신규 모듈은 UMD 순수 모듈이며 실험실 번들(`mobile-lab/invest-bundle.js`)은 `node tools/build-invest-lab.cjs`로 생성(시험이 최신 여부 확인).
