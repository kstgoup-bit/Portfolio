# 갤럭시 실기기 점검표 (10~15분, 휴대폰만)

자동 시험(Playwright 360/390/430px)은 **실기기 통과가 아닙니다.** 아래를 직접 해보시고 결과를 알려 주세요. 현재 실기기 시험 **0건**.

주소는 개발 PC에서 연 실험실 화면을 쓰거나, 승인된 방법으로 연 화면만 사용합니다(운영 앱·기존 기록은 건드리지 않습니다).

1. (1분) 실험실 첫 화면이 열리고 글자가 읽히는가? 가로 스크롤이 없는가?
2. (2분) 탭(원장·위험·시험·감시)을 차례로 눌러 보고, **뒤로가기**로 이전 탭에 돌아오는가?
3. (2분) 초안 입력 후 "저장" 누르고, 브라우저 탭을 닫았다 다시 열어 복원 안내가 뜨는가?
4. (1분) 화면 회전(세로→가로→세로) 후 입력 내용이 유지되는가?
5. (2분) 다른 앱으로 갔다 돌아왔을 때 화면이 정상인가?
6. (2분) 파일 가져오기/내보내기 버튼: 파일 선택창에서 취소해도 화면이 멀쩡한가?
7. (1분) 감시 화면: 공급자·기준시각·가격 유형·통화·유효기간·검증상태가 보이고, 활성 감시가 **0개**로 표시되는가?
8. (1분) 비행기 모드: 이미 열려 있는 화면의 계산은 되는가? (※ 오프라인에서 새로 여는 것은 지원하지 않음 — 서비스워커가 없음)
9. (1분) 글자가 12px 이상 크기로 보이고 흐린 회색 안내문이 없는가?
10. (1분) 기존 포트폴리오 앱의 기록이 그대로인가(숫자 몇 개만 눈으로 확인)?

결과 기록: 항목별 ○/×/메모. × 항목은 기기 모델·Android 버전·브라우저와 함께 알려 주세요.
