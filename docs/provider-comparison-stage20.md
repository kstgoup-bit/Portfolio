# 20단계 시세 경로·공급자 비교표 (확인일 2026-10-29, 실제 호출 0회)

**읽는 법:** 아래 "확인"은 이번 세션에서 공식 페이지 본문을 직접 읽은 것, "2차"는 제3자 문서에서만 확인한 것, "미확인"은 열람하지 못했거나 문서에 없는 것입니다. 무료라는 사실이 화면 표시·저장·재배포 권리를 뜻한다고 추정하지 않습니다. 법률 해석이 아닙니다.

## 1. 현재 앱의 두 가격 경로 (섞어 쓰지 않음)

| 키 노출 | 가격 경로에 API 키 없음(GAS 주소는 localStorage 저장) | 키 없음. 단 Gemini·AlphaVantage 키는 별도 경로에서 URL 쿼리로 전송 |
| 판정 | 미검증 가격 | 미검증 가격(중계 출처) |
