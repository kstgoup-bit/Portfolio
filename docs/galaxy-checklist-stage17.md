# 갤럭시 실기기 점검표 — 17단계 (HAS 이름 확인, 10~15분)

자동 시험은 실기기 통과가 아닙니다. 실기기 시험 현재 **0건**. 아래는 순태씨가 직접 해보실 항목입니다. **실행 전 기존 앱 화면에서 보유 종목 수·금액 몇 개를 메모해 두세요.**

1. 새 버전이 올라간 주소(승인 후 배포된 경우에만)로 앱을 열어 탭 제목·잠금화면·머리글이 HAS인가?
2. 비밀번호 입력 후 보유 종목·금액이 메모와 같은가?
3. 홈 화면에 이미 설치된 아이콘 이름이 바뀌는가, 그대로인가(바뀌지 않아도 정상일 수 있음)? 두 개가 따로 설치돼 있지 않은가?
4. 앱을 완전히 닫았다 다시 열어도 데이터가 같은가?
5. 비행기 모드에서 앱을 열었을 때 화면이 뜨는가?
6. 백업 내보내기 후 복원 미리보기가 정상인가(적용은 하지 마세요).
7. 360~430px 폭에서 머리글 "HAS · Hidden Alpha System"이 잘리지 않는가?
결과는 항목별 ○/×/메모로 알려 주세요.
