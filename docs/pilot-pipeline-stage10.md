# 읽기 전용 파일럿 파이프라인과 신호 구분 (10단계)

합성 입력 전용이며 실제 호출은 없습니다. 종목별 기록은 아래 순서로만 이동하고 건너뛸 수 없습니다. 마지막 단계는 정책(`POLICY.realActivationAllowed=false`)으로 막혀 있어 **어떤 종목도 활성화되지 않습니다.**

미연결 → 권리 확인 → 원본 무결성 → 날짜/시장/시간대 → 수정주가 일관성 → 벤치마크 대조 → 2차 출처 검증 → 수동 승인 → 읽기 전용 활성화

| 단계 | 통과 조건 | 보류 예 |
|---|---|---|
| 권리 확인 | 공급자 판정이 후보 적격 | 미확정·부적격 |
| 원본 무결성 | 해시 일치, 행 수 일치, 공식 출처 | 변조·예시 파일 |
| 날짜/시장/시간대 | 정규장 거래일·최신·시간대 일치 | 휴장일, 시간외, 미래, 오래됨 |
| 수정주가 일관성 | 종가와 52주 고가가 같은 기준 | 기준 혼합, 분할 구간 비조정 |
| 벤치마크 대조 | 동일 구간·같은 조정·같은 통화 | 구간 불일치 |
| 2차 출처 검증 | 독립 출처, 종가 차이 0.5% 이내 | 동일 공급자, 불일치 |
| 수동 승인 | 사용자가 날짜와 범위를 적은 승인 | 승인 없음, 다른 주체 |

나중에 정정공시·출처 충돌·약관 변경이 생기면 `invalidate()`로 미연결에 되돌리고 점수를 만들지 않습니다.

## 서로 다른 세 지표
- **52주 낙폭**: 종목 자신의 52주 고점 대비(-20/-30/-35% 구간). 고점일은 종목마다 다릅니다.
- **동일 구간 상대수익률**: 시작·종료일, 조정 기준, 통화가 같을 때만 계산(%p).
- **낙폭 차이**: 종목과 시장의 낙폭 차이로, 고점일이 다르면 상대수익률이 아닙니다.
세 값은 별도 필드로 나오며 하나의 '시장 대비 부진' 숫자로 합치지 않습니다(`combinedScore:null`).

기존 매수·매도 레이더, 연금 코어/해외 새틀라이트 중복 노출·현금 부족·구조적 악화 경고는 변경하지 않았습니다. 100점 모델은 백테스트하지 않았으며 예측 정확도가 아닙니다.
