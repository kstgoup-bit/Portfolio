# 갤럭시 사용자 점검표 — 20단계 (약 15분)

현재 갤럭시 실기기 시험 **0회**입니다(자동 시험은 실기기 통과가 아닙니다). 이 점검표는 개발 브랜치 소스 기준이며 **홈 화면에 설치된 앱은 이 단계에서 바뀌지 않았습니다**(배포 안 함). 시험하려면 개발 파일을 따로 열어야 합니다(방법을 모르시면 말씀해 주세요). 작성 시작 전에 기존 앱의 보유 종목 수와 총 평가금액을 메모해 두세요.

| # | 할 일 | 기대 결과 | ○/×/메모 |
|---|---|---|---|
| 1 | 앱을 열고 🛡️ 위험관리 → 🧪 원장 시범 | 맨 위에 "시범 화면 · 합성 데이터 · 실제 보유·수익 아님" | |
| 2 | 시범 화면을 끝까지 내려 "기존 보유 → 원장 이전 미리보기" 확인 | "합성 보유 · 저장 안 함", 이력은 "이력 미확인" | |
| 3 | 휴대폰 **뒤로가기** | 이전 화면으로 돌아가고 앱이 종료되지 않음 | |
| 4 | 시범 화면에서 새로고침 | 입력한 시험 거래가 사라짐(안내대로) | |
| 5 | 현황·일반·해외·배당 탭에서 글씨가 너무 작거나 흐린 곳 | 없음. 있으면 화면 이름·위치 메모 | |
| 6 | 기간 버튼(1주~4년), 목표 ± 버튼, 수정·추가 버튼을 손가락으로 | 한 번에 눌리고 옆 버튼이 눌리지 않음 | |
| 7 | 해외 탭의 "가격 신뢰도" 띠 열기 | "미검증 가격 · 출처·기준시각 확인 필요" | |
| 8 | 비행기 모드에서 앱 열기 | 화면·보유 종목이 보임 | |
| 9 | 앱 기존 종목 수·총 평가금액 | 처음 메모와 같음 | |
| 10 | 백업 내보내기 → 복원 **미리보기까지만**(적용 금지) | 오류 없이 미리보기 | |

**오류 기록란:** 화면 이름 / 한 일 / 보인 것(가능하면 화면 캡처) / 시각
결과를 알려주시면 "갤럭시 실기기 시험 N회"로 반영합니다.
