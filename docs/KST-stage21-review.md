## 2. 실전 키의 위험(정확히)
실전 키는 시세 전용이 아니다. 알려진 바로는 주문 API도 같은 키로 호출되므로 유출 시 실제 매매로 이어질 수 있다(포털의 제한 설정 존재 여부 미확인). 따라서:
- 키를 HAS의 HTML·localStorage·URL·백업·ZIP·로그·PR·채팅에 넣지 않는다.
- HAS 코드에 주문·계좌조회 엔드포인트를 만들지 않는다(시세 조회 엔드포인트만 허용 목록으로 고정).
- 자동매매 없음.

## 4. 안 1 상세 설계 (코드는 승인 후 작성, 지금은 설계만)
- 실행기: `tools/kis-quote-runner.cjs`(신규 예정). `tools/us-pilot-runner.cjs`와 같은 안전장치: `--live`+저장소 밖 승인 파일+호출 전 장부 기록, 시험 모드에서 외부망 차단(코드 4 종료).
- 키는 환경변수 `KIS_APP_KEY`·`KIS_APP_SECRET`으로만 받고, 헤더로만 전송, 로그·출력에 마스킹. 토큰은 메모리 캐시만(파일 저장 안 함).
- 호출 허용 목록: 토큰 발급 1종 + **국내주식 현재가 조회** 1종(해외는 별도 확인 후). 주문·계좌·잔고 경로는 코드에서 거부.
- 속도 제한: 초당 1건 이하로 시작(공식 FAQ 10건/초의 1/10, 현재 값 변동 가능성 고려), 오류·429면 즉시 중단·재시도 없음.
- 출력(가격 스냅샷): provider=`KIS Open API`, fetchedAt, marketDate(응답의 기준일), timezone=Asia/Seoul, currency=KRW, priceKind(응답으로 구분 가능한 경우만, 아니면 `미확인`), verification=`미검증`. **독립 검증은 순태씨가 증권사 앱 값과 직접 대조한 경우에만** 승격(20단계 `price-trust` 규칙 그대로).
- HAS 쪽: 스냅샷 읽기 화면은 시범 영역에서 시작, 기존 보유·가계부·백업 형식 변경 없음.
