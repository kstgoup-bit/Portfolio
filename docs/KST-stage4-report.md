- 새 JS/CJS와 기존 inline 구문 검사 및 git diff --check 통과. 별도 ESLint는 도입하지 않았다.

시험 명령은 `npm test`, `npm run test:mobile`, `node tools/review-universe.cjs 2026-10-29`다. 현재 시험 브라우저는 헤드리스 Chromium 138 모바일/터치 재현이며 로컬 Noto Sans KR을 사용했다. **실제 Android 홈 화면 설치/갱신·실제 기기 캐시 삭제·실제 투자 기록 접근은 미실시**다. 외부 자동 시세 요청을 차단하고 합성 자료로만 시험했다.

모바일 결과 JSON은 폭별 geometry·보존·오류와 각 묶음 결과를 포함한다. 전달 evidence에는 기준선/최종 로그, 실패 초기 로그, 200 합성 부하, 목록 감사, 기준 화면 및 레이더/전체 복원/파일럿 차단/지연/오류/중단 복원 PNG가 있다. 지연 데모 캡처의 2020-01-02는 시험에서 주입한 합성 날짜이며 실제 주가 기준일이 아니다.

## 7. 남은 과제와 다음 승인

1. **원격 브랜치/PR 미완료:** 403 해소 전에는 공식 연결 쓰기 지원·저장소 범위 확인 또는 사용자 본인의 인증된 개발 환경 적용이 필요하다. 로컬 SHA·전체/증분 패치·format-patch·소스 ZIP은 제공한다.
2. **실제 5종목 가격 검증 미실시:** 본인용 표시/보관·가공·필요 참조 데이터 권리, 자격증명·안전한 비밀 보관과 공급자 선택을 승인받은 뒤 최대 5종목 파일럿만 진행한다. 비밀키를 채팅/ZIP/localStorage에 넣지 않는다.
3. **특정 벤더 변환/프록시·실제 거래일 캘린더·업종 ETF 매핑·교차 대조:** 미구현/미검증. 표준 계약·가짜 응답 검증이 이를 대신하지 않는다.
4. **200종목 검증·실수집:** 미완료. 적격성·금융/고성장 기준·재무 근거·상장/시총·이용권과 날짜를 종목별 확인해야 한다. 현재 실제 활성0이다.
5. **실제 Android 및 운영 PWA 갱신:** 미실시. 기존 워커의 오래된 HTML/JSON 대체 문제는 운영 앱에 남아 있고 별도 승인 전 변경하지 않는다.
6. **기존 API 키 평문·복원 다중 탭/영구 저장 장애:** 3단계의 별도 보안/저장 제약을 유지한다. 해당 범위는 사용자 승인·호환성 검토 없이 확대하지 않았다.

사용자 승인 없이 하지 않은 항목: 키 사용/추출, 실제 시세 API 호출, 공급자 계정·유료 구독·과금·서버/클라우드·자동 감시 스케줄 생성, 주문/자동매수/알림 전송, main/Pages/운영 배포/워커 반영, 실제 기기 데이터 조작. 이 차단을 감추지 않은 재현 가능한 로컬 납품으로 조건부 완료를 보고한다.
