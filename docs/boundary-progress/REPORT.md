## 보완 내용

- 외부 JSON 문자열 입력을 위한 제한된 API와 작업대 연결. 직접 객체 API는 신뢰하는 내부 데이터 객체용으로 범위를 명시한다.
- 검증한 데이터의 사본을 사용하고 원본 객체의 `JSON.stringify` 및 `toJSON` 경로를 제거한다. 크기·깊이·노드·배열 길이를 제한한다.
- 가림 비교 도구에 정확한 센티널, 기대 결과, 실패 종료 상태와 실패를 실제로 탐지하는 역시험을 추가한다.
- 실제 연결 전 자료 준비도를 검사하는 별도 오프라인 모듈·CLI·합성 예시를 추가한다. GAS 중계와 원천 공급자, 거래소/수신 시각, 가격 유형/지연, 권리 근거, 독립 대조 원천, 차트 조정/달력, 재무 공시 출처를 구분한다.
- 준비도 결과는 입력된 항목의 존재와 형식만 검사한다. 선언이 모두 있어도 `declared-only`이며 원문 확인·계정 권한·독립성·실시간 연결은 검증되지 않는다. 비밀값이 없다는 보증도 하지 않는다.
