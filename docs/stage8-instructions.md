## 3. B — 8단계 목표와 범위

### B1. 국장 후보 100개 공식 검증

- 7단계의 국내 개별주 73개와 ETF 5개는 모두 **공식 목록 미검증 후보**임을 전제로 한다. 공식 KRX/공공기관의 최신 상장종목 자료를 출처·조회일·기준일·원본 해시와 함께 확보 가능한지 검토한다.
- 공식 목록을 합법적으로 내려받을 수 있다면 **가격 API 호출 없이** 오프라인으로 종목코드 6자리, 종목명, 시장구분, 상장·상폐·관리상태를 대조한다. 이름만 같다고 확정하지 말고 코드/시장/기준일 일치 여부를 기록한다.
- 부족한 27개는 **공식 근거가 확보된 경우에만** 보충한다. 근거가 없으면 73개 또는 검증된 개수 그대로 남기고 100개를 채웠다고 주장하지 않는다. ETF 5개는 개별주 100개와 분리한다.
- 기업 분할·합병·우선주·SPAC·REIT·ETF·중복종목·거래정지·상폐·관리종목의 포함/제외 정책을 명시한다. 공식자료가 없으면 도구와 스키마만 구현하고 상태는 `unverified`로 유지한다.

### B2. 미국·한국 시세 공급자 의사결정 자료

- 미국장 5개(MSFT, GOOGL, AVGO, VRT, JPM), 국장 5개(공식 검증이 가능할 때만 확정)를 대상으로 데이터 계약을 설계한다.
- 공급자별 **정규장 일봉, 52주 고가와 분할/배당 조정 기준, 거래소 캘린더, 시차, 지연, 출처, ETF/벤치마크, 개인용 표시·저장·가공 권리, 무료/유료 요금, 호출 제한, 인증키 저장**을 공식 문서 중심으로 비교한다.
- 문서 조회와 실제 시세 API 요청을 구분한다. 약관·요금·권리 미확인 항목은 `미확정`으로 남긴다. 사용자의 키·계정·실제 보유기록을 요청하거나 읽지 않는다.
- 실제 공급자 연결은 **비활성 인터페이스/합성 어댑터**까지만 구현한다. 실데이터 API 호출 0건을 유지한다.

### B3. 투자 판단의 품질·안전

- 한국장 100점 점수는 **미검증 설계 가정**임을 명시한다. 매수·매도 신호의 근거, 반대 근거, 결측, 데이터 만료, 종목 위험 상태, 정정공시, 지배구조, 주주환원(자사주 취득 vs 소각), 경기순환을 구분한다.
- 실가격 미확인, 조정 기준 혼합, 벤치마크 불일치, 공시 미검증, 권리 미확보 시 `평가 보류`로 처리한다.
- 국내 개별주/ETF, ISA/일반/연금, 코어/새틀라이트 구분을 유지한다. 투자 성과나 5년 10억 달성 가능성을 보장하지 않는다.

## 4. 구현 방식 및 시험

- 7단계 성공 원격 SHA에서 새 독립 브랜치로 개발한다. 기존 `portfolio_v5.html`, `manifest.json`, `service-worker.js`, 백업v6, 기존 미국장/국장 모듈은 변경하지 않는 것을 원칙으로 한다.
- 신규 모듈/도구/문서/합성 fixture/단위시험 중심. UI, 실제 API 연결, 실기기 저장소 연동은 별도 승인 전 미실시.
- 기준 259개 단위시험과 모바일 25묶음 재현 후 신규 검증시험 추가. 정정공시, 중복코드, 우선주, 상폐/거래정지, 잘못된 날짜, 누락 데이터, 수정가격 혼합, 가짜 API 키 노출 방지, 원본 불변성 등 음성 시나리오 포함.
- 실제 Android/PWA 시험을 하지 않았으면 하지 않았다고 보고한다. 100종목 합성 부하와 100종목 실제 감시는 구별한다.
