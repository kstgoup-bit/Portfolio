# HAS 실데이터 연결 로드맵

## 목표

실시간 또는 정확히 표시된 지연/종가, 근거 있는 재무제표 분석, 일관된 차트 분석을 한 흐름으로 연결합니다. 기업이 우량한지, 현재 가격이 매력적인지, 시장 공포가 커졌는지는 서로 다른 질문입니다. 마지막 판단은 사용자가 하며 실제 주문 기능을 만들거나 실행하지 않습니다.

## 현재 확인된 상태

- 기존 `portfolio_v5.html`의 `fetchKR`, `fetchUS`, `fetchFX`는 GAS(JSONP) 경로를 사용합니다. stage28의 `quoteMeta`는 이번 접속에서 받은 시간을 메모리에 기록합니다. **받은 시간이 곧 거래 시각은 아닙니다.** GAS 내부 원천·가격 종류·지연시간·이용권은 아직 확인하지 못했습니다. 근거: `docs/KST-stage28-report.md`, `portfolio_v5.html`.
- 기존 Alpha Vantage `fetchFundamentals`는 `OVERVIEW`를 사용하며 `computeQuantScore`가 성장·이익률·ROE 점수를 계산합니다. 소스의 일 25회 제한 문구는 현재 플랜 권리를 검증한 자료가 아닙니다. 실제 키·요금·호출 가능 범위는 확인하지 않았습니다.
- KIS 설계·runner가 있지만 stage28은 KIS 중계 미채택과 GAS 유지 방침을 명시합니다. 이 작업에서 계좌·토큰을 연결하거나 방침을 바꾸지 않았습니다.
- 새 가치평가 엔진은 자료를 자동 수집하지 않습니다. 현재 수동/합성 계약과 계산 검증이 준비된 상태입니다. 레거시 매수 검토 규칙과 새 가치평가가 모든 화면에서 하나의 판정으로 통합된 상태는 아닙니다.

## 1. 기존 시세 공급 경로 확인 및 표준화

먼저 기존 GAS를 재사용할 수 있는지 확인합니다. 원본 스크립트 또는 민감정보를 제거한 응답 계약을 확보하고, 원천 사업자·국내/미국 시장·종목 식별·통화·실제 거래시각·가격 종류·지연시간·조정 여부·이용권을 확인합니다. 알 수 없는 항목을 실시간으로 승격하지 않습니다.

표준 응답에는 종목/시장/통화/가격, 거래소 기준일, 실제 시세 시각, 조회 시각, 원천, 실시간·지연·종가 구분, 검증 근거가 필요합니다. 같은 시점의 독립 원천 대조는 지연·휴장·통화·호가/체결가 차이를 맞춘 뒤 허용 오차를 기록합니다. 원천이 같은 재판매 경로 둘을 독립 원천으로 세지 않습니다.

완료 조건: 승인된 소수 종목으로 읽기 전용 표본 대조, 조회 실패/장마감/휴장/오래된 캐시/순서 역전 재현, 출처·지연 표시, 기존 투자기록 불변 확인. 실시간 권리가 없다면 정확한 지연/종가 분석부터 연결합니다.

## 2. 재무제표 원천과 회계 기준 연결

기존 OVERVIEW 요약값만으로 완전한 재무제표 분석을 대신하지 않습니다. 승인된 공급자 또는 공식 공시 원천에서 손익계산서·재무상태표·현금흐름표를 읽어 기간/통화/단위/연결·별도/발표일/수정 공시를 함께 보존합니다. 한국 공시와 미국 공시 등 후보의 실제 API 이용조건·호출량은 연결 전에 확인합니다.

TTM은 서로 겹치지 않는 네 분기로 구성하고 비교기간을 맞춥니다. EPS·주식수·희석·분할·일회성 손익을 대조합니다. 금융업의 자본·부채 해석, 반도체의 업황 정상화, 적자기업의 현금 소진, ETF의 NAV·보수·구조를 분리합니다. 새 가치평가 엔진의 근거 계약으로 매핑하고 원문으로 되돌아갈 수 있게 합니다.

완료 조건: 각 업종 표본의 공시 원문과 계산값 대조, 분기 누락/통화 혼합/단위 오류/수정 공시/음수 기초값 반례, 자료 부족 시 판단 보류. DCF는 현금흐름·할인율·말기가정의 근거가 준비된 별도 확장입니다.

## 3. 차트·시장 분석 연결

같은 거래일·조정 기준의 OHLCV와 벤치마크를 확보합니다. 분할·배당 조정과 총수익/가격수익을 구분하고 빈 구간·중복 봉·미완성 봉·시간대·거래량 단위를 검사합니다. 공급자가 제공하지 않은 봉이나 거래량을 만들지 않습니다.

기존 수익률·고점 대비 낙폭·변동성·최대낙폭 계산부터 연결합니다. 이동평균·거래량·RSI 등 추가 지표는 관측 구간과 계산법, 표본 수를 표시하고 미래 정보 유입 없이 검증합니다. 차트만으로 기업가치나 매수 결론을 대신하지 않습니다.

완료 조건: 동일 원천의 원본 봉과 화면/지표 일치, 기업행사 전후 재현, 지표별 최소 관측 수, 지연/휴장 구간 표시, 현재 정보와 백테스트 당시 정보 분리.

## 4. 판단 화면과 기존 연구 기능 통합

품질·가치·심리를 각각 표시하고 확인된 사실, 계산, 가정, 해석, 불확실성을 분리합니다. 레거시 `fundamentalsStatus=ok`나 낙폭만으로 새 엔진의 가치 판정을 대신하지 않습니다. 운영 화면에서 긍정적 검토를 보여주기 전에 새 가치/품질 관문과 기존 위험 경고를 연결해 한 가지 명시적 판정 규칙으로 검증합니다.

최신 근거 편집기·복귀 시뮬레이터 전체 소스를 확보한 뒤 기존 여섯 근거 주제와 공유합니다. 세금·수수료·환율·전술 실패·계속 보유 기회비용을 포함한 주식 수 복귀 계산을 검증합니다. 구형 합성 모듈을 최신 통합본으로 덮어쓰지 않습니다.

완료 조건: 새로고침·누락·실패·재시도·뒤로가기에서 의견과 근거가 함께 갱신, 모바일 가독성, 읽기 전용 연결, 원장/백업 바이트 보존. 별도 시험 환경의 실제 브라우저와 갤럭시 확인이 필요합니다.

## 승인·비용·운영 경계

- 지금 가능한 일: 합성 입력 기반 어댑터/계약/지표/회귀 개발과 검토, 비용·권한 변경 없는 자료 조사.
- 실제 데이터 연결 전: 원천별 개인 이용/표시/저장/재배포 권리, 실시간 권리, 무료·유료 한도와 비용을 확인하고 필요한 선택만 사용자에게 구체적으로 제시합니다. 기존 키가 존재한다고 사용/저장/권한 확장을 자동 승인한 것으로 간주하지 않습니다.
- 신규 키·토큰·지속 접근 또는 보안 권한 변경, 유료 계약·거래, 개인정보 전송은 각각 필요한 승인을 받습니다. 비밀값은 문서·브라우저 코드·공유 로그에 넣지 않습니다.
- 이 후속 단계에서는 실제 API를 호출하지 않았습니다. main 병합·운영 배포는 하지 않습니다. 실제 주문은 금지입니다.

안전 차단 자체를 완료 목표로 삼지 않습니다. 다음 개발의 우선순위는 **기존 GAS 응답의 확인 가능한 시세 메타데이터 계약 확보와, 승인된 원천 표본을 가치평가 입력으로 변환하는 읽기 전용 어댑터**입니다.
