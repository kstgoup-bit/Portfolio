## 변경 계약

- `has/quote-model.js`: 엄격한 날짜/시각 검사, 거래소 시간대, 시각 간 일관성. 읽기 전용 순수 함수입니다.
- `has/watch-engine.js`: 가격 신호 관문, 재무 필수값·출처·확인 표식, 보조자료 시점 검사.
- `has/advisor-core.js`: 현재 입력 재평가, 불충분한 근거의 긍정 의견 보류. 기존 `w` 인자는 호출 호환성을 위해 남기되 신뢰하지 않습니다. 별도 감시 설정이 필요하면 `settings.watchSettings`로 명시합니다.
- 합성 예시 세 파일과 공통 시험 자료에는 재무 확인 표식을 명시했습니다. 미국 합성 시각도 뉴욕 날짜에 맞췄습니다. **실제 사용자 자료를 검증됨으로 바꾸지 않았습니다.**
- `independent-verified`는 호출자가 제공하는 계약상의 확인 표식이지 암호학적 증명이 아닙니다. 실제 공급자 대조·출처 인증을 대신하지 않습니다. 값을 채워 넣기만 해서는 운영 승인 근거가 되지 않습니다.
- 레거시 `fundamentalsStatus=ok`는 이 다섯 항목의 제한된 규칙 검사 통과일 뿐입니다. 전체 기업 품질, 회계 정확성, 적정가치 또는 수익 보장을 뜻하지 않습니다. 기존 배수 가치평가 엔진의 별도 품질·가치·심리 평가는 그대로 분리되어 있습니다.
- 재무 일반 금액은 절댓값 `1e18` 이하, 매출 성장률은 `-100..1e6`, 부채비율은 0 이상, 환율 두 값은 `1e-9..1e9` 범위입니다. 범위 밖은 추정해 보정하지 않습니다.
