# HAS 22단계 B 실행 승인 요청서
상태: **미승인·미실행**. A단계 종료만으로 B를 실행하지 않는다.

## 요청 범위
사용자가 승인하면 다음 선행조건을 확인한 뒤에만 무료 계정 연결·키 발급·조회 전용 검증을 진행하도록 요청한다.

| 항목 | 제안 범위·제약 |
|---|---|
| 1차 공급자 | KIS: 미국 5·한국 5 후보. 기존 계정 사용 우선, 신규 증권계좌 개설은 이번 요청에서 제외 |
| 대조 경로 | 한국 KRX, 미국 Twelve Data. 현재 개인용 대조·보존권 및 무료 범위 확정 전 사용 금지 |
| 비용 | 0원 상한. 카드 등록·체험 후 유료전환·유료 구독·초과과금 불허. 필요한 권리가 유료뿐이면 중단·별도 보고 |

## 실행 전에 해결할 조건
1. KIS 개인 직접 이용약관, 현재 계정별 조회 한도·해외 요금, 시세 보존·대조 목적 허용 확인.
2. KRX API 사용료, 보존/대조 범위 및 주식/ETF 서비스별 활용 승인 확인.
3. Twelve Data 무료 Basic의 미국 개인 검증·내부 처리/표시 범위와 보존기간 확인. 유료 한국 시장 사용 안 함.
4. 공급 경로의 독립성·동일 원천 위험·확정 정규 종가 정의 확인. 조건이 부족하면 검증 보류.
5. 계정 연결에 본인인증이 필요하면 제공사의 공식 인증 절차 사용. 승인만으로 사용자 비밀번호를 수집하거나 대신 추정하지 않음.

현재 A단계 코드는 합성 전용이며 실제 전송기능이 없다. B 승인 후 별도 live 어댑터의 스키마 검증·전송/자격증명 경계 구현과 합성 재시험을 먼저 완료한다. 안전한 자격증명 연결 수단이 없으면 실호출을 진행하지 않는다.

## 승인과 무관하게 제외
실제 거래·잔고 조회·주문·자동매매·원장 마이그레이션·비밀번호/API키 자동 이동/삭제·운영 배포·PWA·main 변경·유료 서비스. 검증 완료 후에도 실제 감시 확대/투자 신호 활성화는 별도 판단 사항이다.

## 요청하는 답변
“위 선행조건·0원·40요청 상한으로 B단계 계정 연결과 10종목 조회·대조를 승인한다” 또는 “A단계까지만 유지한다”. 승인 후에도 미확인 이용조건을 허용된 것으로 간주하지 않는다.
