# 백테스트 엔진 1차 — 데이터 계약·편향 방지 설계 (15단계 C)

모듈: `invest/backtest.js` (순수 계산, 네트워크·저장소·시간·난수 접근 없음). 현재 **실데이터 백테스트 0건** — 모든 결과는 합성 자료입니다.

## 1. 데이터 계약
- 가격: `[{d:'YYYY-MM-DD', c:종가>0}]`, 날짜 오름차순·중복 없음(위반 시 실행 거부). 비교지표(예: S&P500)는 같은 형식.
- 메타데이터(`meta`): source, asOf, adjusted(adjusted/raw/unknown), dividends, splits, delistings, haltDays, survivorship, fees, slippage, fx, isSynthetic, license(verified/none).
- 표시 이름: 합성 → "합성 계산기 시험 (성과 주장 불가)" / 실자료라도 license 미확인·출처·기준일 없음 → "실데이터 여부·사용권 미확인 (성과 주장 불가)" / license=verified+출처+기준일 → "실데이터 백테스트". 집계 함수 `realBacktestCount`가 센다(현재 0).
- 미반영·미확인 항목마다 결과 화면 경고.

## 2. 규칙
- 곡소리: 최근 252거래일 고점 대비 하락률이 20/30/35%를 처음 넘는 날(구간별 재장전: 하락률이 구간−5%p 아래로 회복된 뒤 재신호).
- 환호성: 원래 규칙은 밸류에이션·판단 기반이라 가격만으론 재현 불가 → **가격 기반 대용 규칙**(12개월 상승률 50/100%)으로만 계산하고 항상 경고.
- 규칙 버전 `kst-bt-rules-1.0`.

## 3. 미래정보 누출(look-ahead) 방지
1. 신호는 해당 시점까지의 봉만으로 계산. 진입은 **신호 다음 거래일 종가**.
2. `leakCheck`: 8개 시점에서 "그 시점까지만 준 자료"와 "전체 자료"의 신호가 같은지 비교, 다르면 실행 거부(미래를 훔쳐보는 규칙은 시험에서 거부됨).
3. 오염 시험: 미래 구간 가격을 마구 바꿔도 이전 신호가 동일함을 시험.
4. 훈련/검증 분리(기본 60/40), 구간 경계를 넘는 관측은 제외 표시. 매개변수 후보 탐색은 훈련 구간으로만 고르고 검증 구간 결과만 평가, 후보 수 기록·과최적화 경고.

## 4. 산출
신호 횟수, 1/3/6/12개월(21/63/126/252거래일) 후 수익률 중앙값·평균·승률·최악, 보유 중 최대낙폭, 비교지표 대비 초과수익(같은 진입·청산일), 기간 부족·비교지표 결측·겹침·구간 초과 제외 건수. 거래비용(수수료·슬리피지·환전 bp) 반영.
판정 문구는 3종뿐: "검증 부족"(검증 구간 3개월 관측 30건 미만) / "전략 재검토"(중앙값≤0, 승률<50%, 초과수익≤0 중 하나) / "가설 단계 (매수 추천 아님)". 추천·보장 표현 없음.

## 5. 재현성
자료·비교지표·설정·메타 각각의 지문(FNV-1a, 필요 시 sha256 주입 가능)과 결과 지문, 규칙 버전, 시드 합성 자료 생성기(같은 시드→같은 자료)로 같은 결과를 재현.

## 6. 합성 시험 결과
`tests/backtest-stage15.test.cjs` 19개 통과: 손계산 사례(+20%, 최대낙폭 −10%, 비용 17.6238%, 초과 +15%p), 기간 부족 제외, 재장전, 대용 규칙, 겹침, 누출 거부/오염, 입력 검증, 라벨, 경고, 판정, 분리, 후보 탐색, 재현성, 경계, 정적 검사. 변조(진입일·제외 경계·재장전·판정) 시험에서 실패가 감지됨.
