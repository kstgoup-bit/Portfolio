# 동일 거래 세션 종가 비교 · 구현 및 검증

확인·작성: 2026-11-09. 독립 로컬 개발·합성 시험 단계이며 실제 연결·운영 배포본이 아니다.

## 결론

최신 클로 변경을 보존하면서 회귀 목록 오류를 수정했고, 기존 동일 시각 경로와 분리된 동일 거래 세션 종가 모드를 추가했다. 날짜만 같다고 비교하지 않는다. 종목·시장·거래소·통화·거래일·공식 정규장 종가라는 정의·완료 상태·미조정 가격·거래 달력과 시간 순서가 맞아야 한다.

일치해도 **제공된 선언과 숫자의 일치**다. 공식성·실제 완료·달력 진위·최신성·독립성·실시간 연결을 확인한 것은 아니다. 결과는 항상 미검증이며 투자 신호로 쓰지 않는다. GAS는 그대로 유지하고 KIS는 추가 자료 역할만 한다. 주문·자동매매 기능은 구현하지 않았다.

## 기준과 보존

- 원격 기준: `work/has-kis-complementary-claude-verify-20261109` HEAD `5409ca6780ecad1706002b4edd7ca00d246d0362`.
- 로컬 재구성 기준: `178c380fac9e0d6ed7008c359ae522c412fdf977`.
- 기준 전체 트리: `5f75997dcd80a27dea44909aa7262b61aa13557d`. 원격과 정확히 같다. 동일 트리의 로컬 스냅샷이며 원격 이력 전체를 복제한 것은 아니다.
- 클로의 어두운 글자색 수정과 색상 시험을 보존했다. 기존 `kis-comparison.js` 및 합성 예시는 변경하지 않았다.
- 기존 앱·GAS·서비스 워커·장부/백업·market-data·quote-model·quote-crosscheck·가치평가·KIS 실행기·중계 정책은 변경하지 않았다. 실제 투자기록에 접근하거나 변경하지 않았다.

## 구현 범위

### 1. 회귀 목록 복구

클로가 추가한 `tests/kis-comparison-colors.test.cjs`를 명시적 회귀 목록에 포함했다. 새 종가 시험도 함께 등록했다. 기존 실행기가 시험 목록 불일치로 중단되던 상태를 해결했으며, 목록 검사 자체를 끄거나 파일을 조용히 제외하지 않았다.

### 2. 별도 종가 계약

`has/close-comparison.js`와 합성 예시를 추가했다. 최대 12 KiB의 primitive JSON 문자열만 받고, 알려지지 않은 필드·중복 키·숫자 범위 오류·모호한 날짜를 거절한다. 원문·예외를 결과에 되풀이하지 않으며 결과는 동결된다.

- KRX 정규 15:30 서울, 미국 지원 거래소 정규 16:00 뉴욕 및 명시한 13:00 단축장을 시간대/DST에 맞춰 검사한다. 주말·달력 불일치·휴장 선언은 보류한다.
- NXT의 공식 종가 의미, 한국 특수/단축장, 미지원 세션은 추정하지 않고 보류한다. 실제 휴일 여부와 단축장 날짜의 진위는 별도 미검증이다.
- 수정주가끼리도 기업행사 반영 기준/버전을 확인하지 못하므로 이번에는 **raw 미조정 가격만** 지원한다.
- 일정상 마감시각과 가격 관측시각을 구분한다. 게시·관측 시각은 없으면 비워 둔다. 조회시각을 그 대신 넣지 않는다.
- `closeEvidence`와 달력 reference는 입력 선언의 종류를 표시하는 값이다. 인증서·원문 조회·실제 완료 근거 확인을 뜻하지 않는다. `finalityVerified`, `calendarVerified`, `latestSessionVerified`, `independenceVerified`, `freshnessVerified`, `usableForSignals`는 항상 false다.
- 조회시각은 선언된 세션 종료 이후, 입력된 분석 기준시각 이전이어야 한다. 게시·관측 시각이 있으면 시간 순서를 추가 검사한다. 분석 기준시각도 제공된 선언이며 현재 시스템 시각이나 최신 자료임을 보증하지 않는다.

### 3. 모바일 중심 모드 분리

기존 독립 비교 화면에 ‘동일 시각’과 ‘동일 거래 세션 종가 표기’ 선택을 추가했다. 모드를 바꾸면 입력과 결과를 비우고, 선택한 모드의 엔진과 예시만 사용한다. 게시시각 누락을 채우도록 유도하지 않는다. 이유·불확실성은 고정된 문구로 표시한다.

네트워크·키·계좌·저장·업로드·내보내기·주문 기능은 없다. 모드별 가짜 엔진과 DOM 시험을 함께 갱신했다. 글자색·터치 크기·레이블의 정적 검사를 유지했다.

## 공식 자료 검토에서 확인한 중요한 차이

- 국내 일봉 후보 필드는 `stck_bsop_date/stck_clpr`, 해외는 `xymd/clos`다. 국내 raw 옵션은 `FID_ORG_ADJ_PRC=1`, 해외 raw 옵션은 `MODP=0`으로 숫자 의미가 반대다.
- 해외 예제의 일 단위는 `GUBN=0`인데 실행 예제는 `2`(월 단위)여서 그대로 복사하면 안 된다.
- 검토한 샘플은 게시/관측시각, 당일 봉 확정 여부, 정규장 공식 종가의 완전한 의미를 확정해 주지 않는다. 날짜와 ‘종가’라는 이름만으로 실제 어댑터가 final/official을 만들어 넣으면 안 된다.
- FX의 공식 일별 경로는 확인했지만 통화쌍 방향·단위·가격 종류·고시/fixing·시간대·원천 의미가 부족하다. 주식 비교기에 FX를 억지로 추가하지 않았으며, 별도 계약 조건만 정리했다.

공식 링크와 직접 확인/미확인은 DAILY-SOURCE-GAPS.md와 FX-SUITABILITY.md에 구분했다. 실제 API를 호출한 결과가 아니다.

## 미실행과 다음 단계

전체 `npm test`는 이전 네트워크 시험 실행 거부 때문에 재시도하지 않았다. 제외는 기존과 같은 network-guard-stage19, kis-runner-stage21, us-pilot-stage18, krx-runner-cli, kr-krx-stage13 다섯 파일이다. 전체 무제외 통과라고 부르지 않는다.

Chromium은 앞선 환경에서 소켓 권한으로 거부되어 재시도하지 않았다. 실제 모바일 레이아웃·갤럭시·화면 확대·소프트 키보드·실제 뒤로/앞으로 동작은 미검증이다. DOM·정적 스타일 검사가 이를 대신하지 않는다.

실제 KIS/GAS 응답을 정규화하는 어댑터와 공급자 finality/공식 종가 정의·권리·계정 조건·실제 달력 검증은 아직 남아 있다. 기존에 제공된 자료를 먼저 재사용하고, 부족한 비밀정보 제거 GAS 응답과 공식 의미 정의만 추가 확인하는 것이 다음 단계다. 현재 enum 선언을 실제 원문 근거로 오인해서는 안 된다.

실제 키 사용·조회·클라우드 생성/변경·유료 서비스·운영 배포·main 변경은 하지 않았다. 이 보고서나 과거 실행 예시가 그런 실행 승인을 대신하지 않는다. 클로 협업 자료는 사용자 경유이며 외부 에이전트에게 직접 보내지 않았다.
